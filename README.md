# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **1.8.0**
- 엔진 버전: **1.1.0**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC 이동: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 이동: 가상 조이스틱 또는 지형 짧은 터치
- 모바일 카메라: 한 손가락 드래그 회전, 두 손가락 핀치 줌
- Space: 질주
- Q: 광역기
- E: 소환
- R: 집중 명령
- F3: 엔진 통계 HUD

## v1.8.0 / 엔진 1.1.0

### 첫 실행 복구

- 플레이어 생성 전 첫 렌더 프레임에서 `player.group`을 읽던 BOOT RECOVERY 오류 수정
- 월드 생성·정리 중 blob shadow, 청크, 애니메이션 접근을 `worldReady` 상태로 보호
- WebGL 렌더러 생성 실패 시 품질을 낮춰 최대 3단계로 재시도
- 렌더러를 끝내 만들지 못하면 원인을 구분할 수 있는 명확한 오류 메시지 표시
- 비 Vite 실행 환경에서도 에셋 기준 경로가 안전하게 `./`로 폴백

### 대규모 전투 업데이트

- 웨이브마다 전투 규칙을 바꾸는 **달의 징조 5종**
- 3웨이브부터 등장하는 **정예 요괴 속성 4종**
- 피해 없이 웨이브를 끝내면 쌓이는 **달빛 방패**
- 4성·5성 도깨비 소환 시 발동하는 **왕대박 폭주**
- 징조, 방패, 폭주 상태를 전투 HUD에 실시간 표시
- 정예 처치, 방패 방어, 폭주 발동을 결과 분석 통계에 추가

### 안정성과 수명 관리

- 플레이어 공격 애니메이션이 잘못된 `unit.animation`을 참조하던 오류 수정
- 적 ObjectPool 반환 전에 사망 좌표를 보존해 엽전·파티클이 정상 위치에서 생성
- 타이틀 복귀와 재시작 시 플레이어·도깨비·적 애니메이션 컨트롤러를 안전하게 제거
- 정예 오라 geometry는 적 풀과 함께 재사용해 웨이브 중 불필요한 할당을 억제

## 모바일 엔진 원칙

- 실시간 그림자 비활성화, InstancedMesh blob 그림자 사용
- 도깨비 300 triangles, 일반 적 500 triangles 이하
- 바위·등불·상점·소환 발판 InstancedMesh
- 파티클·투사체·엽전·적 모델 ObjectPool
- 거리 기반 LOD와 월드 청크 가시성
- SVG 금지, GLB/GLTF 및 PNG/WebP/KTX2만 허용
- Firebase는 게임 루프에서 호출하지 않고 결과 저장 시에만 사용
