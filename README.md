## v1.0.33 핵심 변경

- 청월 이무기와 백귀 야행왕의 런타임 식별 언어 분리
- 이무기: 청록 동심원·독월 고리·혼령 덫
- 야행왕: 자주·금색 행진 장판·처형 도약·왕의 충격파
- 보스 HUD에 문양·무기·현재 패턴을 표시하는 식별 배지 추가
- 모바일 좁은 화면과 노치 안전영역 보강
- 90웨이브 FPS·메모리·파티클·투사체·장판·비주얼 레코드 검사
- 컴팩트 통파일의 루트 위생 오류 수정

## 검증

```bash
npm run verify
npm run build:static
npm run verify:dist:v133
```

`dist/`가 없는 컴팩트 통파일에서는 Windows 기준으로 다음 파일을 실행할 수 있습니다.

```text
scripts/REBUILD_DIST_WINDOWS.bat
```

상세 내용은 `docs/BOSS_IDENTITY_ASSURANCE_v1.0.33.md`를 확인합니다.
