# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **2.0.0**
- 엔진 버전: **1.3.0**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 배포 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC 이동: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 이동: 가상 조이스틱 또는 지형 짧은 터치
- 모바일 카메라: 한 손가락 드래그 회전, 두 손가락 핀치 줌
- Space: 질주
- Q: 도깨비불 난무
- E: 소환
- R: 집중 명령
- F: 혼불 100%일 때 수호신 폭주
- F3: 엔진 통계 HUD

## v2.0.0 / 엔진 1.3.0

### 오늘의 원정과 재현 가능한 런

- 서울 날짜를 기준으로 매일 고정되는 `MOON-YYYYMMDD` 시드 제공
- 자유 원정은 새 랜덤 시드를 생성하고 결과 화면에서 같은 시드 또는 새 시드로 재도전 가능
- 징조, 웨이브 도전, 유물 후보, 적 종류·문·정예 배치 등 핵심 전투 난수를 시드에 연결
- 오늘의 칙령 6종이 보상, 적 능력, 정예 확률, 혼불, 소환 운 등 한 판의 규칙을 변경
- 전투 HUD와 결과 화면에 시드와 칙령을 표시

### 월식 보스 3종

- 4웨이브: 저승 호랑이 — 돌진과 충격파 중심의 2페이즈 전투
- 7웨이브: 청월 이무기 — 독환, 혼령 속박, 월무 중심의 2페이즈 전투
- 10웨이브: 백귀왕 — 광역 위험 지대와 연속 패턴을 사용하는 3페이즈 최종전
- 보스 전용 체력·의도·페이즈 HUD와 위험 패턴 통계 추가

### 전장 테마 8종

달의 징조에 따라 배경, 안개, 반구광, 월광, 달·후광, 포털, 지면, 룬, 도깨비불 색상과 안개 밀도가 부드럽게 전환됩니다.

- 풍요, 혈월, 서리, 폭풍, 월식
- 사냥, 혼령, 새벽

### 저주받은 전설 유물과 세트

- 일반 유물을 포함해 총 **18종**으로 확장
- 보스 처치 뒤 저주 전설 유물 후보를 최소 1개 보장
- 피의 거울, 월식 가면, 혼령 장부, 깨진 종 등 강력한 이득과 대가를 함께 제공하는 4종 추가
- 행운, 전쟁, 수호, 혼령의 2개 세트 보너스 4종 추가
- 유물 HUD에서 저주 유물과 활성 세트를 별도 표시

### 실제 위험 판정

- 파열 정예 사망 폭발이 단순 연출이 아니라 실제 플레이어·신목 판정으로 변경
- 폭발 범위 안에서는 혼불·엽전 손실과 기절 발생
- 범위 밖으로 회피하면 점수와 혼불 보상 지급
- 결과 화면에 파열 피격·회피와 보스 위험 패턴 피격 수 기록

### 접근성·진단

- 화면 흔들림과 피격 섬광 강도를 0~100%로 개별 저장
- 진동 피드백과 모션 감소를 켜고 끌 수 있음
- 모션 감소 시 파티클과 시네마틱 움직임 축소
- 일시정지 화면에서 성능·런 진단 JSON 내보내기 제공
- 테스트 렌더러 주입 경로를 추가해 GPU가 없는 환경에서도 실제 번들의 게임 흐름 검증 가능

## 안정성

- 플레이어 생성 전 `player.group` 접근으로 발생하던 BOOT RECOVERY 오류 수정 유지
- 월드 생성 중 그림자·청크·애니메이션 접근을 `worldReady`로 보호
- WebGL 렌더러 생성 실패 시 기본 → 호환 → 저사양 3단계 재시도
- 적 풀 반환 전 사망 좌표 보존과 애니메이션 컨트롤러 수명 정리
- 실시간 그림자 대신 InstancedMesh blob 그림자 사용
- 도깨비 300 triangles, 일반 적 500 triangles 이하 예산 유지
