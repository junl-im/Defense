# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **1.7.7**
- 엔진 버전: **1.0.6**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 카메라: 한 손가락 드래그 회전, 두 손가락 핀치 줌
- 메인 화면 또는 일시정지 메뉴에서 감도·줌 범위·좌우 조작 배치 설정 이동
- 지형 짧은 클릭·터치: 해당 3D 바닥 위치로 이동
- 한 손가락 드래그: 카메라 회전
- 두 손가락 모으기/벌리기: 줌인/줌아웃
- PC 마우스 휠: 줌인/줌아웃
- Space: 질주
- Q: 광역기
- E: 소환
- R: 집중 명령
- F3: 엔진 통계 HUD

## v1.7.7 / 엔진 1.0.6

- 회전·핀치·휠 감도를 기기에 맞게 저장
- 최소·최대 카메라 줌 범위 설정
- 모바일 이동 조작을 왼쪽 또는 오른쪽으로 교체
- 신목·야시장 상점·요괴문을 카메라가 관통하지 않도록 거리 보정
- 충돌 시 빠르게 당겨지고 장애물을 벗어나면 천천히 원래 줌으로 복귀
- 320px 세로 화면과 낮은 가로 화면에서도 설정 모달이 화면 안에 유지

## 모바일 엔진 원칙

- 실시간 그림자 비활성화, InstancedMesh blob 그림자 사용
- 도깨비 300 triangles, 일반 적 500 triangles 이하
- 바위·등불·상점·소환 발판 InstancedMesh
- 파티클·투사체·엽전·적 모델 ObjectPool
- 거리 기반 LOD와 월드 청크 가시성
- SVG 금지, GLB/GLTF 및 PNG/WebP/KTX2만 허용
- Firebase는 게임 루프에서 호출하지 않고 결과 저장 시에만 사용

## 배포

패치 ZIP을 저장소 루트에 그대로 덮어쓰고 commit·push합니다. 전체 ZIP에는 `dist/`가 포함되며 패치 ZIP에는 변경 파일만 포함됩니다.

다음 작업은 `PROJECT_HANDOFF.md`의 마지막 항목부터 이어갑니다.
