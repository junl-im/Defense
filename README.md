# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **2.4.0**
- 엔진 버전: **1.7.0**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 배포 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC 이동: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 이동: 가상 조이스틱 또는 지형 짧은 터치
- 모바일 카메라: 한 손가락 드래그 회전
- 모바일 줌: 두 손가락을 벌리면 줌인, 오므리면 줌아웃
- Space: 질주
- Q: 도깨비불 난무
- E: 소환
- R: 집중 명령
- F: 혼불 100%일 때 수호신 폭주
- F3: 엔진 통계 HUD

## v2.4.0 / Engine 1.7.0 — 달빛 도감 사냥

이번 버전은 v2.3.0의 모바일 UI·마스코트·11방향 LOD를 유지하면서, 도감을 실제 전투 성장과 영구 보상에 연결했습니다.

### 발견·숙련 도감

- 전체 29종 도감 진행도를 로컬에 영구 저장
- 수호대는 강림 횟수, 요괴·보스는 조우와 격파 횟수 기록
- 4단계 숙련 표시와 미발견 카드 잠금 처리
- 전장·효과 16종은 기본 발견, 수호대·요괴·보스는 실제 플레이로 해금
- 3D 도감에서 진행도, 약점 연구, 보유 전리품을 함께 표시

### 약점 연구

- 일반 요괴는 3회, 보스는 1회 격파하면 약점 해독
- 장난 요괴·질주꾼·돌갑옷·저주 무당·3대 보스 총 7종 연구
- 해독된 적에게 올바른 수호대 속성으로 공격하면 실제 피해 1.16~1.28배 적용
- 약점 적중 횟수와 해독 수를 결과 분석에 기록

### 전리품과 영구 보상

- 일반 전리품 4종, 보스 증표 3종, 희귀 전리품 3종 등 총 10종
- 각 보스 첫 격파 증표는 100% 보장
- 드롭 시 혼불 조각을 즉시 지급하고 도감에 보유 수량 저장
- 런 결과에 신규 발견, 약점 해독, 전리품 획득 기록 표시

### 보스·장터 비주얼

- 저승 호랑이 2페이즈에 혈월 고리, 등불 갈기, 눈빛 장식 추가
- 청월 이무기와 백귀왕의 페이즈 장식도 공통 시스템으로 연결
- 풀링된 보스가 재등장할 때 이전 페이즈 장식을 완전히 초기화
- 외곽에 가판대·등롱·간판·포목·광주리 조합의 모듈형 달빛 장터 세트 배치
- 로딩 화면에 마스코트 4상태 표정 아틀라스 적용

### 기존 개선 유지

- 320×568부터 동작하는 모바일 한 화면 프로필
- 우측 상단 고정 카메라 설정 톱니바퀴
- 벌리기 줌인·오므리기 줌아웃
- 보스 HUD 겹침 회피
- 축소된 중앙 신목과 동기화된 충돌·피격 앵커
- 불씨 깨비·장난 요괴 idle/move/attack 11방향 LOD

## 에셋 성격

현재 캐릭터와 환경은 **Moon Forge 절차형 런타임 프로토타입**입니다. 최종 작가 제작 리깅 GLB/KTX2가 들어오면 같은 에셋 슬롯, 상태 머신, LOD, 도감 UI를 유지한 채 파일만 교체합니다. 세부 규격은 `docs/ASSET_BIBLE.md`와 `docs/ASSET_MANIFEST.json`을 참고합니다.
