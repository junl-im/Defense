# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **2.2.0**
- 엔진 버전: **1.5.0**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 배포 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC 이동: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 이동: 가상 조이스틱 또는 지형 짧은 터치
- 모바일 카메라: 한 손가락 드래그 회전, 두 손가락 핀치 줌
- Space: 질주
- Q: 도깨비불 난무
- E: 소환
- R: 집중 명령
- F: 혼불 100%일 때 수호신 폭주
- F3: 엔진 통계 HUD

## v2.2.0 / Engine 1.5.0 — Moon Forge

이번 버전은 시스템 수 추가보다 실제 화면 품질을 높이는 첫 비주얼 제작 패치입니다.

### 전투 모델 전면 개편

- 수호대 6종: 속성별 무기, 뿔, 갓, 방울, 부적, 월륜과 등 장식 추가
- 일반 요괴 4종: 이동·방어·주술 역할이 실루엣으로 구분되도록 재구성
- 월식 보스 3종: 저승 호랑이, 청월 이무기, 백귀왕 전용 공격 기관과 장식 추가
- 천년 신목: 금줄, 월륜, 핵심 구슬, 뿌리 구조를 갖춘 랜드마크로 교체
- 대기·이동·공격·피격·사망 상태에서 무기와 장식까지 움직이는 절차형 애니메이션 확장

현재 모델은 게임에서 즉시 사용하는 **Moon Forge 절차형 아트 프로토타입**입니다. 최종 작가 제작 리깅 GLB가 들어오면 같은 슬롯, 상태 머신, 도감 UI를 유지한 채 모델만 교체합니다.

### 실제 런타임 에셋

- `moon-market-ground-v1.webp`: 1024² 월문 석판 장터 바닥
- `moon-fx-atlas-v1.webp`: 1024² 4×4 발사체·충돌 효과 아틀라스
- `ember-idle-11.webp`: 2048×1536 불씨 깨비 11방향 원거리 아틀라스

장터 바닥과 FX 아틀라스는 실제 전투에 적용됩니다. 불씨 깨비는 일반 모드 약 22m, 저사양 모드 약 16m 이후 3D 모델에서 11방향 임포스터로 전환됩니다.

### 실시간 3D 달빛 도감

- 도감 카드 클릭 또는 키보드 Enter/Space로 3D 감상 화면 열기
- 드래그 회전과 휠 확대
- 대기·이동·공격·기술 상태 미리보기
- 수호대·요괴·보스·전장·효과 프리뷰
- 불씨 깨비 3D 모델과 11방향 임포스터 비교
- 현재 LOD와 방향 프레임 표시
- WebGL 생성 실패 시 안내 폴백

### 모바일 예산

현재 절차형 전투 프로토타입 기준:

- 수호대: 최대 1,700 triangles
- 일반 요괴: 최대 800 triangles
- 월식 보스: 최대 3,000 triangles
- 천년 신목: 최대 9,000 triangles
- 래스터 텍스처: 저사양 예산 64MB

최종 GLB 목표치는 `docs/ASSET_BIBLE.md`의 LOD0/LOD1/LOD2 규격을 따릅니다.
