# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **2.1.0**
- 엔진 버전: **1.4.0**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 배포 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC 이동: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 이동: 가상 조이스틱 또는 지형 짧은 터치
- 모바일 카메라: 한 손가락 드래그 회전, 두 손가락 핀치 줌
- Space: 질주
- Q: 도깨비불 난무
- E: 소환
- R: 집중 명령
- F: 혼불 100%일 때 수호신 폭주
- F3: 엔진 통계 HUD

## v2.1.0 / Engine 1.4.0

### 중첩 모달 수정

- 일시정지의 `카메라 · 조작 설정`이 뒤에 깔리던 z-index 오류 수정
- 모달을 열린 순서대로 관리하는 스택 추가
- 카메라 설정을 닫으면 일시정지 화면으로 정확히 복귀
- ESC는 가장 위의 모달부터 닫고, 일시정지 화면에서만 게임을 재개
- 모달을 닫은 뒤 원래 누른 버튼으로 포커스 복귀

### 타이틀 정리

- 첫 화면의 패치 설명과 업데이트 홍보 문구 제거
- 화면 하단에는 `v2.1.0` 버전만 표시
- `도깨비 도감`을 `달빛 도감`으로 확장

### 달빛 장터 대도감

다섯 분류의 총 29개 항목을 한 모달에서 확인합니다.

- 수호대 6종
- 일반 요괴 4종
- 월식 보스 3종
- 전장 오브젝트 8종
- 발사체·기술 효과 8종

각 항목에는 전투 정보뿐 아니라 3D 제작에 필요한 실루엣, 민담 모티프, 대표 연출, 전투 판독 기준이 포함됩니다.

### 에셋 제작 기반

- `docs/ASSET_BIBLE.md`: 한국형 달빛 야시장 아트 방향, 폴리곤·텍스처·애니메이션·환경·이펙트 규격
- `docs/ASSET_MANIFEST.json`: 실제 납품 대상과 파일 규칙
- `src/asset-specs.js`: 런타임과 검증기가 공유하는 제작 목표
- `src/engine/asset-catalog.js`: 수호대 6, 요괴 4, 보스 3, 환경 8, 효과 8 슬롯
- `src/engine/directional-impostor.js`: 원거리 11방향 임포스터 프레임 선택과 히스테리시스
- `scripts/verify-asset-readiness.mjs`: 에셋 슬롯과 제작 규격 자동 검증

### 권장 그래픽 구조

- 0~12m: 리깅된 GLB LOD0
- 12~24m: 단순화 GLB LOD1
- 24m 이상: 11방향 임포스터 LOD2
- 수호대 4k~7k triangles, 일반 요괴 3.2k~5.2k, 보스 12k~18k
- 수호대·일반 요괴 1024² KTX2, 보스 2048² KTX2
- 환경은 8m 모듈 타일과 2048² 공유 아틀라스를 기준으로 제작
