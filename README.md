# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **2.3.0**
- 엔진 버전: **1.6.0**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 배포 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC 이동: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 이동: 가상 조이스틱 또는 지형 짧은 터치
- 모바일 카메라: 한 손가락 드래그 회전
- 모바일 줌: 두 손가락을 벌리면 줌인, 오므리면 줌아웃
- Space: 질주
- Q: 도깨비불 난무
- E: 소환
- R: 집중 명령
- F: 혼불 100%일 때 수호신 폭주
- F3: 엔진 통계 HUD

## v2.3.0 / Engine 1.6.0 — Moonlit Mascot UI

이번 버전은 모바일 한 화면 적응, UI 충돌 제거, 중앙 시야 개선, 마스코트와 상태별 원거리 LOD 확장에 집중했습니다.

### 모바일 첫 화면

- 우측 상단 44px 고정 톱니바퀴로 카메라·조작 설정 통합
- 브라우저 주소창을 반영하는 `visualViewport` 기반 높이 계산
- 표준·컴팩트·초컴팩트·짧은 가로 화면 프로필
- 320×568 화면에서는 부가 설명과 일부 미리보기를 축약해 핵심 버튼을 한 화면에 유지
- 390px 이하 화면의 간격, 글자, 버튼, 카드 크기 별도 조정
- 첫 화면에는 패치 설명 없이 버전만 표시

### UI 충돌 방지

- 보스 체력바가 활성화되면 수호대·시너지·연속 처치 패널을 별도 레일로 이동
- 웨이브, 운, 시드, 징조, 유물, 도전, 첫 임무의 모바일 위치 예산 재조정
- 안전 영역과 화면 하단 액션 버튼을 고려한 패널 최대 높이 적용
- 일시정지 위 카메라 설정 모달 스택과 포커스 복귀 유지

### 중앙 신목과 전장

- 천년 신목 시각 크기를 기존의 78%로 축소
- 이동 충돌 반경 1.82m, 카메라 충돌 반경 2.15m, 가림 높이 6.7m로 동기화
- 피해 숫자와 충돌 파티클 위치를 축소된 신목 높이에 맞춤
- 장승 4기, 달항아리 6개, 마스코트 제단을 외곽에 배치해 중앙 시야를 확보하면서 장터 밀도를 유지

### 달빛 장터 마스코트

- 768×768 투명 WebP 마스코트 `moon-mascot-v1.webp`
- 뿔, 보랏빛 도포, 엽전, 부적, 혼불을 사용한 달빛 야시장 도깨비 디자인
- 타이틀 장식, 앱 아이콘 192/512, 마스커블 아이콘, 커버 이미지에 같은 디자인 언어 적용
- 현재 이미지는 게임에 직접 포함되는 절차형 제작 자산이며 최종 작가 원화로 교체 가능한 슬롯을 유지

### 상태별 11방향 LOD

불씨 깨비와 장난 요괴에 각 3개 상태의 11방향 아틀라스를 연결했습니다.

- `idle`
- `move`
- `attack`

각 아틀라스는 1024×768, 4×3 셀, 11프레임입니다. 카메라 거리와 애니메이션 상태에 따라 근거리 3D 모델과 원거리 임포스터가 전환되며 부모 오브젝트 회전을 보정해 빌보드가 누적 틀어지지 않습니다.

- 중앙 신목 크기·충돌·피격 앵커
- 마스코트와 상태별 11방향 WebP 크기
- 폴리곤·텍스처·모바일 레이아웃 예산
- 전체 게임 시스템 정적 검증

## 에셋 성격

현재 캐릭터와 환경은 **Moon Forge 절차형 런타임 프로토타입**입니다. 최종 작가 제작 리깅 GLB/KTX2가 들어오면 같은 에셋 슬롯, 상태 머신, LOD, 도감 UI를 유지한 채 파일만 교체합니다. 세부 규격은 `docs/ASSET_BIBLE.md`와 `docs/ASSET_MANIFEST.json`을 참고합니다.

## 배포

패치 ZIP을 저장소 루트에 그대로 덮어쓰고 commit·push합니다. 전체 ZIP에는 `/Defense/` 기준의 최신 `dist/`가 포함되며 패치 ZIP에는 변경 파일만 포함됩니다.
