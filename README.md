# 도깨비 운빨 수호대 3D

모바일 웹용 Three.js 3D 액션 운빨 디펜스입니다.

- 게임 버전: **1.9.0**
- 엔진 버전: **1.2.0**
- 배포 주소: `https://junl-im.github.io/Defense/`
- Firebase 프로젝트: `web-game2`

## 실행

```bash
npm ci
npm run verify
npm run dev
```

GitHub Pages 배포 빌드:

```bash
VITE_BASE_PATH=/Defense/ npm run build
```

## 조작

- PC 이동: W/A/S/D 또는 방향키
- PC 카메라: 마우스 드래그 회전, 휠 줌
- 모바일 이동: 가상 조이스틱 또는 지형 짧은 터치
- 모바일 카메라: 한 손가락 드래그 회전, 두 손가락 핀치 줌
- Space: 질주
- Q: 도깨비불 난무
- E: 소환
- R: 집중 명령
- F: 혼불 100%일 때 수호신 폭주
- F3: 엔진 통계 HUD

## v1.9.0 / 엔진 1.2.0

### 원정 난이도 3종

- 달빛 수호전: 기본 밸런스
- 월식 원정: 적 강화와 함께 보상·점수 증가
- 백귀 심연: 높은 정예 확률과 최고 점수 배율
- 선택한 모드는 로컬에 저장되며 시작 엽전, 방패, 적 능력, 보상, 점수, 혼불 획득량에 반영

### 웨이브 도전과 원정 유물

- 웨이브마다 무피해, 정예 사냥, 연속 처치, 엽전 회수, 스킬 피해, 질주 임무 중 하나 등장
- 도전 완료 시 엽전·점수·혼불 추가 획득
- 2·5·7·9웨이브 뒤에 12종 유물 중 3개를 제시하고 최대 4개까지 누적
- 화력, 경제, 소환, 기동, 방어, 폭주, 도전 보상 등 서로 다른 런 빌드 지원
- 유물, 계약, 축복이 같은 웨이브에 겹칠 때 순서대로 처리하는 보상 큐 적용

### 수호신 폭주

- 적 처치, 엽전 수집, 무결점 방어, 도전 완료로 혼불 충전
- 100%에서 F키 또는 수호신 버튼으로 발동
- 폭주 중 대장·수호대 피해와 기동 성능 강화
- 유물과 영구 성장으로 지속 시간, 위력, 시작 혼불 확장

### 전투 변주 확대

- 달의 징조를 5종에서 **8종**으로 확장
- 정예 속성을 4종에서 **7종**으로 확장
- 신규 결계 정예는 추가 보호막 보유
- 신규 파열 정예는 사망 시 경고 폭발과 기절 연출 발생
- 신규 고대 정예는 높은 체력·공격력·보상을 제공
- 정예 현상금 도전에서는 필요한 정예가 웨이브 안에 보장되도록 보정

### 영구 성장과 모바일 엔진

- 영구 성장에 이동 속도, 대박 기운, 시작 혼불 3종 추가
- 기존 3종과 합쳐 총 6개 성장 특성
- FPS 품질 단계에 맞춰 파티클 발생량을 자동으로 48~100% 사이에서 조절
- 320px 세로 화면에서도 질주·광역기·수호신·소환·웨이브 버튼이 겹치지 않는 5버튼 배치 적용
- 결과 화면에 원정 모드, 도전 완료, 유물, 수호신 폭주, 최대 연속 처치 통계 추가

## v1.8.0에서 유지되는 복구와 안정성

- 플레이어 생성 전 `player.group` 접근으로 발생하던 BOOT RECOVERY 오류 수정 유지
- 월드 생성 중 blob shadow·청크·애니메이션 접근을 `worldReady`로 보호
- WebGL 렌더러 생성 실패 시 기본 → 호환 → 저사양 3단계 재시도
- 적 풀 반환 전 사망 좌표 보존, 플레이어 공격 애니메이션 참조, 컨트롤러 수명 정리 유지

## 모바일 엔진 원칙

- 실시간 그림자 비활성화, InstancedMesh blob 그림자 사용
- 도깨비 300 triangles, 일반 적 500 triangles 이하
- 바위·등불·상점·소환 발판 InstancedMesh
- 파티클·투사체·엽전·적 모델 ObjectPool
- 거리 기반 LOD와 월드 청크 가시성
- SVG 금지, GLB/GLTF 및 PNG/WebP/KTX2만 허용
- Firebase는 게임 루프에서 호출하지 않고 결과 저장 시에만 사용
