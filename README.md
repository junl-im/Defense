이번 패치의 264프레임은 실제 런타임에서 사용하는 P0 제작본입니다. 그러나 모든 캐릭터와 모션의 최종 상업 원화 승인을 의미하지는 않습니다.

- P0 런타임 적용: `true`

- 전체 최종 아트: 단계적 교체 중
