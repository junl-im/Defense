# Kingdom Seed v2.4 - Modern Design & Performance Polish

이번 패치는 콘텐츠 확장보다 실제 플레이 화면의 완성도를 올리는 대규모 비주얼/UX/성능 패치입니다.

## 핵심 변경

- PC 전체화면 개입 제거 강화
  - PC에서는 시작 게이트 없이 바로 게임 화면 표시
  - PC에서는 전체화면 복구 이벤트 미동작
  - 모바일에서만 전체화면/가로모드 보조 로직 유지

- HUD 재설계
  - 상단 정보판을 Life / Gold / Wave / Battlefield로 분리
  - 스테이지명이 버튼 영역과 겹치지 않도록 폭과 위치 재조정
  - 사운드 버튼을 ON/OFF 텍스트형으로 변경
  - 조기 웨이브 대신 NEXT 버튼 + 자동 출격 카운트다운 표시

- 웨이브 UX 정리
  - 기본 10초 후 자동 진행 유지
  - 수동 진행 시 “선제 출격 보너스” 지급
  - 버튼명은 `NEXT 10`, `NEXT 9`, `전투중`, `완료`로 상태가 명확하게 보이도록 변경

- 건설지 디테일 개선
  - 건설지 hover 시 프리미엄 링/라벨 표시
  - 타워 건설 메뉴의 역할/가격 안내 유지
  - 시각적으로 “여기서 건설한다”는 느낌 강화

- 2.5D 비주얼 리워크
  - 8개 전투 배경 재생성
  - 전체 몬스터 스프라이트 2.5D 느낌으로 재생성
  - 타워 Lv.1~3 외형 재생성
  - HUD top/bottom 패널 재생성
  - 전장 코너 프레임, 비네트, 부유 파티클 추가

## 적용 방법

`kingdom-seed-v2.4-patch` 폴더의 내용을 기존 프로젝트 루트에 덮어쓰기합니다.

```bash
npm run build
```

성공하면 GitHub Desktop에서 커밋/푸시합니다.

```txt
Summary: Add v2.4 modern design and performance polish
```

배포 확인:

```txt
https://junl-im.github.io/Defense/?v=240
```

## 주의

v2.4는 v2.3.1 빌드픽스 이후 상태를 기준으로 합니다.
빌드 에러가 나오면 캡처를 보내면 해당 파일만 빠르게 수정하면 됩니다.
