# Kingdom Seed v2.5 Wave Flow + Visual Remaster Patch

## 핵심 수정

- 첫 웨이브는 더 이상 자동 카운트하지 않습니다. 플레이어가 `전투 시작`을 눌러 시작합니다.
- 웨이브 진행 중에는 다음 웨이브 카운트가 절대 돌지 않습니다.
- 웨이브 몬스터가 모두 스폰되고 모두 정리된 뒤에만 `진행 10` 카운트가 시작됩니다.
- 카운트 표시는 상단 버튼 한 곳으로 통합했습니다. WAVE 정보판에는 현재 웨이브/총 웨이브만 표시됩니다.
- 스폰 대기 중인 몬스터가 남아 있을 때 웨이브가 끝난 것으로 판정되는 문제를 방지했습니다.
- 사망 중인 몬스터 보상이 여러 번 들어갈 수 있는 조건을 차단했습니다.

## UX/문구 변경

- `NEXT` 중심 문구를 제거하고 `전투 시작` / `진행 10` / `진행중` / `완료`로 정리했습니다.
- 수동 진행 보상은 `선제 출격 보너스`로 유지하되, 첫 웨이브 시작에는 보너스를 주지 않습니다.
- 빈 건설지는 `건설 가능` / `타워 선택` 라벨로 바뀌었습니다.
- 건설 메뉴 제목을 `방어 시설 선택`으로 변경했습니다.

## 디자인 리마스터

- 8개 전투 배경 이미지를 다시 생성했습니다.
- 몬스터 스프라이트 31종을 새로 생성했습니다.
- 타워 Lv.1~3 이미지를 새로 생성했습니다.
- HUD 상단/하단 패널을 다시 생성했습니다.
- 전체 방향은 2.5D 보드게임/프리미엄 모바일 디펜스 느낌입니다.
