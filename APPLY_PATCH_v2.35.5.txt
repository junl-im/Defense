KingdomSeed v2.35.5 Fast Shell Engine Split Patch

목표
- 첫 접속 때 1.4MB급 Phaser 초기 번들이 HTML 첫 화면을 막지 않도록 분리합니다.
- 정적 HTML 시작 게이트와 초소형 main.ts를 먼저 표시하고, Phaser/BootScene은 첫 페인트 이후 유휴 시간 또는 사용자 탭 시 동적 로드합니다.

적용 방법
1. 이 zip의 내용을 기존 프로젝트 루트에 그대로 덮어씁니다.
2. node_modules, dist, .git은 포함되어 있지 않습니다.
3. 적용 후 npm install이 이미 되어 있다면 npm run build로 검증합니다.

검증
- npm run build 통과
- v2.35.4: 초기 index JS 약 1.46MB
- v2.35.5: 초기 index JS 약 16.46KB
- Phaser는 별도 phaser.esm 청크로 분리되어 첫 HTML 표시를 막지 않습니다.

새 URL 옵션
- ?tapboot 또는 ?coldboot: 데이터 절약/초저속 검수용. 탭하기 전까지 엔진 청크를 불러오지 않습니다.
- ?autostart: 디버그용 자동 엔진 시작.
