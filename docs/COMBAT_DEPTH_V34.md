# v3.4 Combat Depth Design

## 목표

전투가 단순히 웨이브를 막는 것에서 끝나지 않고, 매 판마다 조금 더 잘하고 싶게 만드는 평가 구조를 추가한다.

## 신규 전투 목표

- 생명력 75% 이상 보존
- 무누수 클리어
- 연속 처치 20 달성
- 빠른 클리어

## 콤보 시스템

짧은 시간 안에 적을 연속 처치하면 콤보가 증가한다. 콤보가 10 이상이면 소량의 골드 보너스를 지급한다.

이 시스템은 타워 배치의 광역 화력 설계와 병영 길막 설계를 자연스럽게 유도한다.

## 전술 힌트

웨이브 시작 시 다음 공세 구성을 분석해 간단한 대응 힌트를 보여준다.

- 공중 적: 궁수/마법 타워 추천
- 장갑 적: 마법사/저주 계열 추천
- 마법 저항: 포탑/궁수 추천
- 보스: 긴급 강화/최종 진화 스킬 추천
