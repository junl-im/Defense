# v2.4 Design Direction

## 목표

“웹게임처럼 보이지 않는 모바일/PC 대응 미드코어 디펜스”를 목표로 전투 화면을 재정리했습니다.

## UI 원칙

1. 상단 정보는 겹치지 않게 작은 모듈로 분리
2. 웨이브 진행은 자동 10초 + 수동 NEXT 보너스
3. 건설지는 항상 플레이어가 인식 가능해야 함
4. 이펙트는 고급스럽게 보이되 성능 예산 안에서만 출력
5. PC는 브라우저 창 플레이, 모바일은 가로 전장 몰입

## 다음 후보

- 타워 건설 메뉴를 실제 에셋 버튼으로 교체
- 몬스터 사망 애니메이션을 종류별로 더 세분화
- 스테이지별 특수 환경 오브젝트 추가
- 전투 결과 화면 3별 연출 강화
