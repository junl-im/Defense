# Quiet Screen v23.0.0

## 목표

모바일 전투 화면에서 버튼과 정보가 서로 경쟁하지 않도록 HUD 구조를 예약 영역 기반으로 재설계한다.

## 제거

- 화면 카메라 확대 버튼
- 화면 카메라 축소 버튼
- 관련 DOM 참조와 클릭 핸들러
- 모바일 HUD의 줌 버튼 점유 영역

휠과 두 손가락 핀치 줌은 유지한다.

## 세 개의 예약 영역

1. 상단 정보 영역: 신목 체력, 엽전, 웨이브, 보스 체력
2. 하단 조작 영역: 조이스틱과 전투 액션 버튼
3. 중앙 컨텍스트 영역: 진행 복구, 다음 웨이브, 상호작용, 위험 경고

## 컨텍스트 우선순위

1. 진행 복구
2. 다음 웨이브
3. 상호작용
4. 위험 경고

모바일에서는 가장 높은 우선순위 한 개만 노출한다. 데스크톱에서는 기존 동시 표시를 유지한다.

## 모바일 프로필

- 320/360px 초소형
- 390/430px 일반 모바일
- 760px 와이드 모바일
- 667x375, 844x390 가로 화면
- 높이 620px 이하 단축 화면

## 검증

- DOM에서 줌 버튼 0개
- 휠·핀치 줌 계약 유지
- 7개 대표 화면 크기 예약 영역 시뮬레이션 통과
- 실제 DOM 겹침 검사 및 비상 레이아웃 계약
