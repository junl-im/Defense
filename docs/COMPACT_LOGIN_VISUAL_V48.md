# Kingdom Seed v4.8 Compact Login + Visual Polish

첫 로그인 화면을 너무 크게 보이지 않도록 아담한 프리미엄 레이아웃으로 재정리한 패치입니다.

## 변경점

- 로그인 패널을 458x344급에서 382x276급 체감 크기로 축소
- 로고 표시 크기 축소 및 화면 상단 여백 확보
- 빠른 시작 / Google / 이메일 / 가입 버튼을 더 간결한 배치로 정리
- 상단 공지/문의/설정 칩을 작은 크기로 변경
- 하단 안내 바를 슬림하게 변경
- 모바일 시작 게이트와 종료 확인창도 작은 카드형으로 축소
- 뒤로가기 팝업 오작동 방지를 위해 초기 진입/터치 직후 suppression 시간을 확대
