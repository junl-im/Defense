# Mobile HUD Resilience — v1.0.34

## 목표

v1.0.33 터치 HUD 핫픽스가 정적 DOM과 기본 화면 크기에서만 통과하던 범위를 넘어, 늦게 생성되는 UI·가상 키보드·노치·가로 오프셋·빠른 레이아웃 변동에서도 안정적으로 복구되게 한다.

## 런타임 개선

- HUD 대상이 교체되거나 뒤늦게 생성되면 `MutationObserver`가 대상 목록을 다시 만들고 `ResizeObserver`와 속성 감시를 재연결한다.
- `visualViewport`의 `width`, `height`, `offsetLeft`, `offsetTop`을 기준으로 좌우·상하 가시 영역을 계산한다.
- 가상 키보드로 줄어든 하단 가시 영역을 컨트롤·문맥 레인 하단 여백에 반영한다.
- 겹침이 사라진 뒤 3회 연속 안정 프레임을 확인한 후 비상 레이아웃을 해제한다.
- 우선순위에서 밀린 문맥 패널은 `aria-hidden="true"`를 적용하고 다시 활성화될 때 원래 값을 복원한다.

## 터치·키보드 접근성

- 주요 전투 버튼 최소 높이: 44px
- 터치 동작: `touch-action: manipulation`
- 키보드 탐색: 고대비 `:focus-visible` 외곽선
- 가상 키보드 활성 시 보스 상세·위험 요약의 비필수 정보를 접어 전투 조작 공간을 확보

## 검증 프로필

- 320×568, 360×640
- 390×844 노치, 430×932 노치
- 760×1024 모바일 와이드
- 390×844 및 430×932 가상 키보드 축소
- 667×375, 800×390 가로 화면
- 800×390 레이아웃 내 756px 가시 뷰포트 좌우 오프셋

총 10개 프로필에서 핵심 HUD 겹침과 가시 영역 이탈이 없어야 한다.
