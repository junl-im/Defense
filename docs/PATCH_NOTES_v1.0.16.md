# v1.0.16 전체 맵 터치 이동 패치

기준 버전은 **v1.0.15 / b24.15**이며 적용 후 **v1.0.16 / b24.16**이 됩니다.

## 수정 내용

- 모바일 전투 입력 영역에서 화면 왼쪽 34%를 제외하던 CSS 제거
- 세로·가로 모바일, 태블릿, PC에서 좌·중·우 맵 바닥 전체를 터치 이동 영역으로 통일
- 조이스틱·스킬 버튼·HUD는 기존 높은 레이어를 유지해 오동작 방지
- 모달 또는 비전투 화면에서는 맵 터치 입력 자동 차단
- 포인터 취소와 캡처 손실이 이동 명령으로 잘못 처리되지 않도록 수정
- 좌·중·우 입력 횟수와 마지막 NDC 좌표를 런타임 진단값으로 기록

브라우저 콘솔에서 `window.__DOKKAEBI_MAP_TOUCH_V116__`으로 입력 진단을 확인할 수 있습니다.
