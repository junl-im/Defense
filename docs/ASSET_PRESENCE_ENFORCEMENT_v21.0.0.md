# v21.0.0 Asset Presence Enforcement

## 목표

v13~v20에서 등록한 2D 에셋이 단순히 파일로 존재하는 상태를 넘어 실제 타이틀, 직업 선택, 전투 HUD, 스킬 버튼, 장비, 도감, 전장 빌보드에 연결되었는지 런타임에서 추적한다.

## 신규 시스템

- `src/runtime/asset-presence-enforcer.js`
  - 아틀라스 DOM 사용량과 실제 표시 수 추적
  - 타이틀 마스코트·배경·영웅 초상·직업 카드·액션 아이콘 필수 계약
  - 질주·대장 기술·수호신·소환·웨이브·상호작용 6개 버튼에 v15 아틀라스 프레임 강제 연결
  - 화면에 없는 필수 에셋과 전투 효과 공백을 경고로 기록
- `src/runtime/mobile-hud-director-v21.js`
  - 전화·좁은 전화·짧은 화면·가로 전화 프로필 분리
  - HUD·보스 게이지·위험 안내·조이스틱·액션 도크의 실제 충돌 검사
  - 겹침 발생 시 비필수 레일을 자동 축소하는 비상 레이아웃
- `src/combat/combat-readability-director-v21.js`
  - 일반·정예·보스 적의 바닥 실루엣 링
  - 주술 요괴 공격 원점에서 목표 지점까지 위협 추적선
  - 전투 가독성 예산과 활성 효과 수 진단

## 시각 변경

- 접속 화면 PC·모바일 배경과 도깨비 마스코트 캐시 키를 v21로 갱신
- 접속 화면에 10웨이브·5직업·모바일 최적화 정보를 짧은 배지로 표시
- 고립된 한자 아이콘을 정적 HTML에서 제거하고 한국어 UI 가드를 유지
- 적 돌진 예고선 폭·불투명도 강화
- 적 장판 외곽선과 중심 채움 강화
- 액션 버튼에 실제 아틀라스 VFX·UI 프레임 표시

## 승인 경계

- 런타임 에셋 연결과 최종 3D 제작 승인은 별도다.
- 기존 19개 GLB와 154프레임 아틀라스를 사용한다.
- 최종 제작 아트는 0/6이며 1,130개 대량 생산 잠금은 유지한다.
