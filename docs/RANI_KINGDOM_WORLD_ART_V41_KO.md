# 라니킹덤 v4.1 — 기존 승인 월드 이미지의 정확한 선택·회전·복구

## 원칙
- v4.0 `main` 및 #35 모바일 핫픽스(전수 CI/배포 통과)를 기반으로 한다.
- SVG/합성 전체 시안/신규 가짜 건물 없음. 기존 자산 16개 SHA1 체크를 수정하지 않는다.
- 저장 포맷, 자원 경제, 건설 완료/취소, 진영, 세력, 마을/필드 레이어 원본은 그대로 둔다.
- 아직 승인된 실제 월드용 이미지는 시장·무역선 2종뿐이고, 주택 그림은 마을 메뉴에만 사용한다.

## 실제 코드 개선
1. `RaniV4WorldArt.js`의 이미지 버튼에서 실제 `rec.visual.group` 월드 좌표와 `rec.id`를 `Selection.select(cell,anchor,buildingId)`로 전달한다. 육각 타일 내 시설 여러 개가 있을 때 올바른 시설 메뉴를 띄운다.
2. 이미지 크기를 월드 X축이 아닌 **현재 카메라의 우측 기준 벡터**로 투영해 Q/E 회전에 따라 갑자기 찌그러지는 폭을 방지한다.
3. JS에서 모바일 155px, PC 200px 최대 폭을 CSS와 일치시켜 계산된 중심과 실제 렌더링 이미지의 위치 차이를 줄인다.
4. 화면 범위를 벗어나 이미지가 숨으면 원래 3D 건물 모델을 즉시 복구한다. 시야로 돌아오면 다시 승인된 이미지를 사용한다.
5. 같은 화면에 시설이 겹칠 때는 화면 Y가 아니라 **카메라에서의 거리**로 앞뒤 순서를 판단한다. 자산 실패 시 원본 3D 모델 복구는 v4.0대로 유지한다.

## 검증
- `scripts/check-v4-art-directed.mjs`: 원본 선택·회전·복구·크기 보호 조건 강화.
- `scripts/qa_v4_art_direction.py`: PC 1440/1024·모바일 390/320에서 인게임 실월드 앵커·건물 ID 선택, 강제 시야 밖 이동 시 모델 복구, 재진입 시 승인 그림, 화면폭 제한 확인.
- 기존 v0.1~v4.0 정적 검증 및 레거시 브라우저 QA 전부 유지.
- CI가 모두 성공하기 전에는 main 병합/배포 완료로 표기하지 않는다.

## 후속 아트 작업
- 이 패치는 신규 궁전·폭포·도시 고해상도 에셋을 만든 것이 아니다. 건물별 독립 PNG/WebP를 새로 확보하고, 구조적 자산 연결·광원/깊이/높낮이를 월드에 일치시키는 작업은 별도 진행해야 한다.
