# 라니킹덤 v1.6 — 첫 실행 화면 게임 이미지 타이틀 적용

## 핵심 산출물
- `assets/branding/rani-kingdom-logo.webp` — 이미지 생성기로 제작한 **한국어 라니킹덤 황금 왕국 엠블럼**을 원본 PNG에서 720×240 투명 WebP로 최적화한 브랜딩 자산. 초기 로딩에 부담을 주지 않도록 약 30KB로 압축.
- `index.html` 첫 화면의 텍스트 `<h1>라니킹덤</h1>`를 실제 `<img alt="라니킹덤">`로 변경. URL을 preload하며 제목은 접근성용 대체 텍스트로 계속 제공. 자산을 불러오지 못할 때에만 한국어 텍스트를 화면에 표시.
- `css/rani-branding.css`는 첫 화면 로고와 한국어 로딩 진행률만 처리하는 독립 스타일. 왕국을 연상시키는 녹색·금색 톤, 화면별 자동 축소, 320px 세로 소형/390px 모바일/844px 가로/1440px PC의 이미지 잘림 방지. 애니메이션 축소 모드 지원.
- `src/main.js`는 게임 자체를 즉시 실행하면서 첫 로딩 이미지는 최소 약 900ms 확인 가능하도록 하고, 자바스크립트 예외 발생 시 그림이 남은 상태에서 **한국어 오류를 안전한 textContent**로 표시.
- 게임 내 기존 자원 HUD·점수·관리 탭·마을 필드·건축·경제·저장 시스템에는 변경 없음.

## 품질 검증
- `scripts/check-branding.mjs`: WebP 파일 실체·헤더/경량 용량, HTML에서 이미지 사용, 대체 텍스트·한국어 진행률, 반응형 스타일, 오류 처리 코드 확인.
- `scripts/qa_branding.py`: Chromium에서 실제 이미지 픽셀 크기, 가로/세로 중앙 정렬·잘림 여부를 PC·모바일·소형모바일·가로 화면별 검사하고 캡처. 또한 로고 화면이 사라진 후에도 기존 3D 마을·게임 HUD가 정상 시작되는지 점검.
- `npm test`와 GitHub Actions 원본 전체 게임 QA 유지. 새 화면이 동작해도 기존 저장/전투/건축 로직을 임의 변경하지 않음.

## 제한·후속 개선
- 첫 시작 화면을 새로운 별도 게임 메뉴로 바꾸지 않음. 기존 빠른 자동 진입 구조 유지.
- GitHub Pages 실제 CDN 반영 및 각 물리적 Android/iOS 브라우저에서의 렌더링 확인은 자동화 검증과 별도.
- 원본 고해상도 PNG 이미지는 GitHub의 최적화 배포 파일과 구별하여 보관. **로고 자산과 폰트 파일 혼합/배포는 하지 않음.**
