# v1.0.17 패치 노트 — Art Approval & Directional Golden Sample

## 핵심 변경

- 푸푸도깨비 수호대 1종에 실제 11방향 원화 턴테이블을 런타임 적용했습니다.
- 대기 방향 원화 11개는 `direction-approved`로 승인했습니다.
- 이동·공격·스킬·피격·사망 5개 행은 방향 원화에서 파생한 임시 연출입니다. 최종 독립 액션 원화로 계산하지 않습니다.
- 수호성 안정·보호막·균열·위기 4상태 이미지를 새 디자인으로 교체했습니다.
- 기존 v1.0.12 자동 생성 P0 방향 시트 4종은 계속 격리하며 런타임에서 사용하지 않습니다.
- 승인·수정·교체 대기·격리 상태를 확인하는 `asset-approval-v117.html` 자산 관리 화면을 추가했습니다.
- 새 방향 자산이 준비되지 않거나 로딩이 늦으면 기존 승인 정적 원화로 자동 복구합니다.
