# v1.0.24 Identity Lock & Runtime Assurance

## 수정
- PWA manifest에 남아 있던 `도깨비 운빨 수호대 3D` 이름 제거
- 접속·설치·브라우저 제목을 `도깨비 럭 디펜스 3D`로 통일
- 타이틀 워드마크를 `도깨비 / 럭 디펜스 / 3D` 구조로 정리
- 원조 v112 푸른 도깨비 마스코트 고정
- 구형 서비스 워커 캐시 접두사까지 제거하는 마이그레이션 추가
- 부팅 스크립트의 중복 캐시 버전 조건 제거
- 프로젝트 루트에 남은 `README_PATCH.txt`를 검증 전에 `logs/legacy-root-output/`으로 자동 이동
- 반복 실행 시 동일한 레거시 패치 안내 파일을 중복 생성하지 않고 정리
- 이전 원클릭 패치가 루트에 남긴 `PATCH_APPLIED_v*.txt`와 `PATCH_MANIFEST_v*.json`도 자동 정리

- idle, move, attack, skill, hit, death 상태 행 연결량 기록
