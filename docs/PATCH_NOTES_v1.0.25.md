# v1.0.25 Action Asset Assurance

## 전투 액션
- 주인공 공격·기술·피격 상태의 최소 유지 시간 추가
- 액션 중 대기/이동 상태가 한 프레임 끼어드는 현상 완화
- 사망 상태는 다른 상태로 되돌아가지 않도록 잠금
- 11방향 × 6개 상태 사용량 계수 추가

## 자산 승인
- 푸푸도깨비 방향 원화 최종 승인 유지
- 액션 런타임 매핑 승인 유지
- 독립 액션 원화는 파생 임시 승인으로 유지
- 장난 요괴 폭탄병 후보는 교체 대기·런타임 격리

## UI
- 전투 결과 화면의 통계·보상·버튼 구조 시각 통일
- 달빛 도감과 3D 미리보기 패널 디자인 보강
- 모바일 세로·가로와 PC 해상도별 HUD 충돌 프로필 기록

## 장시간 검증
- 웨이브별 비주얼 레코드·파티클·투사체 스냅샷
- 10웨이브 목표 도달과 리소스 잔여량 진단
- 사망 잔상·전투 비주얼 해제 횟수 기록
