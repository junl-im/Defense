# 라니킹덤 v1.9 — 실제 Three.js 마을/농경지/성채 그래픽 1차 업그레이드

## 고정 아트 방향
사용자가 확정한 첨부 참고 이미지의 **2.5D 쿼터뷰·파란 지붕 성채·황금 문장·따뜻한 석조 보도·노란 밀밭**을 실물 게임 지형에 점진 적용한다. 글자나 메뉴만 바꾸는 모형 그래픽으로 대체하지 않는다. 기존 Three.js 육각 공간, 건축·경제·전투·세이브가 기준이다.

## 실제 개선
- **신규 Three.js 기하 모듈** `src/rendering/RoyalWorldArt.js`. 기존 모듈의 `part`/`merge`/vertex-color 공유 재질을 사용하므로 마을/농지 각각 장식이 1개 메시/1 draw call. SVG·가짜 캔버스 이미지/임시 DOM 오버레이가 아니다.
- 시작 마을/모든 마을 타일에 약 60개 석조 포장 부품을 씨드 기반으로 단정한 구획으로 배치하고 높은 중심 성채 주변 보도를 구별. 중앙 시설/성문 입구는 포장하지 않아 기존 클릭·건축물과 겹치지 않도록 설계.
- 모든 농경지 타일에 기존 갈색 고랑 외에 약 40~44개 실제 3D 황금색 이삭/줄기와 토양 띠 추가. 건축 중심부는 비워두어 건설 및 바닥 클릭에 영향 최소화.
- `BuildingFactory.makeCastle` 및 `makeCastleB` 두 성채 변종에 약 1개 병합 메시로 왕실 금장 테두리·황금 첨탑·왕국 문장 방패·작은 빛나는 창호 추가. 기존 4개 건설 단계 중 **4단계 완성 시에만** 장식이 나타나도록 적용. B의 석판 회색 지붕을 채도 높은 푸른 지붕으로 교체. `Materials.js`에서 청색 지붕/푸른 왕실 포인트와 보도/황금 밀밭 색상을 일관화.
- `TileFactory.placeCell`의 정식 타일 장면과 `setGhostTile`의 반투명 건축 예정 타일 **양쪽에 같은 3D 장식 사용**, 사용자 확정 건물 중심 육각 선택과 땅 조준 정보는 계속 원래 타일 그룹을 대상으로 동작.
- 각 타일은 저장된 `seed`를 사용해 결정적 배치. 서버·네트워크·`localStorage` 왕국 저장 구조/건축 자원 수치에는 **변경 없음**. 타일 제거·게임 재시작에서 새 메시도 기존 TileFactory.dispose 경로로 청소됨.

## 자동화 회귀
- `check-royal-world-v19.mjs`: 실제 Three.js 코드와 4단계 건축·조립 메쉬/미리보기·메뉴/세이브 불변 경로 검사.
- `qa_royal_world_v19.py`: PC/390px/320px Chromium의 초기 마을 실제 포장 메시, 3D 농지 작물 메시, 성채 2가지 4단계·금색 장식, 1타일당 장식 1메시, 건설 미리보기, 저장→새로고침 후 마을 복원, 콘솔 예외 여부 확인 및 스크린샷.
- 기존 `npm test`·원본 유닛/게임 로직·육각 터치·소형 기기 HUD·드래그 위치·건설·경제·세이브·세력 3D 필드 회귀 검사 전체 유지.

## 한계
실제 3D 월드의 일부 랜드마크와 농지/마을 지형 표현 **1차 개선**이다. 참고 이미지의 건물 수·파란 지붕 궁전 밀도·항구/바다/길/사람/성벽 전체를 그대로 재현하거나 외부 고해상도 에셋을 대량 확보한 것으로 주장하지 않는다. 전체 월드 아트 전면 작업은 후속 개발 대상이다. 물리적 Android/iOS GPU 테스트 및 GitHub Pages CDN 적용은 별도 점검 필요.
