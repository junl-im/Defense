# v16.0.0 덮어쓰기 패치 적용

기준 프로젝트:

`DokkaebiLuckDefense3D_FULL_v15.0.0`

## 적용

1. 기존 프로젝트를 백업한다.
2. v16 덮어쓰기 ZIP을 프로젝트 루트에 푼다.
3. 동일 파일을 모두 덮어쓴다.
4. 다음 검증을 실행한다.

```bash
npm run verify
npm run build:static
node scripts/verify-static-dist.mjs
```

## 브라우저 캐시

서비스 워커와 아틀라스 캐시 키가 v16으로 변경됐다. 이전 화면이 남으면 브라우저에서 한 번 강력 새로고침하거나 사이트 데이터를 지운다.

## 확인 지점

- 첫 화면에 패치·엔진·아틀라스 정보가 보이지 않는지
- `원정 설정`과 `보관함` 모달이 열리는지
- 전투 HUD 왼쪽에 선택 영웅 초상이 표시되는지
- 중앙 수호성 근처에서도 카메라가 Scenic 최소 거리 아래로 급격히 당겨지지 않는지
- 수호성이 캐릭터를 가리면 반투명해지는지
- 전장 중앙권에서 등불·문·제단·수정 스프라이트가 보이는지
