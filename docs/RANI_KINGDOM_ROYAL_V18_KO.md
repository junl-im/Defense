# 라니킹덤 v1.8 — 황금 왕국풍 UI 1차 실적용

## 확정된 이미지 콘셉트
사용자가 직접 선택한 2.5D 쿼터뷰 판타지 왕국 화면의 시각 언어를 **PC·모바일 공통 고정 아트 디렉션**으로 기록한다.

- 깊은 녹청색(숲녹색) 인셋 패널, 검은 목재/갈색 옻칠 프레임, 따뜻한 금장 테두리 및 강조, 밝은 아이보리 글씨
- 성·영지·시장·농지·성벽·항구의 풍부한 레이어와 중세 판타지 2.5D 입체 건축물
- 리소스 최상단, 게임 정보 카드 상단 정돈, 주요 기능 하단 액션 바, 상태에 따라 접히는 모바일 화면
- **최종 게임 그래픽 전체 달성 상태가 아니라, HUD/UI 스킨의 실제 1차 구현**임을 명확히 구분한다.

## 실제 개발
1. `css/rani-royal-v18.css`: 가장 나중에 로드하여 원래 CSS·경제/저장 로직과 분리. 자원 HUD·인구/안정도·점수·연구·주변 세력·영토 확장·퀘스트·건축·육각 링·마을/필드 정보창의 배경/프레임/버튼/포커스 상태를 금장·목재 스타일로 통일. 각 기능의 원본 클릭·진행률 이벤트를 그대로 사용.
2. `src/ui/RoyalLauncher.js`: **실제 게임에 연결된** PC 하단 7메뉴(마을/필드/영토/연구/세력/왕국/저장). 마을/필드는 기존 NativeVillageUI Three.js 장면 전환, 영토/연구/세력은 기존 UI 패널 접기/복구, 왕국은 기존 성장 및 영토 현황을 열기/닫기, 저장은 기존 Save Manager 버튼을 실행. 실제 기능을 추가하지 않은 가짜 카드 없음.
3. 모바일은 기존 5칸 하단 메뉴/한 손 터치 UX를 유지하면서 PC와 **동일 소재·색상·프레임 스타일** 적용. 320px 소형 폭에서 아이콘/텍스트 축소, 390px 모바일에서 상단 자원 HUD와 점수판 겹침 및 임무/필드 제목 겹침 방지.
4. v1.7의 **10개 위치 이동·저장·재접속 복원**과 `rani-hud-layout-v2`을 그대로 사용. `.rani-positioned` 클래스의 고정 좌표를 재정의하지 않음. 3D 마을, 3D 외부 필드, 기존 선택 원형 링/공사/경제·장비/로컬 저장 v3 불변.

## 검증 계획
- `node scripts/check-royal-v18.mjs`: CSS의 위치 및 이름, 메뉴 7개 실제 액션 이벤트, 게임 저장 함수 연결, 기존 HUD v1.7 로드 순서 검증.
- `scripts/qa_royal_v18.py`: 1440×900, 1024×768, 390×844, 320×700의 실제 브라우저에서 스타일 적용/7기능 링크/마을-필드 전환/모바일 5칸/게임 화면/콘솔 오류/스크린샷 확인.
- 기존 전체 CI(경제/저장/건축/아트/퀵터치/필드/마을/시작 타이틀/드래그 위치 저장/소형 모바일) 계속 적용.
- CI 통과한 경우에만 main 병합.

## 아직 남은 실제 작업
- 참고 이미지에 등장하는 고해상도 **원본 성/왕궁·항구·길·나무·NPC·건축 단계별 그래픽은 기존 3D 아트가 그대로이므로 추가 제작/확보 및 점진적 교체**가 필요하다.
- 아이콘 중 일부는 GameIcons.js의 이모지 폴백이며 참조 이미지 수준의 일관된 래스터 메달 아이콘으로 고도화할 후속 과제가 있다.
- GitHub Pages 최신 배포 및 물리적 스마트폰 터치/성능은 자동 Chromium QA와 별도 실기기 검증 대상.
