# WorldMap v1.4 Design Notes

## 목표

월드맵을 단순 스테이지 선택 화면이 아니라, 챕터를 넘기며 모험을 진행하는 화면처럼 보이게 만듭니다.

## 카드 구성

각 스테이지 카드는 다음 정보를 보여줍니다.

- Stage 번호
- 전장명
- 서브 타이틀
- 클리어 별
- 최고 점수
- 클리어 등급
- 보스 존재 여부

## 클리어 등급

| 별 | 등급 | 느낌 |
| --- | --- | --- |
| 0 | UNCLEARED | 미클리어 |
| 1 | CLEAR | 기본 클리어 |
| 2 | HEROIC | 우수 클리어 |
| 3 | LEGEND | 완벽 클리어 |

## 챕터 연출

스테이지 테마에 따라 챕터 제목과 안개 색상을 바꿉니다.

- forest: 숲의 입구
- canyon: 붉은 협곡
- swamp: 그림자 늪지
- fortress: 마왕의 관문

## 다음 단계

v1.5에서는 월드맵에 다음 요소를 추가하면 좋습니다.

- 챕터별 실제 배경 레이어 분리
- 잠금 해제 순간 지도 길이 밝아지는 연출
- 스테이지 최초 3별 달성 보상 팝업
- 보스 스테이지 진입 컷신
