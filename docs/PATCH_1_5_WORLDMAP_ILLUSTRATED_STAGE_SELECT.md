# v1.5.0 World Map Illustrated Stage Select

## 목표

로그인(v1.3)과 메인 메뉴(v1.4)에 맞춰 월드맵도 코드 드로잉 느낌을 제거하고, 제공된 고퀄리티 에셋 기준의 원화형 화면으로 전환했다.

## 변경 사항

- `package.json` 버전 `1.5.0` 갱신
- 신규 월드맵 원화형 배경 추가
  - `public/assets/backgrounds/worldmap_splash_v1_5.png`
- `WorldMapScene` 리마스터
  - 복잡한 코드 카드/패널/버튼 드로잉 제거
  - 원화형 월드맵 스플래시 이미지 중심 구조로 변경
  - 스테이지 노드, 챕터 슬롯, 시작 버튼, 하단 메뉴는 투명 클릭존으로 처리
  - 선택 스테이지 정보와 미리보기 이미지만 얇은 라이브 텍스트/이미지 레이어로 표시
  - 잠금 스테이지 안내 토스트 유지
- `BootScene` 신규 에셋 로드 추가

## 방향성

- 배경/패널/버튼은 최대한 베이크된 에셋으로 처리한다.
- 코드 UI는 클릭존, 상태 텍스트, 선택 마커처럼 반드시 동적으로 필요한 요소에만 사용한다.
- 다음 v1.6은 전투 화면 HUD와 타워 선택 패널을 동일한 원화형 에셋 구조로 전환한다.
