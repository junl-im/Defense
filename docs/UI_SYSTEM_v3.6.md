# Moonstone HUD UI System — v3.6

## 목표

모바일 320px부터 데스크톱까지 동일한 전투 정보를 유지하면서, HUD 카드들이 서로 독립적인 고정 좌표로 경쟁하지 않도록 한다. 핵심 전투 조작과 보스 의도는 절대 가리지 않고, 시드·설명·보조 진행도부터 축약한다.

## 레이어 구조

1. **Primary HUD** — 메뉴, 신목 HP, 웨이브, 엽전, 사운드
2. **Top Status Rail** — 원정 시드, 달의 징조, 달빛 방패
3. **Center Meter Rail** — 대박 기운, 수호신 혼불
4. **Boss Lane** — 보스 HP, 페이즈, 다음 공격 의도
5. **Left Insight Rail** — 웨이브 도전, 인연, 초행 임무
6. **Right Roster Rail** — 연속 처치, 유물, 수호대 목록
7. **Bottom Control Zone** — 조이스틱과 5개 액션 버튼

레이아웃은 `src/ui-layout-manager.js`가 한 번만 동적으로 마운트한다. 기존 게임 로직은 원래 DOM ID를 계속 사용하므로 시스템 기능과 UI 배치를 분리한다.

## 정보 밀도

- `auto`: 좁은 화면, 짧은 화면, 보스전에서 자동 간소화
- `full`: 설명과 보조 정보를 모두 표시
- `minimal`: 핵심 수치와 진행률만 표시

충돌 감사 결과가 1건 이상이면 `ui-overflow-safe`가 적용된다. 자동/간소 모드에서만 저우선 정보를 숨기며, HP·웨이브·보스 의도·액션 버튼은 숨기지 않는다.

## 모바일 예산

### 320×568 세로

- 조이스틱: 110px
- 액션 도크: 174px
- 좌우 여백: 5px씩
- 두 조작 영역 사이 안전 간격: 26px
- 액션 도크: 첫 줄 질주/도깨비불/수호신, 둘째 줄 소환/웨이브

### 상단 세로 순서

- Primary HUD 하단: 약 46px
- Top Status Rail: 57px
- Center Meter Rail: 105px
- Boss Lane: 143px
- Boss 활성 좌우 레일: 202px

## 시각 토큰

- 크림: `#fff5d7`
- 골드: `#ffc857`
- 청록: `#67e8f9`
- 보라: `#9b78ff`
- 위험 핑크: `#ff7598`
- 패널: 보라색이 섞인 어두운 반투명 표면
- 테두리: 1~2px 밝은 크림 계열
- 버튼: 상단 하이라이트 + 하단 깊이 그림자
- 모서리: 12 / 16 / 24px

얇은 유리 패널만 사용하는 MMORPG 스타일 대신, 두꺼운 실루엣과 높은 대비를 가진 캐주얼 모바일 게임 버튼 계층을 사용한다.

## 충돌 우선순위

반드시 유지:

1. 조이스틱·액션 버튼
2. 보스 HP·공격 의도
3. 신목 HP·웨이브·엽전
4. 웨이브 도전 핵심 진행도

먼저 축약:

1. 원정 시드의 설명
2. 달의 징조 상세 설명
3. 초행 임무 부가 문구
4. 유물 패널 제목
5. 시드 카드 전체

## 검증

`scripts/verify-ui-v360.mjs`가 다음을 검사한다.

- 4개 동적 레일 존재
- 런타임 충돌 감사기 존재
- 5개 버튼 데스크톱 단일 행
- 모바일 3+2 액션 도크
- 보스 전용 안전 위치
- 320px 조작 영역 수평 간격
- 상단 HUD, 상황 레일, 게이지, 보스 레인의 최소 간격
- 중복 보스 에셋 라벨 제거

Chromium 자동 캡처는 현재 검증 환경의 DBus/GPU 초기화 제한으로 완료되지 않았다. 실제 iOS/Android에서는 주소창 높이 변화, 노치 안전 영역, 긴 한국어 문자열, 왼손 배치까지 확인해야 한다.
