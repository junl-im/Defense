# Kingdom Seed v4.4 Premium UI Integration

v4.3에서 만든 사용자 레퍼런스 기반 에셋을 실제 첫 화면과 기존 키 체계에 연결하는 패치입니다.

## 핵심

- 새 타이틀 배경/로고를 MenuScene에서 더 적극적으로 사용
- 기존 씬이 쓰던 파일명에 v4.3 에셋을 alias로 연결
- 로그인 패널, 버튼, 상태 바, 월드맵 배경 키를 신규 톤으로 교체
- PremiumSkinV44 유틸 추가
- BootScene에 v4.3 전용 보조 키 로드 추가

## 적용 후 체감

- 첫 진입 화면이 레퍼런스처럼 밝은 애니메이션 왕국 판타지 톤으로 보임
- 기존 월드맵/전투 HUD도 새 에셋 alias 덕분에 자연스럽게 고급 톤으로 변경됨
- 다음 v4.5에서 타워 패널, 보상 상자, MonsterIntel까지 완전 연결하면 더 커짐
