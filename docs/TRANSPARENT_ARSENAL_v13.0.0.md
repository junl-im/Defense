# TRANSPARENT ARSENAL v13.0.0

## 목적

사용자가 제공한 10장의 에셋 시트를 개별 PNG로 분리하고 실제 게임 UI와 도감에 연결한다.

## 입력 상태

- 시트: 10장
- 해상도: 각 1254×1254
- 파일 형식: RGBA PNG
- 실제 알파: 전 픽셀 255
- 체크무늬: 투명 표시가 아니라 이미지에 구워진 배경

따라서 단순 격자 자르기가 아니라 밝은 무채색 배경의 테두리 연결 영역을 제거한 뒤 개체를 정규화했다.

## 결과

- 개별 크롭: 415개
- 직접 검수·런타임 연결: 42개
- 자동 사용 가능 포함: 124개
- 추가 검수 대기: 291개
- 원본 시트: 10개 보존
- 최종 3D 제작 승인: 0개

## 게임 적용 위치

- 시작 직업 선택 카드 5종
- 달빛 도감의 수호대·몬스터·보스·전장·VFX 초상
- 장비 가방 아이콘 9종
- 결과 화면 장비 보상
- Sprite Forge v13 리뷰 OS

## 사용 제한

이 결과물은 2D UI, 도감, 인벤토리, VFX 참조, 빌보드 후보로 사용할 수 있다. 단일 시점 2D 스프라이트이므로 최종 3D GLB, 리깅, 애니메이션, 턴어라운드 승인을 대신하지 않는다.
