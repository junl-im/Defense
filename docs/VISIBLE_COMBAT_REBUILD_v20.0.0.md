# v20.0.0 Visible Combat Rebuild

- 타이틀 마스코트와 PC/모바일 배경에 v20 캐시 키를 적용했습니다.
- 고립된 한자 아이콘을 한국어 UI용 이모지/기호로 런타임 치환합니다.
- 모바일 HUD에서 비필수 칩을 숨기고 조작 영역을 축소했습니다.
- 신목/보호성 크기를 0.78에서 0.62로 줄였습니다.
- 기본 Scenic 카메라 pitch를 0.73에서 0.86으로 올렸습니다.
- 투사체 크기, 링, 트레일 불투명도를 강화했습니다.
- 에셋 로딩 성공 여부를 `window.__DOKKAEBI_VISUAL_INTEGRATION__`에 기록합니다.
