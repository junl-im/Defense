# Kingdom Seed v1.1.0 - World Map Code UI Art Pass

## 목표
- v1.0.0에서 정리한 로그인/메인 메뉴 규칙을 월드맵까지 확장했습니다.
- 배경 이미지는 배경 역할만 하도록 별도 자산으로 분리하고, 월드맵 경로/노드/패널/버튼/카드는 Phaser 코드 UI로 다시 구성했습니다.

## 적용 내용
- `package.json` 버전: `1.1.0`
- 신규 배경 자산 추가
  - `public/assets/backgrounds/worldmap_background_v1_1.png`
- 월드맵 Scene 리마스터
  - 상단 로고/정보바를 코드 UI 패널로 정리
  - 스테이지 카드 프레임, 리본, 별, 잠금 상태를 코드 UI로 재구성
  - 배경 위 캠페인 루트와 스테이지 노드를 코드로 다시 그림
  - 우측 스테이지 정보 패널과 명예의 전당 패널을 코드 UI로 통일
  - 하단 메뉴 독을 v1 코드 UI 버튼으로 통일
- 로그인 버전 표기를 `v1.1.0 WORLD MAP ART PASS`로 갱신

## 구조 원칙
- 배경: 이미지 에셋
- 로고/버튼/패널/스테이지 카드/노드/경로: 코드 UI
- 장식 캐릭터/타워: 작은 데코 에셋으로만 사용

## 검증
- TypeScript 검사: `tsc --noEmit` 통과
