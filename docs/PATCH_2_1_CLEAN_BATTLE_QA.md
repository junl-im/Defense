# Kingdom Seed v2.1.0 - Clean Battle QA & FX Targeting Pass

## 목적
v2.0에서 전체 원화풍 비주얼은 올라갔지만, 일부 전투 배경에 HUD/타워/몬스터가 이미지에 박혀 보이는 문제가 있었다. v2.1은 전투 구간을 실제 플레이용 구조로 정리한다.

## 변경 사항

- 모바일 화면 보정 추가
  - `visualViewport` 기준으로 16:9 게임 표면 크기를 계산한다.
  - 세로 화면 회전 상태에서도 화면이 작은 띠처럼 보이지 않게 유지한다.
  - 기존처럼 강제 `fill`만 하지 않고, 게임 UI가 늘어나지 않도록 16:9 비율을 보존한다.

- 전투 배경 정리
  - v2.1 전투 배경 8종은 HUD/타워/몬스터가 박힌 스크린샷형 배경이 아니라, 플레이용 빈 전장 배경으로 교체했다.
  - 코드가 그리는 경로, 건설 지점, 타워, 몬스터, HUD가 배경과 겹치지 않게 분리했다.

- 전투 UI 에셋 정리
  - 상단 HUD와 하단 독에서 베이크된 숫자/텍스트가 보이지 않도록 클린 프레임으로 교체했다.
  - 동적 수치와 텍스트는 코드가 담당한다.

- 클릭존 / 터치 QA
  - 상단 HUD와 하단 스킬 독에 안전 입력 가드를 추가했다.
  - 빈 전장을 눌렀을 때만 영웅 이동, 스킬 시전, 메뉴 닫기가 동작하도록 보정했다.
  - `?hit=1` 디버그 모드에서 HUD safe zone / skill dock safe zone / build spot / card hit zone을 확인할 수 있다.

- 스킬 타겟팅 개선
  - 메테오/용병 소환 선택 시 조준 프리뷰 링을 표시한다.
  - HUD나 하단 독 위에는 스킬이 시전되지 않도록 막는다.
