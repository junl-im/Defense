# v1.0.20 Protagonist Directional & HUD Polish

## 수정 범위

- 시작·로딩 화면의 구형 마스코트를 승인된 푸푸도깨비 전면 원화로 교체
- 캐시 리비전을 `release-v120-b24-20`으로 갱신해 이전 이미지가 남지 않도록 조치
- 전사 주인공이 실제 전투에서 승인된 11방향 푸푸도깨비 아틀라스를 사용하도록 연결
- 주인공 방향 아틀라스를 첫 전투 전 필수 로딩 목록에 추가
- 월드 HP 바에 금속 테두리, 내부 셸, 보호막·브레이크 보조 레인, 상태 아이콘을 통합
- 상단 수호성 HP에 소형 상태 바와 안정·경고·위기 색상 적용
- PC 상단 HUD를 좌측·중앙·우측 3개 레인으로 고정
- 모바일 상단 HUD를 정보행과 웨이브행의 2단 구조로 분리
- 보스 HP, 시너지, 행운 게이지와 상단 HUD 간 최소 간격 보정

## 승인 경계

- 주인공 전사: 방향 원화 11방향 런타임 승인
- 공격·스킬·피격·사망 행: 기존 v1.0.17 파생 액션 임시 승인 유지
- 다른 영웅 직업: 기존 고품질 정적 원화를 유지하며 방향 원화 교체 대기
