# Atlas Dominion v14.0.0

## 목표

v13의 개별 PNG 요청을 줄이고, 사용 가능한 2D 에셋을 실제 게임 UI와 3D 전장에서 공유하는 런타임 아틀라스로 통합한다.

## 결과

- v13 소스 크롭: 415개 보존
- v14 마스터 대상: 128개
- 선별 별칭: 42개
- 아틀라스: 1페이지
- 페이지: 1024×512
- 그리드: 16×8
- 타일: 64×64
- 출력: PNG + lossless WebP
- 최종 3D 승인: 0

## 적용 영역

### UI

- 대장 깨비 직업 카드 5종
- 장비 아이콘 전체
- 도감 캐릭터·몬스터·환경·VFX 이미지

### 3D 전장

`BattlefieldSpriteDirector`가 동일한 WebP 아틀라스를 로드해 환경·VFX를 `THREE.Sprite`로 배치한다.

- 저사양: 최대 7개
- 일반 플레이: 최대 10개
- 타이틀 쇼케이스: 최대 12개
- VFX 빌보드: 제한적 additive blending
- 환경 빌보드: normal blending

### 카메라

`CameraDirectorV14`는 다음 값을 계산한다.

- 적 분산 반경
- 활성 적 수
- 보스 존재 여부
- 전투 압력
- 추가 시야 거리 최대 +2.4
- 초점 보간 가중치 최대 0.28

## 승인 정책

아틀라스 패킹은 요청 수와 런타임 메모리를 개선하는 기술 승인이다. 다음 항목을 의미하지 않는다.

- 최종 3D 모델 승인
- 턴어라운드 승인
- 리깅 승인
- 최종 애니메이션 승인
- 1,130개 생산 잠금 해제
