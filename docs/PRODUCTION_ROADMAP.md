# AAA 캐주얼 SD 3D 제작 로드맵

## Gate 0 — 스타일 잠금

- 절대 프롬프트
- 공용 얼굴·체형
- 손그림 Stylized PBR 재질
- 팔레트·실루엣·5방향 규격

## Gate 1 — 골든 주인공

도깨비 전사 1종을 6k~10k triangles, BaseColor/Normal/ORM, 리그, 7 AnimationClip으로 완성한다.

## Gate 2 — 적 3종

근접, 원거리, 보스 각 1종. 흑백 64px 실루엣과 공격 예고 자세를 승인한다.

## Gate 3 — 환경

바닥, 나무, 돌, 장터 건물의 8m 모듈 세트.

## Gate 4 — UI

공용 버튼, 아이콘, 패널, 상점, 강화, 소환, 도감.

## Gate 5 — VFX

불, 얼음, 바람, 바위, 혼령, 번개, 독, 회복의 공용 시트.

## Gate 6 — 대량 생산

카탈로그 목표: 캐릭터 50, 몬스터 50, 보스 20, 무기 100, UI 300, VFX 150, 환경 80.

v3.5.0에서 도깨비 전사 골든 샘플은 Skin·7개 AnimationClip·PBR Map·소켓 기술 조건을 통과했다. 현재 Gate 1은 아트 디렉터 실기기 리뷰 대기이며, 나머지 13종은 기술 프로토타입이다.


## v3.8.0 IP 제작 운영 레이어

장기 제작 기준은 `production/DokkaebiDefense`로 이동했다. 1,130개 시각 에셋 마스터리스트, 13개 제작 영역, 5대 기준 문서, 11개 시작 직업, 7개 스테이지를 P0~P3 우선순위로 관리한다. 기존 런타임 프로토타입과 기술 후보는 자동으로 제작 승인되지 않는다.
