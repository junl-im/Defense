# v3.2 Spell & Boss Arena FX Pipeline

## 목적
v3.1에서 몬스터 정보와 보스 컷인을 붙였다면, v3.2는 전투 중 플레이어가 누르는 핵심 액션의 손맛을 올리는 패치다.

## 신규 FX

### 메테오
1. 타겟 레티클 축소
2. 하늘에서 탄두 낙하
3. impact sheet 재생
4. 폭발 링 + 카메라 흔들림
5. 실제 피해 적용

### 용병 소환
1. 초록/청록 게이트 생성
2. holy gate sheet 재생
3. 용병 2명 등장

### 영웅 대지강타
1. earth stomp sheet 재생
2. 방사형 파편 튐
3. 짧은 카메라 흔들림

### 보스 아레나
1. 보스 웨이브 시작 시 화면 가장자리 오염 효과
2. 보스 지점 리프트 FX
3. 패턴 발동 시 배너 + 공략 힌트 표시
