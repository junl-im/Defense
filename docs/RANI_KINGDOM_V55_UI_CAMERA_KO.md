# 라니킹덤 v5.5 — 게임 시작 화면·카메라·건물 UI
- 처음 화면에서 Esc/로딩 설명과 개발자 링크, 배포용 하단 구버전·라이선스 링크 제거. 버전 v5.5만 작은 글씨로 표기.
- 원본·라이선스 파일 및 과거 게임 /legacy/는 보존하며 게임 내 Esc 메뉴의 게임 정보에서 접근 가능.
- 마우스로 끌 때 화면 세로 방향 반전 보정. 터치, 경계 이동, 휠 확대, 연속 건축 동작은 기존 시스템 유지.
- 육각 메뉴: 간결한 왕실 문양 색채, 상태 클릭/호버 감각, 실 HP 바, 모바일 표시 영역 보정과 정보 측면 배치.
- 실제 건설 메뉴: 버튼 간격, 시각 피드백, 가용 비용 한국어 표기, 원본 건물 설명 기반 동적 정보 패널.
- QA: 첫 화면, 실 월드 마우스 입력, 생존 건물 HP 정보, 실 건설 카테고리/저장/레거시/SVG 없음 검증.
- 별도 원본 왕궁·항구·배 신규 아트는 이번 패치에 포함되지 않음.
