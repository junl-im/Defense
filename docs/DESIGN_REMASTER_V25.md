# v2.5 Design Remaster Notes

## 웨이브 플로우

기존 문제는 `waveRunning && enemies.length === 0`만으로 웨이브 종료를 판단한 점입니다. 몬스터가 시간차로 스폰되는 동안에도 `enemies.length`가 순간적으로 0이 될 수 있으므로, 다음 웨이브 카운트가 전투 중에 시작될 수 있었습니다.

v2.5는 `pendingWaveSpawns`를 추가해 아직 예약 스폰이 남아 있으면 웨이브를 종료하지 않습니다.

## 표시 정책

- WAVE 패널: `현재/총`만 표시
- 진행 버튼: 시작/진행중/카운트/완료 표시
- 자동 진행: 첫 웨이브가 아니라, 클리어 후 다음 웨이브에만 적용

## 디자인 정책

- 전투 배경은 실제 경로와 겹치지 않는 지형 레이어로 유지
- 경로는 Phaser에서 stage.path 기준으로 다시 그려 가독성을 보장
- 타워/몬스터는 작은 캔버스에서도 그림자와 하이라이트를 넣어 2.5D 느낌 강화
- HUD는 정보판과 조작 버튼을 더 명확히 분리
