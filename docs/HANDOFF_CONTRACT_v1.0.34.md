# Handoff Contract — v1.0.34

## 완료 조건

릴리스는 코드 검증만으로 완료되지 않는다. 다음 조건을 모두 만족해야 한다.

1. `PROJECT_HANDOFF.md`의 현재 버전·빌드·프로젝트명이 실제 산출물과 일치한다.
2. `절대 규칙`에 결과 보고 형식, 통파일·패치 ZIP 두 개 제공, 다음 패치 예정 라인이 기록되어 있다.
3. `인수인계 내역 작성 필수` 문구와 버전별 `인수인계 내역`이 존재한다.
4. 인수인계 내역에 변경 파일, 검증 결과, 잔여 위험, 다음 예정 라인이 포함된다.
5. 검증 스크립트가 위 조건을 자동 검사한다.

## 산출물 계약

- 전체 통파일 ZIP: 바로 실행·검증 가능한 전체 프로젝트
- 붙여넣기용 패치 ZIP: `APPLY_TO_PROJECT_ROOT/` 내부를 기존 프로젝트 루트에 복사
- 패치 메타데이터: `PATCH_MANIFEST.json`, `PATCH_CONTENT_SHA256.txt`, `DELETE_LIST.txt`, `README_PATCH.txt`
