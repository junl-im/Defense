# 라니킹덤 v2.9 — 본판 실제 플레이 화면 3D·왕실 명령 UI 적용

## 본판의 정확한 의미
사용자 제공 중세 왕국 디자인 이미지를 목표 **참고 시안**으로 활용하되, 이미 게임 중인 Three.js 왕국 게임에 실제 기능·시각 작업을 통합한다. 시안 이미지 1장을 웹 화면 위에 덮어씌우거나 가짜 메뉴를 만들지 않는다. 완성되지 않은 자산을 신규 PNG로 위장하지 않으며, **SVG 전면 금지**.

## 이번 실제 개발
1. `src/rendering/RoyalVillageSquareArt.js`: 첫 시작부터 존재하는 플레이어 마을(village) 타일에 왕실 청색·금장 가로등 4종, 북쪽 작은 왕실 깃발대 2종, 자연스러운 화단 4개 등 기존 중심 3D 성 주변의 실제 입체 디테일을 추가. 자원/경제/세이브/건설지형을 변화시키지 않고 **1개의 vertex-colored merged Three.js mesh**로 렌더링. 기존 성문·중앙 건물·외곽 석판 길을 가리지 않고 방사 거리 약 0.6~0.8의 타일 외곽에 배치.
2. `TileFactory.placeCell`과 `TileFactory.setGhostTile` 모두 `makeRoyalVillageSquareArt(cell)`를 기존 v1.9 왕실 도로, v2.6 수변 아트와 **별개**로 연결. 실제 3D 육각 마을+배치 미리보기에서 보이며 `raycast=()=>{}`를 통해 건물 선택/건설 탭을 가로채지 않음. 기존 GPU 처분·저장/시드 규칙 재사용.
3. `src/ui/ProductionCommandRail.js`는 실제 본판 데스크톱 왼쪽에 건설·연구·세력·임무·왕국 버튼으로 왕실 명령 레일 배치. 연구/세력/건설/왕국 버튼은 기존 `RoyalLauncher`의 **현재 작동 중인 이벤트 리스너를 .click()으로 위임**하고, 임무는 기존 임무 패널 숨김 클래스만 토글. 가짜 창/분리 데이터 시스템/별도 전투 시스템 생성 없음. 하나 누르면 연결된 기존 정보창을 열고 닫을 수 있으며 `aria-pressed`도 실제 상태와 일치. 기존 하단 런처, 3D 필드 이동, 저장 메뉴 모두 그대로.
4. `css/rani-production-screen-v29.css`는 전체 스타일을 무차별 재정의하지 않고, 큰 PC(가로≥1180px, 세로≥620px)에만 좌측 빠른 메뉴와 왕실 남색/금색 테마를 추가. 기존 사용자 이동한 UI 패널 `.rani-positioned` 위치는 절대 덮어쓰지 않음. 기존 연구/임무 패널 기본 위치만 96px로 바꿔 빠른 메뉴와 겹치지 않음. 1024px 노트북은 종전 런처 유지, 스마트폰은 빠른 메뉴를 숨기고 기존 하단 터치 탭만 유지하면서 같은 왕실 테마 사용.
5. `src/main.js`: 게임 생성 완료 후 기존 `installRoyalLauncher(game)` 바로 뒤에 `installProductionCommandRail(game)` 1회 호출. 전체 게임 이펙트, 성벽/항구·무역선, 도로·연구/세력·방어·저장 키는 전혀 교체/초기화하지 않음.

## 현재 한계
이번 v2.9는 **실제 플레이 화면에 왕실 명령 UI와 왕실 광장 3D 장식을 정식 구현하는 단계**로, 사용자의 레퍼런스에 등장한 수백 채의 대도시·폭포·바다·NPC 군중·아이템 장식·인물 초상화 전체를 완성했다고 말할 수 없음. 앞서 생성된 고해상도 시안은 코드로 변환되지 않은 **시각 참고 자료**이며 게임 실제 캡처가 아님. 실제 Android/iOS 스마트폰 GPU FPS/발열 실측 미완료.
