# v3.8.0 IP Production Foundation

- 13개 IP 제작 영역을 `production/DokkaebiDefense`에 추가했다.
- 게임 기획서, 아트 바이블, UI/UX 설계서, 애니메이션 바이블, 에셋 마스터리스트의 5대 기준 문서를 고정했다.
- 사용자가 제시한 수량의 정확한 합계인 1,130개 시각 에셋을 고유 ID와 납품 파일명으로 등록했다.
- 11개 시작 직업, 7등급, 7스테이지, 10개 메인 화면, 99개 시작 직업 핵심 애니메이션 행을 계약화했다.
- 미래 Unity 이관용 Assets 폴더 계약과 사운드·수익화·라이브 운영 기준을 추가했다.
- 생성기와 검증기를 CI에 연결해 수량·중복·금지 포맷·선승인 오류를 자동 차단한다.
- 캐릭터 비율을 2.3등신, 머리 42%, 몸 35%, 다리 23%로 명시적으로 동기화했다.
- SVG 금지, PNG 전용 PWA manifest, 전투 GLB 14종 해시 계약을 유지한다.
