# Golden Convergence v10.0.0

## 목적

v9의 에셋 품질 감사 체계를 실제 게임 화면과 제작 검수 파이프라인으로 연결한다. 원본 970개를 완성 에셋으로 과장하지 않으며, 고해상도 후보 40개만 투명 프레젠테이션 파생본과 실루엣 검수본으로 가공한다.

## Asset Forge 10

- 입력: v9 고해상도 리뷰 후보 40개
- 출력: 512×512 투명 PNG 40개
- 출력: 256×256 실루엣 PNG 40개
- 배경 처리: 캔버스 경계에서 연결된 배경색 영역만 제거
- 가장자리 처리: 알파 페더링과 흰색 매트 오염 완화
- 검증: 출력 해시, 캔버스 경계 접촉, 프레젠테이션 적합성
- 승인 상태: 전부 `transparent-presentation-candidate`
- 최종 제작 승인: 0개

자동 배경 분리는 원본 제작 파일을 대체하지 않는다. 머리카락, 반투명 FX, 세밀한 장식은 사람의 마스킹 검수가 필요하다.

## 플레이 직업 5종

| 직업 | 패시브 | 전투 특성 |
|---|---|---|
| 도깨비 전사 | 철벽 대장 | 대장 피해 증가, 신목 피해 감소 |
| 도깨비 궁수 | 월영 사냥 | 이동·보스 피해 증가, 관통 사격 |
| 도깨비 법사 | 원소 도관 | 원소 반응·스킬 피해 증가 |
| 도깨비 도사 | 백귀 봉인 | 상태 지속·반응 피해 증가, 봉인 연쇄 |
| 도깨비 무당 | 신목 굿판 | 신목 회복 증가, 방어 보조 |

5개 논리 직업은 현재 검증된 3개 영웅 GLB를 공유한다. 도사와 무당은 법사 기술 후보 GLB에 절차형 부적·부채·방울 외형을 결합한다. 따라서 5개의 최종 캐릭터 모델이 완성됐다는 뜻은 아니다.

Asset Review OS의 전체 80개 파생 이미지는 전투 런타임과 분리한다. 타이틀 직업 선택 화면에서 사용하는 5개 카드만 전투 텍스처 예산에 포함하며 검증값은 62.86MB / 64MB다.
