# v1.0.29 에셋 정제 보증

## 목표

푸푸도깨비 11방향 승인 원본의 정체성과 픽셀을 바꾸지 않고, 아틀라스 셀 경계에서 발생할 수 있는 색 번짐·검은 가장자리·접지 흔들림을 런타임 파생 자산과 메타데이터로 완화한다.

## 처리 원칙

- v1.0.17 최종 승인 원본은 변경하지 않는다.
- 파생 아틀라스는 원본을 RGBA로 읽어 보이는 픽셀과 알파를 그대로 보존한다.
- 알파가 0인 투명 픽셀의 RGB만 같은 셀 안에서 3px까지 확장한다.
- 각 셀에 0.75px UV 안전 여백을 사용한다.
- 11방향 × 6액션, 66셀의 바운딩 박스·중심점·접지점·면적을 기록한다.
- 독립 공격·기술·피격 원화는 새 최종 원화가 아니므로 파생 임시 승인 상태를 유지한다.
- 장난 요괴 폭탄병 후보는 원본 11셀 증거가 확보될 때까지 런타임에서 격리한다.
