# v23.1.0 Native Input Shell

## 목표
브라우저 기본 키와 게임 입력의 경계를 명확하게 분리하고, PC 타이틀 화면에서 마스코트와 접속 패널의 겹침을 제거한다.

## 영구 입력 원칙
- F1~F12는 브라우저와 운영체제의 기본 동작을 가로채지 않는다.
- 게임 전역 액션 단축키를 등록하지 않는다.
- PC 키보드는 WASD·방향키 이동만 처리한다.
- 스킬, 소환, 수호신, 상호작용, 일시정지, 제작 도구는 화면 버튼으로 실행한다.
- 포커스된 버튼의 Enter·Space 동작은 웹 접근성 표준으로 유지한다.

## PC 타이틀 레이아웃
- 901px 이상 가로 화면: 마스코트 좌측, 접속 UI 우측.
- 901~1120px: 축소된 2열 레이아웃.
- 모바일·세로 화면: 기존 중앙형 흐름 유지.
