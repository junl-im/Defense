# v2.33.0 Runtime Bundle Split QA

## 목표

v2.32 기준 모바일 안정화 구조를 유지하면서, 기본 실행에서 불필요하게 초기 JS 번들에 섞이던 선택형 원화/갤러리 아트 코드를 분리했다. 다운로드를 막아도 코드 파싱 비용이 남는 문제를 줄여 첫 접속, 첫 탭, 로비 전환의 체감 지연을 낮추는 것이 핵심이다.

## 주요 변경

- `ProgressiveAssetLoader` 경량화
  - v2.25~v2.27 대량 갤러리 목록의 정적 포함 제거
  - 기본 모드에서는 소형 핵심 카탈로그만 유지
  - `?ultraart` 등 명시 옵션에서만 제한적으로 고급 아트 로딩
  - 로드 오류 발생 시 전역 백오프 적용
  - 조용한 부팅 구간에서는 병렬 다운로드 1개 고정

- 로비/월드맵/전투 선택형 아트 코드 스플릿
  - v2.17~v2.22 누적 장식 모듈을 동적 import로 전환
  - v2.24 프리미엄 정적 아트 모듈을 동적 import로 전환
  - v2.25~v2.27 progressive art 적용 모듈을 동적 import로 전환
  - 기본 플레이에서는 해당 모듈을 초기 JS 번들에서 분리

- 첫 화면 정책 유지
  - v2.29에서 복구한 원래 시작 화면 정체성 유지
  - 프리미엄 로그인 아트 자동 주입 없음

## 기대 효과

- 약한 모바일 네트워크에서도 초기 JS 파싱 부담 감소
- `?fullart`를 붙이지 않은 기본 플레이의 메모리 부담 감소
- 로비/월드맵/전투 진입 순간에 선택형 아트 모듈이 선제 파싱되는 문제 완화
- 대용량 아트 감상은 옵션으로 분리하고, 기본은 안정성 우선 유지

## 테스트 메모

- 기본 주소: 안정성 우선
- `?quality=low`: 강제 저사양 테스트
- `?resetperf`: 런타임 lockdown 초기화
- `?ultraart`: 고성능 기기에서만 선택형 아트 스트리밍 확인
