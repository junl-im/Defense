# v2.8.0 Contract QA + Runtime Cleanup

이번 패치는 v2.7 전투 다양화 이후의 후속 대규모 다듬기 패치입니다. 목표는 전투 반복성을 더 높이면서 모바일에서 누적 랙과 UI 밀집 문제를 줄이는 것입니다.

## 1. 전장 계약 시스템

- 스테이지/유저/전장 구성 기준으로 3개의 전장 계약이 자동 생성됩니다.
- 계약 종류:
  - 정찰대 소탕
  - 방어선 완성
  - 왕실 전술 시전
  - 무누수 방어
  - 연속 처치 지휘
  - 선제 출격 명령
  - 공중 감시망
  - 장갑 파쇄 작전
- 계약 완료 시 즉시 골드 보상과 점수 보너스가 반영됩니다.
- 결과 화면에는 전술 목표와 전장 계약 결과가 같이 표시됩니다.

## 2. 작전 카드 풀 확장

- 비상 금고 개방
- 공중 감시단
- 야전 의무대
- 공성 조율 명령

기존 v2.7 작전 카드와 같이 섞여 나오며, 경제/대공/회복/포격 운영 루트를 보강합니다.

## 3. 모바일 UI 밀도 조정

- 전장 계약 HUD는 작은 칩 형태로 표시합니다.
- 누르면 현재 계약 진행 상황을 메시지로 확인할 수 있습니다.
- 기존 시너지/작전 카드/상단 정보바와 겹치지 않도록 전장 상단 좌측 보조 영역으로 분리했습니다.

## 4. 런타임 누적 랙 방지

- `installScenePerformanceWatch()`의 업데이트 리스너를 Scene shutdown/destroy 시 명확히 해제합니다.
- GameScene 종료/재시작 시 남을 수 있는 웨이브 타이머, 스폰 이벤트, 입력 리스너, 타겟 프리뷰, 전술 카드 오버레이를 정리합니다.
- 반복 재도전 시 listener/timer가 누적되는 위험을 줄였습니다.

## 5. WebP 추가

- `public/assets/ui/v2_8/` 신규 UI 에셋은 PNG/WebP를 동시에 제공합니다.
- 기존 WebP 우선 로더에 `v2_8` 경로를 추가했습니다.
- `?png=1`을 사용하면 PNG fallback을 확인할 수 있습니다.

## 6. 검증

```bash
npx tsc --noEmit
```

통과 기준으로 작성되었습니다.

확인용 주소:

```text
http://localhost:5173/?hit=1
http://localhost:5173/?perf=1
http://localhost:5173/?png=1
http://localhost:5173/?lite=1
```
