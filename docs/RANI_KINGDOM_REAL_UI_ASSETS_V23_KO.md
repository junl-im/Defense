# 라니킹덤 v2.3 — 독립 제작 왕실 이미지 실제 UI 활용 확대

## 자산 승계와 절대 규칙
- 이전 확정 개별 PNG 원본과 v2.2 경량 WebP **10종 전부 보존**. 새 스프라이트 시트를 잘라서 가짜 개별 자산으로 사용하지 않는다.
- 사용자 확정 **SVG 전면 금지**. 현재 게임의 원본 Three.js/GLTF 지도, 건설, 마을, 필드, 경제와 세이브 구조를 변경하지 않는다.
- '게임 실제 3D 그래픽 개선'과 '게임 메뉴에 2D 전용 아이콘/프레임 사용'은 별개의 작업이며 완료를 혼동하지 않는다.
- 목표: 사용자가 첨부·승인한 따뜻한 중세 판타지 왕국 2.5D, 진한 푸른 지붕/황금 장식/목재 패널, PC와 모바일 공통 아트 콘셉트.

## 이번 v2.3 실제 패치
1. `RaniAssetRegistry.js`: 기존 준비 자산 `houseA`/`market`/`tradeShip` 3종을 `RANI_GAMEPLAY_ICONS`에 각각 실제 **village / market / port** 기능용 고유 이미지로 등록. 각 그림은 별도 투명 PNG에서 만든 WebP이며 3D 지도에 삽입하는 것이 아님.
2. `GameIcons.js`: 새 3종을 기존 `iconHtml()` 출력 경로에서 실제 <img>로 사용. 시장 건축 메뉴와 시장 관련 표시, 항구 관련 UI, 내 마을 아이콘에서 기존 임시 이모지 대신 래스터 이미지. 이미지 손상시 이전 이모지 fallback 유지.
3. `RoyalLauncher.js`(PC) 및 `MobileDock.js`(모바일): 기존 **마을 실제 이동 버튼**에 동일 독립 청색지붕 주택 아이콘 연결. 버튼 자체의 왕국/필드 이동·토글·위치 저장 기능은 그대로.
4. `css/rani-individual-ui-v23.css`: 기존 독립 금장 목재 버튼 `rk_btn_royal_primary_v001.webp`를 초보 성장 안내의 실제 `#slg-tutorial-go` 액션 버튼에 2:1 원본 비율에 가까운 94×47(PC), 86×43(모바일), 80×40(소형) 크기로 `background-size:contain` 적용. **배너를 단순히 가로로 늘리지 않음**. 호버·눌림·포커스·장애물 없는 버튼 이벤트 보존.
5. 기존 별도 금장 HUD 프레임은 원본 비율이 긴 리소스 HUD와 달라 **급하게 찌그러뜨리지 않고 준비 상태 유지**. 새로운 UI 전용 크기 자산이 따로 준비될 때 통합.
6. `assets/rani/manifest-v23.json`: 총 10종의 기존 원본 그대로, 실제 적용 9종(자원 5 + 마을·시장·항구 3 + 금장 CTA 1)과 원본 HUD 프레임 대기 1종을 정확히 기록. 역사 기록 `manifest-v22.json` 그대로 유지.

## 품질 검증
- `scripts/check-rani-visual-v23.mjs`가 10종 파일의 바이트 크기 불변/이전 자산 보존/앱에 적용한 9개 파일/원래 3D 렌더 경로/비율이 맞는 금장 버튼을 체크.
- `scripts/qa_rani_visual_v23.py`: PC 1440×900·노트북 1024×768·모바일 390×844·소형 320×700 실제 Chromium에서 독립 시장/주택/항구 3개의 이미지를 불러오고, PC·모바일 실제 마을 버튼에 동일 이미지가 있는지, 금장 버튼 2:1 원본 비율 유지/실제 CSS 이미지 로드, 마을↔필드 및 연구 토글 기능 유지, 콘솔 예외/기존 SVG 금지 검사.
- 이전 게임 전체 테스트 + v2.2 WebP 실제 자원 5종 불러오기/로드 실패 대체 테스트 유지. CI 성공 시에만 병합.

## 누적 원본과 후속
- 이전 v2.2 PNG+WebP ZIP은 [Google Drive 보존본](https://drive.google.com/file/d/17z3CxG084H009VspkNGYBaQMQDt9aXRf/view), 약 16MB. 이 버전은 같은 파일을 재사용하므로 불필요하게 원본을 다시 복사하지 않는다.
- 새로 필요한 영향력/안정도/연구/건설/퀘스트/전투/지도/설정 등은 아직 임시 이모지가 남아 있다. **각각 개별 이미지 생성**이 필요하며, 대량 이미지 시트를 분할하거나 원본을 함부로 품질 저하해서 넣지 않는다.
- Reference의 전체 도시 밀도·건물 아트·NPC·강과 바다·왕궁/성벽까지 교체되는 것은 이 버전 완료 내용이 아니다. 물리 스마트폰 FPS 및 GitHub Pages CDN 최신 배포는 별도 실기기 확인.
