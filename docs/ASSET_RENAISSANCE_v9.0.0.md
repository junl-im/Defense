# ASSET RENAISSANCE v9.0.0

v9는 에셋 수를 부풀리는 패치가 아니라, 새로 들어온 시각 자료를 실제 제작 파이프라인에 안전하게 편입하는 패치다.

## 핵심 원칙

- Source file과 Finished asset을 분리한다.
- 자동 분리 조각은 Quarantine에서 벗어날 수 없다.
- 고해상도 단일 이미지도 Concept Review Candidate일 뿐이다.
- Runtime 3D 승인에는 GLB, Rig, 11개 모션, PBR, 장비 소켓, 실기기 리뷰가 필요하다.
- Absolute Art Bible v2.0은 변경하지 않는다.

## 사용자 노출

- 타이틀 직업 선택에서 전사·궁수·법사 신규 후보를 확인한다.
- `스튜디오 에셋 리뷰`에서 970개 파일을 품질 단계별로 검색한다.
- F4 Production Console에서 40 High-Res / 823 Quarantine / 0 Approved를 확인한다.
