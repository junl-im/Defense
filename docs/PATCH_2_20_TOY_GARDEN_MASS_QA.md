# v2.20.0 Toy Garden Massive Art QA Patch

## 목적

v2.16~v2.19의 귀엽고 말랑한 UI 방향을 유지하면서, 로그인·로비·월드맵·전투 화면에 “토이 가든/장난감 왕국” 느낌의 신규 대량 에셋과 장식 레이어를 추가한 누적형 대량 패치입니다. 텍스트와 클릭 영역은 계속 코드가 소유하고, 신규 에셋은 투명 PNG/WebP 장식으로 분리했습니다.

## 신규 에셋

- `public/assets/ui/v2_20/` 신규 PNG 64개
- 동일 파일명 WebP 64개
- 총 128개 신규 이미지 파일
- 주요군:
  - 토이 가든 로그인 프레임, 성 크레스트, 오로라 리본, 구름 아치
  - 여우 기사, 달빛 고양이, 티타임 토끼, 베이커 곰, 씨앗 요정 마스코트
  - 로비 재화 둥지, 퀘스트북, 우편 새, 상점 텐트, 이벤트 풍선
  - 월드맵 젤리 노드 링, 캔디 비즈 루트, 잎사귀 브리지, 보스 포털, 미리보기 프레임
  - 전투 상단 레이스, 하단 베개 독, 꽃 레일, 스킬 카드, 오브/콤보/안전 배지

## QA 수정

- 로그인 비동기 로그인/리다이렉트 확인이 씬 전환 후 status text를 만질 수 있는 경로를 가드했습니다.
- 로그인 완료 후 220ms 페이드 지연 중 씬이 바뀌면 MainMenu 전환을 건너뛰도록 보호했습니다.
- 로비/월드맵 토스트 표시 및 hide timer가 씬 비활성 상태에서 실행되지 않도록 보강했습니다.
- 전투 시작 지연 호출, 일일 도전 메시지, 웨이브 후 전술 카드, 다음 웨이브 자동 타이머에 씬 생존 가드를 추가했습니다.
- 전투 스폰 스트림과 콤보/메시지/전술 힌트 hide timer가 씬 종료 후 동작하지 않도록 안정화했습니다.
- 월드맵 v2.20 루트 장식은 실제 노드 방향 각도로 회전하도록 배치해 경로 시각 연결감을 높였습니다.

## 검증

```bash
npx tsc --noEmit --pretty false
npm run build
```

둘 다 통과했습니다. Vite 빌드에서는 기존과 동일하게 큰 번들 경고가 표시됩니다.

## 적용

프로젝트 루트에 압축을 풀어 그대로 덮어씁니다. `.git`, `node_modules`, `dist`는 패치 zip에 포함하지 않습니다.
