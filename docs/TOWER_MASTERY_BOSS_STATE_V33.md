# Kingdom Seed v3.3 - Tower Mastery FX / Boss State Link

## 목표
v3.2에서 추가한 스킬/보스 연출을 실제 전투 상태 변화와 더 강하게 연결한다.

## 추가 내용

### 타워 최종 진화별 전용 컷인
- 최종 진화 선택 시 대형 컷인 1회
- 최종 진화 효과가 전투 중 발동할 때 소형 컷인 표시
- 장궁/저격/비전/저주/박격포/충격포/성기사/돌격대 각각 별도 문구와 색상 사용

### 투사체 트레일
- Lv.3 또는 최종 진화 타워의 투사체에 잔광 트레일 추가
- 저격은 날카로운 금빛 직선
- 비전/저주는 마법 입자
- 포탑/충격포는 굵은 탄도 궤적

### 보스 패턴 상태 연동
기존 보스 패턴은 자체 버프 중심이었다. v3.3부터는 전장에도 디버프를 건다.

- 관문 군주: 전체 타워 피해 감소 / 재장전 지연
- 화산룡: 가까운 타워 재장전 지연
- 공허 거신: 타워 압박 + 잡몹 응집 연출
- 불사조: 포탑/병영 라인 압박
- 오우거/골렘/살점 괴물: 병영/용병 전선 경직

## 테스트 체크리스트
1. Lv.3 타워를 최종 진화할 때 컷인이 나오는지 확인
2. 최종 진화 타워가 공격할 때 트레일이 나오는지 확인
3. 보스 패턴 발동 시 상태 패널이 나오고 타워에 압박 오라가 생기는지 확인
4. 병영 전선이 지진 강타에서 잠시 경직되는지 확인
