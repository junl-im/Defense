# Production Gate & Performance Contract v4.2.0

## 목적

Absolute Art Bible v2.0을 문서 규칙이 아니라 실제 승인 게이트로 사용한다. 기존 런타임 GLB 19종은 레거시 후보로 유지하되 `production-approved`로 승격할 수 없다.

## 골든 수직 슬라이스

대량 제작 전에 다음 6개 항목을 한 세트로 승인한다.

1. 도깨비 전사
2. 일반 요괴
3. 저승 호랑이
4. 도깨비마을 전장
5. 전투 HUD
6. 전투 VFX

6개가 모두 승인되기 전까지 1,130개 에셋 대량 생산은 잠금 상태다.

## 승인 증거

- 스타일 잠금 메타데이터
- 아트 리뷰 체크리스트
- 5방향 턴어라운드
- 0.3초 실루엣 테스트
- 60/25/10/5 팔레트 검사
- 기술 예산 검사
- 실기기 런타임 리뷰
- 아트 디렉터 승인

## 성능 계측

Engine 3.1.0은 240프레임 고정 버퍼에서 다음 값을 집계한다.

- 평균 프레임 시간
- P95 프레임 시간
- 25ms 이상 장시간 프레임 비율
- 40ms 이상 심각 프레임 비율
- 세션 누적 장시간 프레임 수

`?stats=1`로 렌더 통계를 표시하며 P95 상태에 따라 정상·경고·위험 테두리를 적용한다. 성능 로그 JSON에도 동일한 스냅샷과 아트 제작 게이트 상태를 기록한다.
