# v1.0.21 Live Combat Ascension

## 목적

전투 개체와 이펙트가 많아질수록 월드 HP 바와 상단 HUD가 겹치고, 작은 화면에서 정보가 과밀해지는 문제를 실제 런타임 밀집도에 따라 조정한다.

## 적용 내용

- 4단계 전투 밀집도 자동 분류: calm / active / crowded / extreme
- 영웅·수호대·보스·수호성 HP 바 우선 유지
- 혼잡 구간에서 일반 몬스터 HP 바는 피격·상태 이상·저체력·집중 대상 위주로 표시
- HP 감소 잔상, 저체력 경고광, 보호막·브레이크·상태 아이콘 유지
- 겹치는 일반 몬스터 HP 바에 안정적인 미세 오프셋 적용
- 실제 HUD 높이를 측정하여 보스 HP 바와 보조 패널의 시작 위치 자동 조정
- p95 프레임 시간·심각 프레임 비율·FPS를 이용한 성능 압력 상태 표시
- PC·태블릿·모바일 공통 진단값 제공

## 런타임 진단

```js
window.__DOKKAEBI_LIVE_COMBAT_V121__
```

## 승인 경계

이번 패치는 전투 연출과 UI 운영 체계를 개선한다. 신규 캐릭터 11방향 원화를 최종 승인한 것으로 계산하지 않는다.
