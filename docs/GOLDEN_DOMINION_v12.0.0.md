# Golden Dominion v12.0.0

## 목적

v11의 전투·메타 시스템을 유지하면서 기본 카메라를 넓은 전장 조망형으로 전환하고, 플레이 가능한 골든 수직 슬라이스 6개 영역을 증거 기반으로 인증한다.

## 카메라

- 기본 프리셋: `scenic`
- 기본 거리: `19.5` (v11 `15.5` 대비 약 26% 확대)
- Pitch: `0.73`
- FOV: `52`
- 웨이브: 자동 거리 `+0.8`
- 보스전: 자동 거리 `+1.35`
- 데스크톱 월드 청크 반경: `2`
- 모바일 월드 청크 반경: `1`
- F5: 전장 조망 → 균형 시야 → 근접 시야 순환

## 런타임 수직 슬라이스 6/6

다음 영역은 코드·파일·해시·레이아웃·예산 증거를 갖춘 `runtime-certified` 상태다.

1. 도깨비 전사
2. 일반 요괴
3. 저승 호랑이
4. 도깨비마을 전장
5. 전투 HUD
6. 전투 VFX

이 인증은 게임 안에서 정상 동작하는 수직 슬라이스의 완성도를 뜻한다. 최종 작가 제작 아트 승인을 뜻하지 않는다.

## 11클립·6소켓 승격

공용 Skin을 가진 런타임 GLB 8종을 아래 계약으로 승격했다.

- `Idle`
- `Walk`
- `Run`
- `Attack1`
- `Attack2`
- `Skill1`
- `Skill2`
- `Hit`
- `Death`
- `Victory`
- `Spawn`

장비 소켓:

- `HelmetSocket`
- `ShoulderSocket`
- `WeaponSocket`
- `AccessorySocket`
- `BackSocket`
- `FXSocket`

## 승인 구분

- 런타임 수직 슬라이스 인증: **6/6**
- 최종 제작 아트 승인: **0/6**
- 대량 생산 잠금: **유지**

최종 제작 아트는 다각도 원화, 최종 메시, 독립 장비 파츠, 수동 알파 검수, 실기기 아트 디렉터 승인을 추가로 통과해야 한다.
