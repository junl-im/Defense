# 라니킹덤 v2.0 — 왕실 도로·성벽·성문·항구 실제 3D 품질 강화

## 확정 아트 콘셉트
사용자가 제시한 2.5D 쿼터뷰 중세 판타지 왕국 이미지 기준: **푸른 지붕·금빛 왕실 문장·따뜻한 석재 포장·성벽·항구/부두·나무·풍부한 도시 밀도**. 기존 3D 세계·게임 규칙·데이터를 유지하며 그래픽을 점진 강화.

## 실제 작업
- `src/rendering/RoyalInfrastructureArt.js` 5종 실제 Three.js 3D 그래픽 생성기 신설. 모두 `part`/vertex color/`merge`의 **단일 메시 방식**이며 새 별도 SVG·캔버스 PNG·가짜 월드 DOM을 사용하지 않는다.
- **도로:** 기존 `AutoMesh`의 roadBuilder에서 도로 방향/연결 비트마스크를 그대로 읽어 약 5×2개의 돌과 중앙 광장 석판을 렌더링. 기존 MATS.road의 연결 길·막다른 길 지오메트리 위에 **1개 병합 메시**만 추가. 막다른 길은 원본 짧은 길이를 넘지 않도록 제한. 기존 `ConnectorSystem`·`RoadSystem`의 길 방향·점수·거래·경제 계산 손대지 않음.
- **외곽 방어선:** `WallSystem`은 원래 적대 세력 경계에만 방책을 생성한다. Lv.1 기본 나무 방책을 보존하고, 내 마을 **중심 건물 Lv.2 이상일 때만** 기존 적대 경계선의 외형을 돌 성벽·흉벽·왕국 문장으로 변경. `native-village:expanded` 승격 시 갱신하며 매초 진행률 이벤트에서는 갱신하지 않음. 기존 적대 판정, 방어 수치, 영토 소유권 변경 없음. 이전 경계 메시 GPU 지오메트리 dispose 처리 추가.
- **성문/보루:** 원본 `MilitaryFactory`의 `makeWallGate`/ `makeWallTowerCorner` 4단계 건축 유지, **완공 최종 p4**에만 파란 탑 지붕·금빛 돌 이음새·문장과 방패 추가. 플레이어 건설 성문에 무작위 적 색상 깃발이 나오지 않도록 푸른색 왕국 깃발로 통일. 원래 골격·문 개구부·타일 배치 유지.
- **항구/낚시 부두:** 원본 `CivicFactory.makePort`/ `makeFishingPier`에 완공 4단계에서 푸른 왕국 깃발·황금 테두리·목재 부두 띠와 항만 행정 표식을 입체적으로 부착. 원래 배/크레인·무역·어업 생산/잠금 해제, 부두 조작 유지.

## QA
- `npm test`에 `scripts/check-royal-infra-v20.mjs` 실제 소스 연결 및 기존 저장 로직 불변 검증 추가.
- `scripts/qa_royal_infra_v20.py`는 PC 1440×900·모바일 390×844·소형 320×700에서 Three.js 원본 게임을 실행해 실제 도로 패턴·돌 방벽 승격 전후·성문/보루/항구/낚시 부두 4개 생성기의 원래 4단계 구조와 새 장식이 마지막 단계에만 등장하는지 검사. 원래 3D 마을/저장 재로드/브라우저 오류 검사 병행.
- 기존 Korean PC·모바일 전체 자동 검증(건물·육각 팝업·우클릭/드래그·원형 정보창·위치 저장·경제·마을/필드) 전부 유지.

## 제한
항구는 **기존 항구 건설 조건이 충족되면** 표시된다. 개발용 가짜 항구를 시작 화면에 강제로 설치하지 않는다. 돌 성벽도 **실제 적대 경계+중심 건물 Lv.2 이상**이 전제다. 이번 v2.0 역시 참고 이미지의 모든 모델·성벽 둘레·바다와 인물까지 완전히 대체한 것은 아니다. 최종 GitHub Pages CDN 배포와 물리 스마트폰 GPU FPS는 브라우저 자동검사와 별도.
