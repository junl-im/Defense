- 앞서 제작하고 승인한 **독립 PNG 원본 10종·변환 WebP 10종, 로고·11 지형 아틀라스, GLTF 4종**을 삭제·압축 재생성·스프라이트 시트 절단 없이 전량 계승한다.
- 참고 화면: 파란 지붕·왕실 금장·석판 도로·2.5D 중세 왕국. **SVG 전면 금지**. 원본 Three.js 실제 마을·필드·경제·연구·건설·전투·저장 구조 불변.
- 원본 [Google Drive ZIP](https://drive.google.com/file/d/17z3CxG084H009VspkNGYBaQMQDt9aXRf/view) **16,285,113바이트**: 별도로 확인된 PNG+WebP 백업. GitHub의 16종 런타임 보호 목록과 구분한다.
- 개발 원본 저장소: [junl-im/Defense](https://github.com/junl-im/Defense); 2026-10-19 main v2.4 기준 `018893aa29be3c8b879a0302c0709722cd84b21f`.

## 실제 v2.5 패치
1. `assets/rani/asset-integrity-lock-v25.json`: v2.4 `main`의 **승인 런타임 파일 16개** (독립 WebP 10 + 왕국 로고 1 + 지형 아틀라스 1 + Quaternius GLTF 4)의 **바이트수·Git blob SHA-1** 를 기록한다. 외부 임의 해시가 아니라, 원본 GitHub에 보관된 각 실제 Git 객체 식별자에 근거한다.
2. `scripts/check-rani-integrity-v25.mjs`: 실행 환경에서 해당 파일을 직접 읽고 Git blob 형식의 지문을 재계산하여 바이트 동일성 검증. 기존 v2.2/v2.3 10종 출처·사용 상태와 `RaniAssetRegistry.js` 실제 경로 연결 일치 여부, 원본 HUD 프레임 대기 상태 및 타이틀·GLTF·자료 출처를 점검한다.
3. CSS `url(...)`, HTML 로컬 링크·이미지·스크립트, JavaScript 상대 경로 import를 각각 **원래 파일 기준 상대 경로**로 해석해 확인하여 잘못된 참조를 조기에 실패 처리한다.
4. `package.json`의 `npm run build`를 `npm run test`로 위임해 테스트 목록 2군데가 다르게 수정되는 **코드 꼬임을 원천 예방**. 기존 v0.1~v2.4 검사 전부 유지하고 마지막에 v2.5 검사 추가.
5. `scripts/qa_rani_integrity_v25.py`: 실제 PC 1440×900·노트북 1024×768·모바일 390×844·소형 모바일 320×700 Chromium으로 원래 마을 로딩, 기존 5 자원·3 건물 단독 이미지·3D 석재·필드/마을 왕복, SVG DOM 0, 자바스크립트 오류/자산 404 없음, **16종 브라우저 파일 전송 바이트수** 검사.

## 패치 QA 조건
- PR 시 GitHub Actions 기본 소스·JS 문법과 전체 한국어 PC/모바일 Chromium 회귀 통과 전 **main 병합 금지**. 병합 후 Pages 재배포·main 브라우저 QA 확인.
- 원본의 '변경'은 의도적 새 버전 이미지 제작 승인과 **새 잠금 목록 버전**을 통해서만 가능. 기존 잠금을 그냥 삭제해 '통과'시키지 않는다.
- 새로 추가된 미사용 황금 HUD 프레임은 **2:1 비율로 보관**한다. 긴 자원 HUD에 가로 강제 변형하지 않는다. 아이콘 신규 제작 없이 임시 이모지를 속이거나 전체 원본 3D 맵을 교체한 것으로 표시하지 않는다.
