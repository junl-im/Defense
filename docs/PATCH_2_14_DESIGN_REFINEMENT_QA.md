## QA 체크
- `npx tsc --noEmit` 통과
- `npm run build`는 컨테이너 환경의 `vite: Permission denied`로 Vite 단계에서 실패. 로컬에서는 `npm install` 후 확인 필요

## 확인용 URL
- 클릭존 확인: `/?hit=1`
- WebP 비활성 PNG 확인: `/?png=1`
- 저사양 모드: `/?lite=1`
- 배터리 모드: `/?battery=1`
