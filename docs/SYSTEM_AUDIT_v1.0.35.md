## 발견된 실제 결함

1. 서비스워커 핵심 캐시에 런타임 의존 모듈 83개가 명시적으로 누락되어 오프라인 첫 재실행 실패 가능성이 있었다.
2. 링·소환 빔·번개 이펙트가 게임 수명주기 밖의 RAF를 사용해 런 종료나 dispose 시 잔류할 수 있었다.
3. 보스 식별 배지가 비활성화된 뒤 이전 `aria-label`을 유지했다.
4. 주소창 축소가 80px 이상이면 가상 키보드로 오인할 수 있었다.
5. 150% 핀치 줌에서 조이스틱과 액션 도크가 겹쳤다.

## 빌드 툴체인 예외

- 전달된 `node_modules/vite`는 빈 디렉터리여서 로컬 Vite 번들은 실행할 수 없었다.
- `package.json`·`package-lock.json`의 Vite 8.1.5 고정은 정상이다.
- 정적 배포본 전체 검증은 통과했으며, CI에서는 `npm ci` 후 실제 Vite 빌드와 프로덕션 번들 검증을 수행한다.
- `scripts/audit-build-toolchain-v135.mjs`가 이 예외를 자동 기록하고 의존성 재설치 여부를 판정한다.
