# Moon Gate Reborn v17.0.0

## 목표

- 사용자가 제공한 PC·모바일 배경과 도깨비 마스코트를 첫 접속 화면에 최적화 적용한다.
- 웨이브 3~4 전환 구간에서 발생할 수 있는 정지 상태를 복구 가능하게 만든다.
- 한 서브시스템 오류가 전체 프레임 루프를 멈추지 않도록 런타임 오류 경계를 추가한다.

## 첫 화면

- PC 배경: 1280×720 WebP, 약 117KB
- 모바일 배경: 600×1067 WebP, 약 109KB
- 마스코트: 560×705 알파 WebP, 약 97KB
- PC와 모바일은 CSS 미디어 쿼리로 별도 이미지를 사용한다.
- 원본 대형 PNG는 런타임 패키지에 포함하지 않는다.
- 첫 화면에는 수호 시작, 원정 설정, 보관함, 설정만 표시한다.

## 스테이지 흐름 안정화

- 웨이브 소환 상태 변화가 5.5초 이상 멈추면 비상 소환 경로를 사용한다.
- 특정 적 모델 생성이 실패하면 기본 장난 요괴로 대체한다.
- 대체 모델까지 실패하면 해당 소환 슬롯을 기록 후 건너뛰어 무한 대기를 막는다.
- 웨이브 3 축복 및 웨이브 4 유물 모달이 숨겨졌을 때 자동으로 다시 표시한다.
- 축복과 유물 화면에 추천 선택으로 계속할 수 있는 복구 버튼을 추가한다.
- 전투 종료 조건이 충족됐지만 완료 함수가 호출되지 않은 경우 자동 복구한다.
- 보상 처리 후 자동 진군 타이머가 사라진 경우 5초 카운트다운으로 복구한다.

## 오류 격리

애니메이션 프레임에서 다음 시스템을 개별 오류 경계로 감싼다.

- 웨이브
- 적 AI
- 전장 프롭
- 스프라이트
- 카메라
- 렌더러
- HUD
- 파티클 및 투사체

오류는 최대 30개까지 진단에 기록하고, 동일 오류의 사용자 알림은 한 번만 표시한다.

## 성능 예산

- 신규 첫 화면 런타임 파일 합계: 약 323KB
- 업로드 원본 대비 런타임 전송량 감소: 96.36%
- 전체 검증 텍스처 메모리: 57.84MB / 64MB
