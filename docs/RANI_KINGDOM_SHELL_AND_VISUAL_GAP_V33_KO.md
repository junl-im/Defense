# 라니킹덤 v3.3 — 로딩 직후 몰입 화면·전체화면·뒤로가기·나가기·종료하기

## 실제 사용자 요청
- 게임 실행 후 화면 전체를 사용하는 레이아웃으로 시작
- 가능한 환경에서 진짜 OS/브라우저 전체화면
- PC Esc, 모바일 뒤로가기, 화면 안 메뉴에서 **뒤로가기·나가기·종료하기**
- 이미 구현한 저장·건설·전투·연구·도감·원본 아트와 미디어 안전성 유지

## 중요한 브라우저 제약 — 반드시 정확히 안내
- 일반 웹브라우저는 페이지 로드만으로 `Element.requestFullscreen()`을 무조건 허용하지 않는다. 보안상 대부분 **사용자 제스처**가 필요하다.
- 이에 v3.3은 게임 시작부터 **viewport 100dvh/inset=0** 화면을 차지하도록 하고, 진짜 `requestFullscreen()`은 로드 때 시도(거부 시 정상 화면 유지), **첫 사용자 터치/클릭 시 한 번 더 시도**하며 왕국 게임 메뉴에 전체화면/해제 버튼을 별도 제공한다. 허용 불가 시 성공한 것처럼 안내하지 않음.
- 자동으로 `window.close()`할 수 있는 곳은 주로 스크립트가 연 새 브라우저 창뿐이며, 브라우저 사용자가 직접 연 탭과 앱 창은 닫기를 제한할 수 있음. 제한될 경우 종료 화면에 **직접 창을 닫아달라**는 메시지를 표시한다. 종료 성공을 추측하지 않음.
- PWA 전체화면 설치 UX에는 적합한 정사각형 브랜드 아이콘과 앱 매니페스트가 필요하므로, 준비되지 않은 브랜딩 이미지를 임의로 512x512 PWA 아이콘이라고 선언하지 않는다.

## 실제 코드
1. `src/ui/RaniGameShell.js`: 기존 `installRoyalLauncher` 이후 설치하는 독립 왕실 메뉴. ESC/Backspace(텍스트 입력은 제외)와 모바일 history `popstate`의 뒤로가기를 처리. 기존 왕국/모바일 열려 있는 창이 있으면 우선 닫고, 필드에서 뒤로가면 마을로 복귀, 아무 창도 열려 있지 않으면 왕실 메뉴를 열어 선택권 제공. 현재 게임의 게임오버와 세이브/로딩 구조는 건드리지 않음.
2. 메뉴 명령은 **뒤로가기 / 전체화면·해제 / 나가기 / 종료하기**. 뒤로가기는 현재 메뉴 닫기. 나가기는 기존 `SaveSystem.save(game)`로 왕국을 저장하고 **시작 화면(같은 앱 안 오버레이)**으로 가며, 게임 루프의 시뮬레이션만 일시중지. 게임 이어하기로 원상 복구; 사운드/데이터 신규 시스템 없음. 종료하기는 왕국 저장 후 `window.close()` 시도, 브라우저 제한 시 수동 종료 안내/이어하기 제공.
3. `src/core/Game.js`: `game.shellPaused`가 참일 때 프레임 렌더링은 지속하되 기존 건설/군사/자원 시뮬레이션의 시간이 흐르지 않도록 일시중지. 사용자가 실제 진행 중인 세이브 키 변경 없음.
4. `css/rani-shell-v33.css`: 100dvh/viewport/safe-area, 기존 청색·금장 왕실 메뉴 UI; PC와 좁은 모바일 모두 별도 미디어쿼리. 기존 승인 PNG/WebP 10종, 로고·지형/GLTF 4종 및 SVG 금지 기준 유지.

## 검증
- `scripts/check-rani-shell-v33.mjs`: 위 4개 메뉴와 사용자 활성화를 통한 전체화면, 제한 안내, 저장 계약, 기존 자산 지문 잠금 검사.
- `scripts/qa_rani_shell_v33.py`: 실제 Chromium PC1440·노트북1024·모바일390·소형320 뷰포트에서 전체화면 버튼, 화면 맞춤, ESC/모바일 history 뒤로가기, 나가기/이어하기 일시중지, 브라우저 종료 불가 시 진실된 안내, 원본 WebP/Three.js/SVG 0 검증.
- v0.1~v3.2 기존 자산·건축·저장·경제·UI·3D 회귀검사 전부 유지. 기본/PC모바일 QA 둘 다 통과한 뒤에만 main 병합.

## 핵심 그래픽 격차 — 우선순위 변경 기록
**기존 v2.4~v3.2 본판 패치는 목표 레퍼런스 풍의 '완성된 아트 대체'가 아니다.**
현재 `src/buildings/BuildingFactory.js`는 코드 첫 줄부터 **procedural low-poly medieval structures**라고 명시하고, `src/tiles/TileMeshBuilder.js`에서 육각 기초지형 역시 코드 생성 메시를 사용한다. `RaniAssetRegistry.js`는 기존 고품질 개별 건물·선박 일러스트를 실제 3D 건물 재질이 아니라 UI 썸네일이라고 명시한다. 가로등/꽃/돌길 추가로는 사용자가 첨부한 풍부한 청색 지붕, 대형 건물, 촘촘한 입체 도시, 항구·물의 아트와 동일해질 수 없다.

**다음 고우선순위 방향:** 핵심 건축물(왕궁/주택/상점/성벽/부두)의 실제 게임 월드 렌더 외관/질감부터 레퍼런스와 일치하는 **각개 원본 에셋**(독립 투명 PNG 및 본판용 개별 WebP/텍스처 또는 검증된 GLTF/GLB)을 제작·백업·연결하고, 지형/수면/빛/카메라/건축 밀도를 같은 기준으로 맞춰 시각 회귀 QA를 한다. **새 가짜 콘셉트 스크린샷을 실제 본판 적용으로 착각하지 않는다.**

이번 기능 패치로 해당 고품질 그래픽 격차가 해결됐다고 주장하지 않는다.
