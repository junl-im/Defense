# v1.9.0 Viewport QA + 원화급 비주얼 동기화 패스

## 목적
모바일에서 16:9 게임 화면이 세로폰 안에서 작게 보이거나, 회전된 캔버스의 클릭 좌표가 불안정하게 느껴지는 구간을 보정했다. 동시에 전투 구간의 배경, 타워, 유닛, HUD 에셋을 v1.9 계열로 다시 로드해 로그인/메뉴/월드맵/전투의 톤을 더 가깝게 맞췄다.

## 적용 내용
- 모바일 세로 화면 CSS 회전 로직을 중앙 기준 회전으로 교체
- 모바일 캔버스를 실제 화면 영역에 꽉 채우도록 `#game canvas` 크기 보정
- 주소창 접힘/펼침, 방향 전환, 전체화면 진입 후 Phaser ScaleManager 재계산 이벤트 추가
- v1.9 로그인/메인 메뉴/월드맵 배경 에셋 적용
- v1.9 전투 배경 8종 적용
- v1.9 타워 이미지 세트 적용
- v1.9 몬스터/영웅 원화풍 유닛 이미지 적용
- v1.9 전투 HUD, 하단 독, 타워 건설 메뉴, 타워 선택 패널 적용
- 타워 건설 메뉴가 여러 개 겹쳐 남는 문제 방지
- 빈 맵 터치 시 열려 있는 타워/건설 패널을 우선 닫도록 정리
- 클릭존 점검 모드 추가: URL에 `?hit=1`을 붙이면 주요 투명 클릭존이 표시됨

## QA 체크
- `npx tsc --noEmit` 통과
- BootScene에서 문자열로 로드하는 에셋 경로 누락 0건
- v1.9 신규 에셋 72개 생성 및 연결
- 로컬 빌드는 `npm install` 후 실행 권장. 현재 컨테이너의 기존 `node_modules`는 Vite/Rolldown optional native binding이 누락되어 `vite build`를 끝까지 검증할 수 없다.

## 클릭존 점검법
개발 서버 실행 후 아래처럼 접속한다.

```text
http://localhost:5173/?hit=1
```

노란색/파란색 반투명 박스가 버튼과 핫스팟의 실제 터치 영역이다. 모바일에서 그림과 클릭 영역이 어긋나 보이면 이 모드로 바로 좌표를 재조정한다.
