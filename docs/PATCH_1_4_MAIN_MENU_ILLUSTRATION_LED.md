# Kingdom Seed v1.4.0 - Main Menu Illustration-Led Art Pass

## 목표

메인 메뉴가 코드로 그린 버튼/패널 때문에 저가형 UI처럼 보이던 문제를 줄이고, 제공된 원화급 UI 레퍼런스처럼 보이도록 화면 전체를 고퀄리티 베이크 이미지 중심 구조로 전환한다.

## 변경 사항

- `package.json` 버전 `1.4.0`으로 갱신
- 신규 메인 메뉴 원화형 스플래시 추가
  - `public/assets/backgrounds/main_menu_splash_v1_4.png`
- `BootScene` 프리로드 추가
  - `v1-main-menu-splash`
- `MainMenuScene` 리마스터
  - 기존 코드 로고/패널/버튼 렌더링 제거
  - 제공된 프리미엄 로비 UI 느낌을 유지하는 전체 이미지 기반 메인 메뉴로 전환
  - 월드맵/전투/모험/영웅/임무/설정 등은 투명 클릭존으로 연결
  - 마우스 오버 시에만 얇은 광택/하이라이트가 나타나도록 구성

## 디자인 원칙

- 원화급으로 보여야 하는 요소는 이미지 에셋으로 베이크한다.
- Phaser 코드는 클릭 영역, 화면 전환, 최소 피드백만 담당한다.
- 앞으로 상점, 패스, 길드, 랭킹, 우편함도 같은 방식으로 고퀄 UI 에셋을 먼저 만들고, 투명 클릭존/팝업 로직을 얹는다.
