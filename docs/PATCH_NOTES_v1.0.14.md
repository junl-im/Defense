# v1.0.14 초대규모 에셋 폴리시·디자인 보강 패치

기준 버전은 **v1.0.13 / b24.13**이며 적용 후 **v1.0.14 / b24.14**가 됩니다.

## 핵심 변경

- 영웅 5종, 수호대 6종, 몬스터 7종, 보스 3종 등 전투 캐릭터 **21종**을 192/320/512px 품질 단계로 재정규화했습니다.
- 투명 외곽 번짐, 지면 접지, 캐릭터 크기, 실루엣 여백, 색감·선명도를 동일한 제작 규격으로 맞췄습니다.
- 승인되지 않은 P0 자동 생성 방향 시트는 제작 검토 자료로만 남기고 런타임 사전 로딩에서도 제외했습니다.
- 승인된 단일 원화는 좌우 반전하지 않습니다. 독립 제작된 11방향 원화가 승인되기 전까지 역할별 동작 타이밍으로 방향감을 전달합니다.
- 근접·원거리·마법·지원·제어·탱커·포효 등 **7개 액션 프로필**을 런타임에 반영했습니다.
- 수호성은 정상·보호막·균열·임계의 **4단계 전투 상태 이미지**로 전환됩니다.
- 수호성 레이어와 월드 HP 바는 각각 1개만 유지됩니다.
- PC·태블릿·모바일 HUD 패널 재질과 정보 밀도를 보정하고 작은 모바일 화면에서 보조 패널이 전투를 가리는 문제를 줄였습니다.
- 모바일 저전력 프로필은 192px 에셋만 상주하며 텍스처 예산 **62.53MB / 64MB**를 통과합니다.

## 실제 제작 자산

| 구분 | 수량 |
|---|---:|
| 전투 캐릭터 원화 정규화 | 21종 |
| 수호성 상태 | 4종 |
| 품질 단계 | Low 192 / Medium 320 / High 512 |
| 런타임 WebP | 75개 |
| 직업·행동 프로필 | 7종 |

## 중요한 품질 경계

이번 패치는 기존 고품질 IP 원화를 실제 게임 화면에 적합하도록 다듬은 업데이트입니다. 21종 전체의 최종 11방향 원화가 새로 제작된 것은 아닙니다. 독립 제작 방향 시트는 품질 승인 전까지 런타임에 사용하지 않습니다.
