# Kingdom Seed v3.6 Reward Forge Patch

## 목표
v3.5의 결과 화면 보상 상자를 실제 반복 성장 시스템으로 연결한다.

## 추가 시스템

### 1. 보상 상자 실제 개봉
- 클리어 결과에서 `보상 열기` 버튼 추가
- 메달/목표 달성도/스테이지별 보상 테이블에 따라 보상 산출
- 상자 개봉 시 전용 오버레이, 흔들림, 보상 라인 연출 표시

### 2. 유물 파편 저장
- `localStorage` 기반 클라이언트 저장
- Firebase 세이브 구조와 분리되어 무료 플랜 요청을 늘리지 않음
- 추후 Firebase 저장이 필요하면 `/users/{uid}.artifactInventory`로 병합 가능

### 3. 유물 제작/강화/장착
- 월드맵 `제작소` 버튼 추가
- 유물 12종 표시
- 파편으로 제작
- 파편 + 유물 가루로 강화
- 3개 슬롯 장착 구조

### 4. 스테이지별 특수 보상 테이블
- Stage 1: 궁수/병영/경제
- Stage 2: 포탑/마법/스펠
- Stage 3: 제어/병영/스펠
- Stage 4: 보스 대응
- Stage 5~8: 고급/전설 유물 파편

## 디자인 방향
- 제작소 전용 배경
- 상자 티어별 외형 분리
- 유물 아이콘 12종
- 결과 보상 오픈 시 상용 모바일 RPG 스타일 팝업 연출

## 주의
현재 v3.6 유물 인벤토리는 로컬 저장이다. 모바일 브라우저 캐시 삭제 시 초기화될 수 있다. 운영판에서는 Firebase 사용자 문서에 병합 저장하는 것을 권장한다.
