# 라니킹덤 v1.7 — 이동 가능한 UI·PC 상단 정리·영토 래스터 타일

## 사용자 요구별 실제 변경

1. **우클릭·글자 드래그 제한** — 게임 전체에서 브라우저 우클릭 메뉴를 방지하고 우클릭 드래그 이벤트를 캡처·중단. 버튼·정보 라벨·맵 HUD에서 브라우저 기본 글자 드래그/드래그 앤 드롭 비활성화. 저장 이름 입력, 메모 입력 등 실제 편집 필드는 선택·커서 유지.
2. **PC 기본 배치 개선** — 연구소는 화면 **왼쪽 위**, 주변 세력은 **오른쪽 위**, 영토 확장은 오른쪽 중간, 현재 임무는 연구 아래, 건설 대기열은 왼쪽 아래. 우측 세력과 확장이 기본적으로 겹치지 않게 분리. 모바일은 기존 하단 1개 탭을 여는 UX 보존.
3. **메뉴·HUD 위치 자유 이동** — 자원·점수·영토 확장·연구·주변 세력·건설 대기열·마을/필드 관리·하단 기능 메뉴·주요 임무·모바일 메뉴바 **10개 영역에 개별 이동 손잡이** 장착. 게임 내부 터치와 충돌하지 않게 손잡이에서만 드래그 시작. 손잡이의 방향키 이동 지원.
4. **접속 시 위치 복원** — 브라우저 `localStorage['rani-hud-layout-v2']`에 데스크톱/모바일별 정규화된 위치 저장. 페이지 새로고침·재접속해도 같은 비율 유지. 창 크기가 변하면 화면 밖으로 벗어나지 않게 clamp. `배치 초기화` 단추 또는 손잡이 더블클릭으로 복원. 왕국 플레이 데이터 저장 스키마에는 혼합하지 않음.
5. **영토 확장 진짜 이미지** — 기존 `UI.js`는 초소형 스와치에 색상만 채웠고, `TileDefs.js`의 previewColor만 사용. SVG 문제가 아니라 **이미지 자체가 없었던 것**. 직접 제작한 2.5D 11종 육각 지형(숲/농경지/초원/구릉/강/호수/늪/산악/채석장/마을/유적)을 **실제 WebP 640×480 스프라이트 `assets/terrain/rani-terrain-atlas.webp`**에 보관. 영토 확장 버튼에 11종 구별되는 래스터 그림 표시, 실제 Canvas 큰 미리보기도 같은 정규 타일 이미지 활용. 기존 회전 방향 접속 색상 오버레이·비용/해금/생산/타일 타입/저장 값은 보존.
6. 상단 글씨·아이콘의 터치 미스 및 패널 UI 중첩 방지. 단순 SVG 이모지로 회귀하지 않음.

## 검증
- `npm test`에 `scripts/check-ui-v17.mjs` 추가: 실물 WebP 자산·11개 지형·미리보기·위치 저장 및 우클릭 제한 코드 확인.
- `scripts/qa_ui_v17.py`: PC 1440×900 / 모바일 390×844 / 소형 320×700에서 WebP 실로드·11종 그림 위치가 모두 다른지·큰 Canvas 미리보기 차이, 실제 패널 손잡이 드래그, localStorage 저장, 페이지 리로드 뒤 위치 보존, 초기화, 우클릭 메뉴 차단, 기존 UI 콘솔 오류 검사.
- 기존 3D 마을·필드·경제·건설·세이브·육각 선택 및 PC/모바일 QA 모두 그대로.
- 실제 Windows/Android/iOS 기기 테스트는 자동 Chromium과 구별. GitHub Pages 배포 시간, CDN 및 브라우저 캐시 상태 별도.

## 메모
현재 구체적인 생산/건축 엔진은 기존 마을 3D 기반. 새 2.5D 지형 이미지는 **영토 확장 UI의 썸네일**이고 게임 실제 Three.js 타일 모델을 2D 이미지로 대체하지 않음. 외부 서버/온라인 전쟁/Firebase 신규 기능을 허위로 주장하지 않음.
