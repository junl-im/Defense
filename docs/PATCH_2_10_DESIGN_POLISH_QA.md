# v2.10.0 Design Polish QA

## 핵심 목표
- 모바일 기준으로 글씨/버튼/팝업 크기를 더 줄이고, 원화 배경 위에 얹는 UI 프레임을 클린 에셋 중심으로 재정리.
- 타워/건설 터치 영역을 다시 축소하여 주변 터치 오작동을 줄임.
- 시작 게이트와 전투 HUD의 과한 흰색/큰 패널 느낌을 줄이고, 어두운 프리미엄 판타지 톤으로 통일.

## 적용 내용
- `public/assets/ui/v2_10/` 신규 PNG/WebP UI 프레임 추가.
- 전투 상단 HUD, 하단 독, 건설 팝업, 타워 선택 패널을 v2.10 프레임으로 교체.
- 건설 지점 hit-zone: 42x30 기준으로 축소.
- 타워 선택 hit-zone: 36x48 기준으로 축소.
- 건설 팝업: 252x168 기준으로 축소, 카드 102x40 기준으로 재배치.
- 타워 선택 패널: 302px 폭으로 축소, 버튼/글자 소형화.
- 메인 메뉴 원화 위에 클린 버튼/재화/프로필 프레임을 별도 에셋으로 얹어 그림 속 UI와 코드 텍스트 정렬감을 보정.
- 모바일 첫 시작 DOM 게이트를 어두운 프리미엄 카드 톤으로 변경하고 글씨 크기를 더 작게 조정.
- HUD/쿨타임 갱신 주기를 소폭 늦춰 반복 텍스트 갱신 비용을 줄임.

## QA 포인트
- `?hit=1`로 건설 지점/타워/메인 메뉴 클릭존이 보이는 버튼 크기와 맞는지 확인.
- `?png=1`로 WebP 비활성 fallback 확인.
- `?lite=1` 또는 `?battery=1`로 저사양 모드에서 이펙트/필터가 줄어드는지 확인.
