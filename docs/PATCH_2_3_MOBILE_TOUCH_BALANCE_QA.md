# v2.3.0 Mobile Touch / Balance / UI QA Pass

## 목표

모바일 실제 플레이 기준으로 터치 오작동, UI 과밀, 설치/선택 팝업 겹침, 첫 화면 비율 문제를 다시 점검했다. 원화형 이미지를 계속 사용하되, 클릭존과 실시간 텍스트는 코드가 관리하는 구조를 유지한다.

## 수정 내용

- 타워 터치 영역 축소
  - 설치 후 타워 선택용 hit halo를 기존보다 작게 조정
  - `Tower` 자체 interactive footprint도 보이는 타워 크기에 더 가깝게 축소
  - `?hit=1`에서 실제 선택 영역을 확인 가능

- 건설 지점/설치 팝업 조정
  - 건설 지점 터치 영역 축소
  - 건설 가능 패드 이미지를 더 작은 v2.3 에셋으로 교체
  - 타워 설치 팝업을 324x214 기준의 컴팩트 모바일 UI로 변경
  - 카드 크기, 글씨 크기, 가격 표시, 역할 표시를 모바일 기준으로 재배치

- 상단 정보바 최적화
  - 상단 HUD 높이를 줄이고 버튼/텍스트를 작게 재배치
  - 사운드 / 전투 시작 / 속도 / 정지 버튼을 우측 가장자리에서 살짝 안쪽으로 이동
  - 전장 안전 영역을 `top 82`, `bottom 448`로 재조정

- 타워 선택 패널 조정
  - 패널 폭을 390 기준으로 줄임
  - 타워 정보 글씨를 작게 조정
  - 패널 자동 클램프 로직 유지
  - 강화/타겟/철거/교체 버튼을 모바일용으로 소형화

- 게임 밸런스 1차 보정
  - 초반 몬스터 HP/속도 일부 완화
  - 초반 시작 골드/라이프 소폭 상향
  - 타워 가격/사거리/화력 일부 재조정
  - 모바일 조작 난이도 때문에 초반 실패 압박을 조금 낮춤

- 영웅 디자인 조정
  - 영웅 표시 크기를 줄이고 터치 영역을 실제 캐릭터 크기에 맞게 축소
  - 신규 v2.3 영웅 컷아웃 적용

- 첫 화면/모바일 시작 화면 보정
  - 모바일 시작 게이트 카드 크기와 글씨를 작게 조정
  - 로그인 화면 로고/패널 크기를 소폭 축소
  - 버전 표기 v2.3.0으로 갱신

- 비주얼 에셋 점검
  - v2.3 전투 배경 8종 추가
  - 첫 숲길 배경은 원본을 그대로 쓰지 않고 톤/가독성/안전 영역을 재보정
  - 메인 메뉴는 기존 베이크 UI 위에 클린 패널을 다시 얹고 코드 텍스트/클릭존과 맞춤

## QA 주소

- 기본 실행: `http://localhost:5173/`
- 클릭존 확인: `http://localhost:5173/?hit=1`
- 기존 contain 보기 비교: `http://localhost:5173/?fit=contain&hit=1`
