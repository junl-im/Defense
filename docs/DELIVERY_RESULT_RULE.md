# 결과 전달 필수 규칙

이 프로젝트의 모든 패치 결과는 아래 순서를 반드시 따른다.

## 1. 작업한 내역

- 시스템, 성능, 기술, 기능, 엔진, 문제점, 개선점, 오류, 버그, 예외사항을 구분해 실제 수정과 검증 결과를 적는다.
- 실행하지 못한 검증은 통과했다고 표현하지 않고 제한 사유를 명시한다.
- 발견했지만 다음 패치로 넘긴 위험은 숨기지 않고 추적 항목으로 남긴다.

## 2. 다운로드 파일

항상 아래 두 파일을 함께 제공한다.

1. 전체 프로젝트 통파일 ZIP
2. 기존 프로젝트에 덮어쓰는 direct-overlay 패치 ZIP

패치 ZIP의 적용 대상은 `overlay/` 내부뿐이며, 안내문과 매니페스트는 저장소 루트에 복사하지 않는다.

## 3. 다음 예정 내역

- 다음 버전에서 처리할 구조 개선, 성능 계측, 기능 보강, 잔여 위험을 우선순위와 함께 적는다.
- 이미 완료한 항목을 다음 예정으로 반복 기재하지 않는다.

이 문서는 v1.0.48부터 `PROJECT_HANDOFF.md`, 릴리스 보고서, 최종 사용자 응답의 공통 전달 계약으로 사용한다.
