# v1.0.15 빠른 시작 · 아트 승인 파이프라인 패치

기준 버전은 **v1.0.14 / b24.14**이며 적용 후 **v1.0.15 / b24.15**가 됩니다.

## 수정

- 시작 화면에서 마스코트 이미지가 실패할 때 `alt` 설명문이 둥둥 떠다니던 문제 제거
- 경량 마스코트와 배경을 먼저 표시하고 고해상도 이미지는 게임 준비 후 유휴 시간에 교체
- 최초 로딩 자산을 53개 전체 대기에서 필수 타이틀 자산 우선 방식으로 분리
- 선택 자산, 몬스터, 보스, GLB 및 전장 아틀라스는 백그라운드에서 병렬 준비
- 서비스 워커 최초 설치 시 대형 아트 라이브러리 전체를 받던 동작 제거
- 에셋 파이프라인에 모바일 2개 / PC 4개 동시 로딩과 캐시 재사용 적용
- 승인 25개, 격리 4개를 구분하는 v1.0.15 아트 승인 계약 추가

## 안전 정책

고해상도 이미지가 실패해도 문자가 화면에 노출되지 않으며, 경량 마스코트 또는 무문자 배경으로 복구합니다. 백그라운드 에셋이 늦어도 절차형 안전 그래픽으로 전투 진입이 가능합니다.
