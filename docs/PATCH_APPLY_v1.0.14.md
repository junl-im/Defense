# v1.0.14 패치 적용 방법

## 직접 붙여넣기

1. 현재 프로젝트가 v1.0.13인지 확인합니다.
2. 패치 ZIP을 별도 폴더에 압축 해제합니다.
3. 압축 해제된 모든 파일과 폴더를 프로젝트 최상위 폴더에 붙여넣습니다.
4. 같은 이름의 파일은 모두 덮어씁니다.
5. 삭제할 파일은 없습니다.
6. 가능하면 아래 검사를 실행합니다.

```text
npm run verify:release:v114
npm run build:static
```

## Windows 원클릭 적용

프로젝트 폴더를 `APPLY_PATCH_WINDOWS.bat` 위로 드래그합니다. 패치 전에 변경 대상 파일은 `__backup_before_v1.0.14` 폴더로 백업됩니다.

## 브라우저 캐시

적용 후 이전 이미지가 남아 보이면 브라우저를 완전히 닫았다가 다시 실행하거나 서비스 워커 캐시를 한 번 갱신합니다. v1.0.14는 `b24.14` 캐시를 사용합니다.
