# Combat Presentation Contract v4.1.0

## 목표

모바일 화면에서 캐릭터가 실제 목표를 바라보고 공격한다는 사실이 즉시 읽히도록 방향, 발사 위치, 타격 순간, 화면 반응을 하나의 계약으로 묶는다.

## 공격 방향

- 플레이어는 공격 대상 방향으로 선회한 뒤 0.18초 동안 공격 방향을 잠근다.
- 영웅 기술은 가장 가까운 유효 대상을 기준으로 0.36초 방향을 잠근다.
- 수호대는 공격 0.16초 전부터 목표를 예측 선회한다.
- 발사 순간에는 목표 방향에 90% 가까이 정렬한다.
- 적은 신목 공격 직전에 신목 중심을 바라본다.
- 발사 위치는 모델 중심이 아니라 `WeaponSocket`의 월드 좌표를 우선 사용한다.

## 임팩트 계층

| 계열 | 주요 형태 | 반응 |
|---|---|---|
| 전사/기본 | 베기 호 | 짧은 히트스톱, 작은 흔들림 |
| 바람/궁수 | 초승달 | 얇고 빠른 확산 |
| 화염 | 폭발 코어 | 파편 2단 |
| 서리 | 빙정 | 위로 튀는 결정 |
| 바위 | 지면 충격파 | 큰 링과 강한 흔들림 |
| 방울 | 회전 문양 | 원형 파동 |
| 번개 | 스파크 | 빠른 회전 파편 |
| 기술/궁극 | 다층 폭발 | 화면 플래시와 강화 히트스톱 |

치명타, 보스 타격, 궁극기만 화면 전체 플래시를 사용한다. 저사양 기기는 동시 효과를 34개로 제한하고 짧은 일반 히트스톱을 생략한다.

## 자동 진군

- 웨이브 보상 선택이 끝난 시점부터 10초를 센다.
- 유물, 계약, 축복 모달이 열려 있는 동안에는 시작하지 않는다.
- 일시정지 중에는 카운트다운이 정지한다.
- 버튼을 누르면 남은 시간과 무관하게 즉시 시작한다.
- 마지막 3초는 카운트 링, 진동, 배너로 알린다.
- 마지막 웨이브에는 자동 진군을 예약하지 않는다.

## 접근성

- `reducedMotion` 사용 시 히트스톱과 버튼 펄스를 제거한다.
- 화면 흔들림과 플래시는 기존 사용자 강도 설정을 따른다.
- 자동 진군 버튼의 ARIA 레이블에 남은 시간과 즉시 시작 가능 여부를 포함한다.

## 금지

- SVG 파일 및 인라인 SVG
- 프레임마다 신규 텍스처 생성
- 무제한 파티클 또는 효과 메시 생성
- 전투 대상과 관계없는 고정 월드 방향 발사

## 프리미엄 시각 디자인 규칙

- 타격은 밝은 코어, 속성색 후광, 방향성 슬래시, 작은 파편의 4개 레이어로 구성한다.
- 치명타와 보스 타격만 화면 슬래시·확산 링을 사용해 일반 공격과 위계를 분리한다.
- 자동 진군은 버튼 숫자만 바꾸지 않고, 월문 문양·진행 게이지·남은 초가 있는 전열 정비 패널로 표시한다.
- 패널은 Moonstone HUD의 보라·금색·청록 팔레트와 둥근 입체 프레임을 사용한다.
- SVG, 인라인 벡터, 외부 아이콘 폰트는 사용하지 않는다.
- 저사양 모드에서는 파편 개수를 줄이되 코어·후광·방향성은 유지한다.
