# 라니킹덤 v1.0 — 실제 3D 필드 카메라·마을 탐색 UX

## 변경 사항
- 기존 Three.js 기반 **마을 건축·연구·경제·병력·로컬 저장**을 유지한다. 2D/DOM 마을로 교체하지 않는다.
- 필드의 **마을 찾기**에서 실제 세력 데이터를 고르면 텍스트만 바뀌는 대신 **해당 3D 대표 건물 좌표로 카메라 중심을 이동**한다. 3D 건물 직접 클릭과 이름표 클릭도 같은 동작을 한다.
- 상단에 크기가 작은 **내 거점** 버튼을 추가해 자신의 거점을 바로 다시 찾는다. 기존 **🏠 마을**은 건설 마을 화면 복귀로 구분한다.
- 선택한 도시 이름표에 시각 강조 및 `aria-pressed` 상태 표시. 게임을 과도하게 가리는 새로운 패널은 도입하지 않는다.
- 필드에서 마우스 휠 줌, 손가락 1개 드래그 이동, 2개 핀치 확대·축소를 지원한다. 화면을 움직여도 카메라는 실제 이동된 목표 지점을 본다.
- 마을 전용 `CameraController`는 필드 모드일 때 휠/터치/키보드 입력을 무시한다. 필드를 보는 도중 마을 카메라가 몰래 바뀌는 이중 입력 문제를 막는다.

## 회귀검증
- 기존 `scripts/qa_village.py` 테스트에 3D 세력 선택 후 실제 카메라 포커스 좌표, 필드 휠 줌, 모바일 PointerEvent 핀치, 마을 카메라 줌값 불변, **내 거점** 복귀 테스트 추가.
- GitHub Actions `Validate Korean SLG` 기존 Node/Chromium 데스크톱·모바일 테스트로 검증. 통과 전에는 main 병합·배포 완료로 표기하지 않는다.
- 수동 실기기 점검 항목: iOS Safari·Android Chrome 손가락 드래그/핀치, 320px 패널 겹침, 줌 후 거점 직접 터치, 마을 복귀 뒤 기존 제스처.
- 브라우저 합성 QA와 실제 모바일 기기 FPS 측정은 별개이다.

## 고정 사항 및 미구현
- 외부 세력, 실제 영토·병력·공격 가능 조건은 원래 `FactionSystem`, `ArmySystem.canAttack` 그대로다. 가짜 공격/새 병력 생성 금지.
- 장거리 행군, 약탈 경로, PvP 연맹, 실시간 서버 판정 및 Firebase Auth/Firestore 저장은 **아직 미구현**이다.
- 저장 구조 v3, Firebase `web-game2` 프로젝트, LICENSE, CC0 에셋 저작권 고지 변경 없음.
- 원격 GitHub 수정은 Windows `D:\\K-city-webgame\\Defense`의 로컬 작업 폴더를 자동 갱신하지 않는다.
