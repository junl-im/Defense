# Kingdom Seed v2.6.0 Massive Campaign Expansion

## 목적
v2.6.0은 모바일 기준의 초대규모 확장 패치입니다. 단순히 화면 하나를 고치는 방식이 아니라, 캠페인 분량, 전투 변수, 원화급 이미지 활용, 스테이지 보상, 작전 변수, 타워 시너지, WebP 로딩 경로를 함께 확장했습니다.

## 주요 변경

### 1. 캠페인 확장
- 기존 8개 스테이지에서 12개 스테이지로 확장했습니다.
- 신규 원정 스테이지:
  - Stage 009 수정 숲의 반격
  - Stage 010 화염 왕관 협곡
  - Stage 011 공허 정원
  - Stage 012 천공 왕좌 결전
- 신규 스테이지별 경로, 설치 포인트, 웨이브, 해금 조건을 추가했습니다.
- 월드맵 노드를 12개 구조로 재배치했습니다.

### 2. 원화급 이미지 활용 확대
- 전투 배경 v2.6 12종 추가.
- 신규 스테이지 카드 4종 추가.
- 신규 맵 썸네일 4종 추가.
- v2.6 UI 세트와 전장 장식 prop 세트를 추가했습니다.
- 전투 배경 / 카드 / UI / props는 WebP 우선 로딩 대상에 포함했습니다.

### 3. 전투 작전 변수 시스템
- 스테이지별 로테이션 작전 변수를 추가했습니다.
- 예시:
  - 봄바람 보급로
  - 상단 지원
  - 안개 낀 길목
  - 붉은 달
  - 마력의 흐름
  - 공중 습격
  - 공성 북소리
  - 왕실 격려
  - 정예 순찰대
- 변수는 시작 골드/생명, 적 체력/속도/방어, 보상, 타워 화력/공속에 영향을 줍니다.

### 4. 웨이브 이벤트 시스템
- 일부 웨이브마다 동적 이벤트가 발생합니다.
- 이벤트 예시:
  - 왕실 보급품: 골드 보급 및 일부 타워 긴급 강화
  - 정예 선봉대: 적 강화 및 보상 증가
  - 마력 개화: 스킬 쿨타임 일부 회복
  - 폭풍 행군: 적 속도 증가 및 타워 긴급 강화 유도
- 이벤트는 별도 배너와 아이콘으로 표시됩니다.

### 5. 타워 시너지 / 지휘 오라
- 타워 조합 수에 따라 시너지 보너스가 적용됩니다.
- 2종 이상: 복합 방어
- 3종 이상: 삼각 전술
- 4종 모두: 왕국 연합
- 작전 변수의 타워 보너스와 함께 누적되어 전장 위 오라로 표시됩니다.

### 6. 보상/업적/미션 확장
- 신규 Stage 009~012 보상 테이블 추가.
- Stage 012 클리어 업적 추가.
- 일일 도전 스테이지 후보를 Stage 012까지 확장.
- 보스 클리어 미션 판정에 신규 고난도 보스 스테이지를 포함했습니다.

### 7. 성능/모바일 체크
- 신규 대형 이미지는 PNG fallback과 WebP 우선 로딩 구조를 유지합니다.
- 전투 배경은 HUD/유닛/클릭존과 분리된 클린 배경 구조입니다.
- prop 애니메이션은 `?lite=1`에서 줄어들도록 했습니다.
- 클릭존 확인은 `?hit=1`, PNG fallback 확인은 `?png=1`, 기존 full preload 확인은 `?fullpreload=1`을 계속 사용할 수 있습니다.

## 검증
- `npx tsc --noEmit` 통과.
- `npm run build`는 컨테이너 node_modules의 Rolldown optional native binding 누락으로 실패했습니다. 로컬에서는 `npm install` 후 재시도해야 합니다.

### 8. v2.6 추가 QA 보강
- 대량 웨이브에서 적 1마리당 타이머를 만들던 구조를 그룹 스트리밍 타이머로 바꿔 모바일 랙 가능성을 줄였습니다.
- 정예 적 출현 시 전용 배지와 짧은 스폰 알림을 추가했습니다.
- 메인 메뉴에 원정/웨이브 변수/타워 시너지 안내 카드를 추가해 신규 시스템 진입성을 높였습니다.
- RunModifier 시스템과 WaveEvent 시스템이 동시에 적용되도록 적 스폰 변환 순서를 정리했습니다.
