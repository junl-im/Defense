# P0 Runtime Expansion v3.9.0

## 목표

IP 마스터리스트의 P0 항목을 실제 브라우저 전투에 연결하되, 기술 후보를 최종 아트로 오인하지 않는다.

## 플레이어 직업

| 직업 | 역할 | 런타임 차이 | 모델 상태 |
|---|---|---|---|
| 도깨비 전사 | 균형형 | 안정적인 기본 공격과 범위 폭발 | 골든 샘플 아트 리뷰 |
| 도깨비 궁수 | 원거리 관통 | 긴 사거리, 관통 기본 공격, 다중 화살 기술 | 공용 리그 기술 후보 |
| 도깨비 법사 | 광역 제어 | 광역 기본 공격, 범위 기술, 둔화 | 공용 리그 기술 후보 |

직업별 무기와 오라는 `WeaponSocket`, `AccessorySocket`에 런타임 키트로 장착한다.

## 신규 일반 적

- 달그림자 귀신: 결계 침투형, 방울 약점, 달빛 혼백 전리품.
- 백골 무사: 방패 압박형, 바위 약점, 백골 방패편 전리품.
- 먹구름 까마귀: 고속 우회형, 바람 약점, 먹구름 깃 전리품.

세 모델은 Skin·7클립·소켓·PBR 텍스처 슬롯 기술 조건을 갖췄지만 전용 최종 메시와 아트 승인은 대기 상태다.

## UI

- 직업 선택 카드 3개와 역할 요약.
- 유물 무기·관·후광 장착 상태 표시.
- 보스 의도를 타격·소환·제어 PNG 아이콘과 진행 게이지로 표시.
- 320px부터 긴 문구를 축약하며 기존 HUD 안전 레일을 유지.

## 자산 계약

- 신규 256×256 PNG 아이콘 9종.
- SVG 사용 0건.
- 텍스처 추정 예산 56.19MB / 64MB.
- 최종 제작 승인 0종, 기술 리뷰 8종, 프로토타입 11종.
