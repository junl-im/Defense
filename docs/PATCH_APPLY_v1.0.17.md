# v1.0.17 패치 적용 방법

기준 버전은 **v1.0.16 / b24.16**입니다.

1. 실행 중인 개발 서버와 게임 창을 종료합니다.
2. 기존 프로젝트 폴더를 복사해 백업합니다.
3. 직접 붙여넣기 패치 ZIP을 압축 해제합니다.
4. 압축 해제된 모든 파일과 폴더를 기존 프로젝트 최상위 폴더에 덮어씁니다.
5. `npm run verify:release:v117` 또는 `npm run verify`를 실행합니다.
6. 브라우저 캐시가 이전 화면을 유지하면 서비스 워커와 사이트 데이터를 한 번 삭제한 후 다시 접속합니다.

삭제되는 기존 파일은 없습니다.
