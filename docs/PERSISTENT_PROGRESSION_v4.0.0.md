# 영구 장비·직업 숙련 설계 v4.0.0

## 목표

한 판의 운빨 재미를 해치지 않으면서 다음 판을 준비하는 명확한 영구 성장 축을 제공한다.

## 장비 슬롯

- 무기: 대장 피해, 기술 피해, 보스 피해
- 부적: 기술 피해, 혼불 획득, 수집 범위
- 신발: 이동 속도, 질주 재사용

장비 변경은 현재 진행 중인 판의 복합 보정을 훼손하지 않도록 다음 원정부터 적용한다.

## 장비 보상

- 웨이브 3 미만: 장비 보상 없음
- 웨이브 3 이상: 일반·희귀 후보
- 웨이브 5 이상: 영웅 후보
- 웨이브 8 이상: 전설 후보
- 원정 승리: 신화 후보 포함

이미 보유한 장비가 다시 나오면 등급에 비례한 장비 정수로 변환한다.

## 직업 숙련

- 전사·궁수·법사 경험치 별도 저장
- 기본 레벨 1, 최대 레벨 10
- 원정 진행 웨이브와 승리 여부에 따라 경험치 지급
- 레벨마다 대장 피해, 기술 피해, 이동 속도 소폭 상승

숙련 보정은 장비·유물·영구 특성보다 별도 단계에서 곱연산해 수치 출처를 추적할 수 있게 한다.
