# Kingdom Seed v2.24.0 Premium Art Performance QA

## 목표

v2.23의 빠른 접속/빠른 시작 구조는 유지하면서, fast start 모드에서 v2.16~v2.22의 누적 장식 에셋이 스킵되어 화면이 단순한 투톤 코드 그래픽처럼 보이던 문제를 개선했습니다.

이번 패치는 모든 과거 장식을 다시 로드하지 않고, 고품질 핵심 원화풍 에셋만 기본 로드합니다.

## 핵심 변경

- 버전 2.24.0 갱신
- 신규 `public/assets/ui/v2_24/` 프리미엄 원화풍 에셋 추가
  - PNG 42개
  - WebP 42개
  - 총 84개 신규 이미지 파일
- 기본 fast start 모드에서 v2.16~v2.22 누적 장식 레이어는 계속 억제
- 대신 v2.24 핵심 원화풍 레이어만 기본 적용
- 저사양 기기에서는 v2.24 아트의 무한 트윈/장식 애니메이션 수를 자동 축소
- BootScene WebP 변환 패턴에 v2_24 추가
- 로그인/로비/월드맵/전투 화면 모두 v2.24 전용 원화풍 레이어 적용
- `?fullart` 모드에서는 기존 누적 장식도 함께 확인 가능

## 디자인 개선 방향

- 단순 투톤/스티커 느낌을 줄이고, 다색 그라디언트/광원/펄/금박/페인터리 텍스처를 사용
- 로그인 화면: 원화풍 카드 프레임, 유리 타이틀 플라크, 왕실 여우 기사/달빛 사슴 마스코트
- 로비: 원정 본부 배너, 벨벳 네비 러그, 재화 유물 뱃지, NPC 3종
- 월드맵: 오일페인트 미리보기 프레임, 보석 스테이지 링, 프리즘 루트, 오로라 보스 게이트
- 전투: 상단 오일페인트 레이스, 하단 스킬 독, 스킬 카드 3종, 보스/콤보/마나 장식

## 성능 개선 방향

- 무거운 누적 아트 전체 로드를 되돌리지 않음
- 기본 로드 추가분은 v2.24 핵심 42개 에셋으로 제한
- WebP 우선 로드 유지
- 저사양 기기에서는 장식 트윈 수를 줄여 전투 중 랙을 완화
- `?fullart` 옵션이 없으면 기존 대량 장식 레이어는 기본적으로 켜지지 않음

## 검증

```bash
npx tsc --noEmit --pretty false
npm run build
```

둘 다 통과했습니다. Vite의 큰 번들 경고는 기존 구조에서 발생하는 경고이며 실행을 막는 오류는 아닙니다.
