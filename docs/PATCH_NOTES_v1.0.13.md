# v1.0.13 수호성·캐릭터 비주얼 안정화 패치

## 핵심 수정

- 수호성에 남아 있던 구형 3D 신목 메시와 이전 수호성 스프라이트를 정리합니다.
- 전투 화면에는 승인된 수호성 스프라이트 1개와 통합 월드 HP 바 1개만 유지합니다.
- 자동 생성 P0 11방향 시트 4종은 검토 자료로 보존하되 실제 런타임 선택에서 격리합니다.
- 영웅·수호대·몬스터·보스는 기존 고품질 IP 원화를 우선 사용합니다.
- 캐릭터의 과도한 원근 압축, 지면 위치와 크기 값을 완화했습니다.
- 기존 저장 데이터, IP 메가베이스, 아트 바이블과 v1.0.12 자산 파일은 삭제하지 않습니다.

## 적용 기준

기준 버전은 v1.0.12 / b24.12이며 적용 후 v1.0.13 / b24.13이 됩니다.
