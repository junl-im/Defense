# v1.0.24 적용 안내

기준 버전: v1.0.23 / b24.23

1. 게임 폴더를 종료합니다.
2. 직접 붙여넣기 ZIP을 풀어 프로젝트 최상위 폴더에 덮어씁니다.
3. 숨김 폴더 `.github`도 함께 덮어씁니다.
4. 배포 후 브라우저를 완전히 종료하고 다시 접속합니다.
5. PWA로 설치했다면 기존 바로가기를 다시 실행하면 v1.0.24 캐시로 자동 교체됩니다.

원클릭 패치는 기존 변경 파일을 `logs/backups/v1.0.24_날짜_시간`에 백업합니다.
## CI 루트 위생 오류 자동 복구

기존 저장소 최상위에 `README_PATCH.txt`가 남아 있어도 `npm run verify`와 `npm run build` 시작 전에 `logs/legacy-root-output/README_PATCH.txt`로 자동 이동됩니다. 수동으로 삭제하지 않아도 됩니다.
