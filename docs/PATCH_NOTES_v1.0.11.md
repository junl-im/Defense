# 패치 노트 — v1.0.11 IP Knowledge Megaforge

- 공개 버전: `1.0.11`
- 빌드 ID: `b24.11`
- IP 메가베이스: `4.0.0`
- 아트 스타일 잠금: `DD-ABSOLUTE-ART-BIBLE-2.0`

## 핵심 업데이트

### 초초대규모 IP 지식 자산

총 **147,232개**의 제작 지식 레코드를 추가했습니다.

- 베이스 자산 8,192개
- 영웅·수호대·몬스터·보스 11방향 액션 89,232개
- 수호성·타워 성장/피격/행동 10,560개
- PC·모바일 HUD 계약 480개
- 실제 브라우저 10웨이브 비주얼 QA 5,040개
- 장시간 메모리·텍스처·GPU 회귀 프로필 960개
- VFX·UI·환경·사운드 관계 그래프 32,768개

### 게임다운 그래픽 목표 이미지

전투 화면 업그레이드 키 비주얼과 아트 제작 보드를 프로젝트에 포함했습니다.

- `public/assets/ip-mega-v4/reference/gameplay-key-visual-v4.webp`
- `public/assets/ip-mega-v4/reference/art-production-board-v4.webp`

두 이미지는 최종 런타임 자산 승인이 아니라 제작 방향과 품질 기준을 맞추기 위한 참고 기준선입니다.

### 11방향 제작 계약

영웅·수호대·몬스터·보스는 좌우 반전으로 방향을 채우지 않습니다. 11개 방향을 독립 제작하며 발 중심 접지, 피격점, 무기와 VFX 소켓을 함께 기록합니다.

### 액션 차별화

근접, 원거리, 마법, 포효, 타워 발사에 서로 다른 준비·유효·회수 프리셋을 추가했습니다. 각 레코드에는 프레임 수, FPS, 충돌 시점, 캔슬 시점, VFX 정책이 포함됩니다.

### 수호성·월드 HP·보스 보정

- 수호성 성장 5단계
- 피격 상태 4단계
- 행동 모드 3종
- 보호막·브레이크·상태 이상 통합 월드 HP 계약
- 보스 발 접지, 약점, 피격점, 화면 점유율 보정 규격

### PC·모바일 HUD 분리

PC는 3레인 전술 셸, 모바일은 엄지 영역 전투 셸을 사용합니다. 하나의 HUD를 단순 축소하지 않으며 안전 영역과 정보 밀도를 별도로 관리합니다.

### 자산 라이브러리

게임 설정 화면과 제작 콘솔에서 `IP 지식 자산 메가베이스 v4` 브라우저 라이브러리를 열 수 있습니다. 샘플 자산 검색, 카테고리·역할 필터, 제작 프롬프트와 기술 규격 확인을 지원합니다.

## 중요한 제한

이번 패치는 **제작 가능한 지식 자산과 그래픽 기준선**을 초대규모로 확장한 패치입니다. 최종 원화·스프라이트·GLB 8,192개가 모두 완성 또는 승인되었다는 의미는 아닙니다.

- 지식 생성: 완료
- 최종 아트: 계획 상태
- 자동 생산 승인: 없음
- 최종 아트 승인: 0

실제 제작 자산은 P0 골든 세트부터 단계적으로 교체하고 자동 비주얼·성능 검사를 통과한 뒤 승인해야 합니다.
