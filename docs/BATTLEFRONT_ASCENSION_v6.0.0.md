# Battlefront Ascension v6.0.0

## 목표

전투 난이도, 적 구성, 상태이상, 개체 예산, 성능 계측을 분리된 임시 로직이 아니라 하나의 검증 가능한 런타임 체계로 통합한다.

## Encounter Director 1.0

일반 웨이브는 다음 교리 중 하나를 선택한다.

- 달빛 진군: 기본 균형형
- 백귀 군집: 개체 수 증가, 체력 감소, 빠른 생성
- 철갑 야행: 개체 수 감소, 체력·공격력 증가
- 폭풍 질주: 이동 속도와 빠른 적 비중 증가
- 주술 행렬: 주술사·혼령 계열 비중 증가
- 월식 강림: 정예 확률과 위험·보상 증가
- 우두머리 강림: 보스 웨이브 전용

신목 체력이 낮으면 압력을 제한적으로 낮추고, 높은 체력으로 빠르게 클리어하면 압력을 제한적으로 높인다. 적응 범위는 공정성을 위해 고정 상한 안에서만 움직인다.

## 원소 상태이상

- 화염: 연소 지속 피해
- 달빛: 빙결 이동 저하
- 바람: 풍인 피해 증폭
- 산: 균열 이동 저하와 피해 증폭
- 혼령: 공명 주기 피해와 피해 증폭
- 천둥: 감전 주기 피해와 피해 증폭

상태이상은 적 개체에 독립적으로 저장되며 사망·재활용 시 반드시 정리한다.

## Runtime Budget Manager

현재 품질 프로필과 FPS·P95·위험 프레임 비율을 기준으로 활성 적 개체 상한을 조정한다. 상한 도달 시 웨이브 진행을 삭제하지 않고 생성만 짧게 지연한다.

## Combat Telemetry

다음 값을 로컬 진단과 성능 내보내기에 포함한다.

- 웨이브별 공세 교리
- 클리어 시간과 무피해 여부
- 피해원별 누적 피해
- 상태이상 적용 횟수
- 일반·보스 처치
- 런타임 예산으로 지연된 생성 횟수

## Save Schema 6

이전 스키마에서 처음 실행할 때 주요 설정과 로컬 점수를 `dokkaebi-save-backup-v6`에 백업한 뒤 스키마 버전을 기록한다.
