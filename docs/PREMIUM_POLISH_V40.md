# PREMIUM POLISH V4.0

## 발견한 문제와 보완 방향

1. PC UX
   - PC는 가로 화면이 기본이므로 회전/전체화면 강제는 몰입을 해칩니다.
   - v4.0은 CSS 레벨에서 데스크톱 회전을 무조건 막고 시작 게이트를 숨깁니다.

2. 전투 UI
   - 웨이브 카운트는 반드시 한 곳에서만 보여야 합니다.
   - 상단 WAVE 패널은 현재 진행 정보만, 진행 버튼은 다음 액션만 담당하는 구조가 가장 명확합니다.

3. 프리미엄 디자인
   - 버튼, 패널, 보상창, 툴팁의 재질감을 하나로 통일해야 합니다.
   - 금속 테두리, 리벳, 골드 하이라이트, 어두운 판넬, 짧은 광택 움직임을 공통 문법으로 사용합니다.

4. 모바일 마감
   - 노치/홈 인디케이터 영역 대응을 CSS safe-area로 보강했습니다.

5. 성능
   - 새 비주얼은 PNG 에셋 위주로 처리하고 DOM 애니메이션을 최소화했습니다.

## 다음 권장

- 실제 플레이 캡처 기준으로 HUD 가독성 측정
- 전투 중 모든 팝업의 z-depth 충돌 점검
- 타워 패널의 버튼 수를 1차/2차 액션으로 분리
- 월드맵/제작소/임무/영웅전당을 같은 디자인킷 컴포넌트로 통합
