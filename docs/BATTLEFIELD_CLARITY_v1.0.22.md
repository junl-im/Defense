# Battlefield Clarity v1.0.22

## 목적

실전 전투에서 캐릭터 방향이 빠르게 흔들리는 현상, 몬스터 HP 바 중첩, 상단 HUD와 보스 정보 충돌, 장시간 프레임 압력 누적을 줄인다.

## 구현

- 11방향 후보 프레임에 상태별 홀드 시간과 공격 중 방향 잠금을 적용한다.
- 월드 좌표를 화면 좌표로 투영해 인접 HP 바를 최대 5개 레인으로 분산한다.
- `ResizeObserver`와 `visualViewport`로 실제 HUD 하단을 측정해 보스·보조 패널 위치를 계산한다.
- 지속적인 FPS 압력에서는 몬스터 오라와 상태 장식을 단계적으로 축소한다.
- 진단 객체: `window.__DOKKAEBI_BATTLEFIELD_CLARITY_V122__`

## 승인 경계

신규 캐릭터 원화 최종 승인은 추가하지 않는다. 기존 푸푸도깨비 11방향 승인 자산을 안정적으로 표시하는 런타임 개선이다.
