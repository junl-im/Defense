# Kingdom Seed v2.7 - Premium Tower & Visual Pass

## 핵심 목표
- 타워가 "짓고 끝"이 아니라, 판매/교체/타겟/긴급강화/최종진화까지 이어지는 운영 오브젝트가 되도록 확장.
- 월드맵과 전투 화면의 색감, 패널, 폰트, 타워/몬스터 실루엣을 한 단계 더 현대적인 2.5D 느낌으로 정리.
- 다음 공세 프리뷰를 제공해 플레이어가 타워 교체와 최종 진화를 판단할 수 있게 함.

## 최종 진화
각 타워는 Lv.3 이후 2개 갈래 중 하나를 선택한다.

- 궁수: 장궁 초소 / 저격 감시탑
- 마법: 비전 첨탑 / 저주 오벨리스크
- 병영: 성기사 막사 / 돌격대 막사
- 포탑: 대구경 박격포 / 충격포 진지

## UI 변경
- 타워 패널 높이와 정보 계층 재정리.
- 최종 진화 선택 시 설명/비용/전술 역할을 함께 표시.
- 하단 우측에 다음 공세 프리뷰 표시.
- 월드맵 배경을 더 진한 콘솔풍 프리미엄 캠페인 맵으로 교체.

## 렌더링 변경
- `pixelArt: false`, `antialias: true`로 고해상도 PNG 에셋이 더 부드럽게 보이도록 변경.
- CSS canvas image-rendering을 auto로 전환.

## 주의
이 패치는 v2.6 이후 상태 기준이다. v2.5 이하에 바로 적용하면 TowerMastery 연동부가 누락될 수 있다.
