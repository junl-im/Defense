# 라니킹덤 v5.7 — 게임다운 첫 화면 + 실제 건설 편의성 개선

- 기존 승인한 고해상도 WebP 왕실 로고·메인 버튼과 Fiefdom의 실제 방향별 PNG 성채·원형 탑·주택·참나무 이미지 및 기존 무역선 WebP로 타이틀 해안 풍경 구성. 추가 SVG·재단 없는 CSS 원본 이미지만 사용. PC·모바일 보기, 저사양 모션 감소 대응.
- 실제 저장 게임 목록이 있을 경우에만 '이어하기' 버튼 표시. 누르면 Fiefdom 원본 저장 목록을 열고 로드. '게임 시작' 버튼은 원본 실제 지역→영주→월드 입장 단계 유지.
- 실제 배치 판정은 original Placement.check 기반. 모든 건물 크기를 포함한 성공 판정에서만 지형 오버레이·설치 가능 표시, 불가할 경우 정확한 판정 사유 한국어 표기. 지형·자원·충돌·완만한 땅·영토·해안 등 실제 원인 표시. 고스트에 건물 크기(가로×세로 칸)와 회전 안내.
- 선택 건물 육각 메뉴는 지금 가능한 행동만 시각적으로 노출. 기존 엔진의 강화·수리·성문·생산·철거 콜백 보존, 사용 불가 이유는 메뉴 안내 문구에 표시. 전체 건설 메뉴는 원래 하단 건설 메뉴 사용.
- 인게임 튜토리얼은 현재 실제 건물 목록을 읽어 주택→벌목장→밀 농장→시장 순서 중 없는 건물을 안내, '건설 메뉴 열기'는 기존 버튼을 실행. 닫기/완료는 사용자가 직접 선택.
- 로고와 건축 원본 보존, SVG 0, Fiefdom AGPL 및 독립 아트 라이선스 유지. 저장 데이터 이행 없음.
