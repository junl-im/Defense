# Kingdom Seed v2.9 Premium Visual Identity Overhaul

## 목표
프로토타입 느낌을 줄이고, 상용 모바일 디펜스 게임처럼 보이도록 UI/UX와 에셋 톤을 통일합니다.

## 적용 범위
- 타이틀 화면: 성채/실루엣/고급 로그인 패널
- 월드맵: 캠페인 지도, 스테이지 카드, 잠금/클리어 상태 강화
- 전투맵: 8개 스테이지 배경 2.5D 리마스터
- 타워: Lv.1~3 + 최종 진화 8종 이미지 재생성
- 몬스터: 31종 36프레임 다방향/공격/사망 시트 재생성
- HUD: 상단/하단 패널, 버튼, 카드, 보상 패널 리디자인

## 디자인 원칙
1. 직접 모방이 아니라 장르 문법 차용: 양피지/철제 프레임/보석 포인트/2.5D 배경.
2. 정보 우선순위: 전투 수치와 버튼은 더 선명하게, 장식은 뒤로.
3. 실루엣 구분: 소형/비행/탱커/보스가 멀리서도 다르게 보이게.
4. GitHub Pages 친화: PNG 중심, 외부 폰트 파일 없음, 빌드 의존성 추가 없음.

## 다음 추천

- WebP 변환과 texture atlas packing으로 5MB 이하 용량 최적화 가능.
