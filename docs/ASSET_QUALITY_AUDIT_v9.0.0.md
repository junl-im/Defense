# ASSET QUALITY AUDIT v9.0.0

## 결론

`Defense.zip`의 v8 라이브러리는 **970개 완성 에셋**이 아니다.

- 고해상도 이름 지정 후보: **40개**
- 시트에서 수동 선별된 참고 크롭: **101개**
- 자동 분리된 저해상도 조각: **823개**
- 원본 아틀라스: **6개**
- 투명 배경 파일: **0개**
- 최종 제작 승인: **0개**

따라서 v9부터 파일 수와 제작 완료 수를 분리한다.

## 고해상도 후보 40개

512×512 이름 지정 파일이다. 캐릭터 12, 몬스터·펫 12, 보스 2, UI 9, 오브젝트 3, VFX 2개로 구성된다.

장점:

- 기존 비교 시트보다 스타일 응집력이 크게 개선됐다.
- 파란 피부 도깨비 영웅 계열은 전사·궁수·법사·암살자·승려·창병·천둥 법사로 패밀리 확장이 가능하다.
- 몬스터와 UI는 Cute 70 / Cool 30, Gold Border / Blue Glow 방향에 대체로 부합한다.

남은 문제:

- 전부 단일 시점 콘셉트다.
- 전부 불투명 배경이다.
- 캐릭터 턴어라운드, 장비 파츠, Rig, 11개 모션, PBR 텍스처가 없다.
- 일부 인간형 여성·사신·동물 계열은 핵심 파란 도깨비 DNA와 별도 패밀리 규칙이 필요하다.

## 참고 크롭 101개

원본 시트에서 비교적 온전한 형태를 잘라낸 자료다. 색·실루엣·장식 참고용이며 최종 에셋으로 사용하지 않는다.

## 격리 조각 823개

대부분 한 변 128px 미만이며 얼굴 일부, 무기 일부, 팔·장식·FX 일부가 잘려 있다. 자동 추출 조각은 다음 용도로만 허용한다.

- 원본 아틀라스 위치 추적
- 실루엣·팔레트 참고
- 신규 프롬프트와 제작 지시서의 참조 자료

런타임, UI, 마케팅 이미지, 최종 에셋 수 집계에는 사용할 수 없다.
