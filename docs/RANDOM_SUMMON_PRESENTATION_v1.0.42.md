# Random Summon Presentation v1.0.42

- 랜덤 소환 버튼을 금색 테두리, 청록 발광, 보라색 강림 문양으로 재설계했다.
- 신규 `random-summon-emblem-v142.png`는 256×256 RGBA이며 외곽 2픽셀을 완전 투명하게 유지해 모서리 잘림과 검은 테두리를 방지한다.
- 도깨비 얼굴, 강림 원형 문양, 주사위 배지를 한 아이콘에 결합해 0.3초 이내에 랜덤 소환 기능을 식별할 수 있도록 했다.
- 엽전 충분, 엽전 부족, 강림 봉인, 선택권 보유 상태를 색·광택·ARIA 안내로 구분한다.
- PC에서는 가로형, 모바일에서는 세로형 버튼 구성을 사용하며 기존 액션 도크 크기를 변경하지 않는다.
- 모션 감소 설정에서는 회전·호흡 애니메이션을 비활성화한다.
