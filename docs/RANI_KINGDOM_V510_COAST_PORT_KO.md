# 라니킹덤 v5.10 — 실제 해안 어장 부두와 항로를 따라 운항하는 선박 (2026-10-20)

## 목적
정식 게임(v5.9)에서 해안의 무역선 3척은 물 위에서 약간 흔들리는 정적 소품이었다. 실제 물 타일 위를 이동하고, 플레이어가 기존 어장(fishery) 건물을 해안에 건설하면 주변 바닷물 타일과 접하는 실제 월드 부두가 생성되도록 확장한다. **어장은 기존 생산 건물이며 부두는 시각적 부속 구조물이다. 신규 항구 생산·교역·선박 충돌·선택 기능은 아직 구현하지 않는다.**

## 변경
- `rani-next/v510-world-port.mjs`가 기존 `rani-next/v56-world-flow.mjs` 적용 완료 후 `src/main.ts`를 순차 수정. 원본 Fiefdom 건축 판정과 세이브 포맷 수정 없음.
- 기존 승인 투명 `rk_ship.webp`를 쓰는 실제 3척 Sprite 오브젝트에 각 해안 물 타일의 5개 방향 이웃 검증을 통과하는 곧은 2.5D 항로 생성. 최대 18칸, 지정 경로 내 실제 수면만 움직이며 왕복·파도 흔들림 연출. 지도 좌표와 카메라 연결 유지.
- 실제 `GameState.buildings`에서 이름이 `fishery`인 건축물만 찾아 해당 건물 근처 물 타일에 `THREE.Group` 부두(물 위 바닥, 원목 판자 7, 나무 기둥 4, 등불 2)를 생성한다. 어장 철거 후 동기화에서 즉시 제거. 내구도·경제·NPC 충돌·건설 비용은 원본 유지. 프레임당 전체 검사 없이 약 950ms마다 변경 확인.
- 기존 4방향 PNG/무손실 모바일 아틀라스, SVG 0, 라이선스/AGPL 문서, v5.9 429 요청 완화 유지.
- 검증: 실제 2.5D `rani_coast` 게임 세계에서 무역선 3척의 물 타일 경로와 위치 변화, 원본 GameState 내 어장 객체 추가/삭제 시 부두의 월드 오브젝트 수명 검사. 기존 건설·전투·600초 게임·PC/모바일 및 `/Defense/`/legacy 실경로 QA 병행.
