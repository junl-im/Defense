# Kingdom Seed v4.6 QA + Visual Patch

## 수정 사항

- 타워 클릭 범위를 타워 전체 발자국으로 확대
- 건설 가능 위치 클릭 범위를 확대
- 화면 위/아래에 가까운 건설 메뉴가 화면 밖으로 나가지 않도록 자동 보정
- 선택 타워 패널도 화면 안쪽으로 자동 정렬
- 맵 상단 HUD/하단 도크 안전 영역을 고려해 건설 위치를 클램프
- v4.5 BootScene에 잘못 들어간 로드 블록 위치 수정
- 모바일/카카오 인앱 브라우저 뒤로가기 가드 오작동 완화
- 시작 게이트 CSS/DOM fallback 추가로 첫 화면 무응답 완화

## 브라우저 가드 정책

- PC에서는 뒤로가기 종료 팝업을 띄우지 않음
- 모바일에서만 popstate 기반 종료 확인을 시도
- hashchange/beforeunload 강제 팝업 제거로 오작동 감소
- pagehide/visibilitychange는 팝업 대신 보호 저장 이벤트만 발생
