# Kingdom Seed v2.0.0 Art QA + Playfield Sync Patch

## 목표

v2.0.0은 모바일 화면 크기 문제, 원화형 에셋과 코드 클릭존 정렬, 전투 구간 비주얼 동기화를 함께 다루는 QA 중심 대규모 그래픽 패스입니다.

## 변경 사항

- 모바일 세로 화면에서 게임 캔버스가 작게 보이는 현상 추가 보정
  - `visualViewport` 기반 CSS 변수 `--ks-vw-px`, `--ks-vh-px` 주입
  - 주소창 접힘/회전/전체화면 복귀 시 Phaser ScaleManager 재계산 유지
  - 최종 CSS override로 캔버스가 부모 컨테이너를 100% 채우도록 고정

- 원화급 비주얼 동기화
  - 로그인 배경 v2.0 컬러/샤프니스 재보정
  - 메인 메뉴 배경 v2.0 재보정
  - 월드맵 배경 v2.0 재보정
  - 전투 배경 8종 v2.0 재보정
  - 타워 4종 + 3레벨 + 최종 전문화 이미지 세트 v2.0 추가
  - 몬스터/영웅 static art v2.0 추가
  - 전투 상단 HUD, 하단 독, 타워 건설 메뉴, 타워 명령 패널, 버튼 v2.0 추가

- 전투 화면 QA
  - 우측 상단 속도/정지 버튼이 화면 밖으로 밀리는 좌표 보정
  - 타워 공격 시 이미지 스케일이 순간적으로 과하게 커질 수 있는 문제 수정
  - 타워 레벨업/전문화 시 이미지 크기 재적용 로직 추가
  - 투사체에 글로우/트레일을 추가해 전투 이펙트 톤을 원화형 UI와 맞춤

- 클릭존 점검
  - 기존 `?hit=1` 디버그 모드 유지
  - 로그인/메인/월드맵의 투명 클릭존은 이미지 버튼 크기 기준 유지

## 확인 방법

```bash
npm install
npm run build
npm run dev
```

개발 중 클릭존 확인:

```text
http://localhost:5173/?hit=1
```
