# Living Battlefield v15.0.0

## 목표

v14에서 구축한 2D 런타임 아틀라스를 실제 전투 시스템으로 확장한다. 전장에 배치된 이미지가 장식에서 끝나지 않고 플레이어 상호작용, 자동 방어, 이벤트 보상, 카메라 프레이밍에 참여하도록 만든다.

## Atlas Forge v15

- 총 프레임: 154
- 직접 선별 프레임: 74
- 상호작용·프롭 후보: 32
- 페이지: 2
- 1x 셀: 64px
- 2x 셀: 128px
- 출력: PNG + lossless WebP
- 자동 경계 검사 통과: 154/154
- 최종 3D 승인: 0

### 페이지 구성

- Page 01: 16×8, 1x `1024×512`, 2x `2048×1024`
- Page 02: 16×2, 1x `1024×128`, 2x `2048×256`

저사양 기기는 1x, 고밀도 화면은 2x WebP를 우선 선택한다.

## Living Props

### 상호작용 3종

| ID | 이름 | 효과 | 기본 재사용 |
|---|---|---|---:|
| treasure | 달빛 보물 상자 | 웨이브 비례 엽전 | 22초 |
| supply | 장터 보급 상자 | 신목 최대 체력의 약 5.5% 회복 | 25초 |

플레이어가 3.4 거리 안에 접근하면 화면 버튼과 `G` 입력이 활성화된다.

## Camera Director 2.1

입력 데이터:

- 플레이어 위치
- 최대 32개 활성 적 표본
- 보스 위치
- 준비된 상호작용 오브젝트
- 발사 중인 자동 방어 장치
- 화면 종횡비

출력 제한:

- 추가 거리 최대 +3.4
- 관심 지점 초점 가중치 최대 0.31
- 추가 FOV 최대 +3.2
- 흔들림 제한 0.42~0.86

## 제작 승인 정책

v15는 다음을 승인한다.

- 2D 런타임 아틀라스 기술 계약
- 전장 상호작용 기능 계약
- 카메라 프레이밍 기능 계약

다음은 승인하지 않는다.

- 최종 3D 프롭 모델
- 최종 영웅·몬스터·보스 모델
- 최종 턴어라운드·리깅·애니메이션
- 1,130개 대량 생산 잠금 해제
