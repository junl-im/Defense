# v1.0.17 아트 승인 보고서

## 승인 원칙

- 방향 원화와 액션 원화를 별도 승인합니다.
- 좌우 반전 이미지는 독립 방향 원화로 인정하지 않습니다.
- 파생 변형은 런타임 임시 연출로 사용할 수 있지만 최종 액션 원화 승인 수량에는 포함하지 않습니다.
- PC·모바일 크기, 접지점, 알파 가장자리, 실루엣, 방향 연속성, 피격점, 이펙트 가독성, 메모리 예산을 통과해야 런타임 승인이 가능합니다.

## 푸푸도깨비

- 방향 원화: 11/11 승인
- 좌우 반전: 0
- 대기 행: 승인
- 이동·공격·스킬·피격·사망 행: 파생 임시 연출
- 런타임 정책: 새 아틀라스가 정상 로드되면 사용, 실패하면 기존 승인 정적 원화 사용

## 수호성

- 안정: 승인
- 보호막: 승인
- 균열: 승인
- 위기: 승인
- 중복 레이어 방지 규칙과 단일 월드 HP 바 규칙 유지

## 보류·격리

- 기존 P0 자동 생성 방향 시트 4종은 격리 상태를 유지합니다.
- 나머지 캐릭터 20종은 기존 승인 정적 원화를 유지하며 독립 11방향 원화 제작 대기입니다.
