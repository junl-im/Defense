# v4.0.0 UI·HUD 계약

## 장비 가방

접근 경로:

- 타이틀 화면 `장비 가방`
- 전투 상단 우측 다이아 버튼
- 일시정지 메뉴 `장비 가방 · 직업 숙련`

모바일에서는 슬롯 카드와 장비 목록을 한 열로 접고, 가로 화면에서는 슬롯과 목록을 좌우로 배치한다. 확정 버튼은 모달 하단에 고정한다.

## 스테이지 HUD

도깨비마을을 웨이브에 따라 네 구역으로 구분한다.

1. 달문 입구
2. 야시장 거리
3. 신목 광장
4. 만월 제단

스테이지 칩은 상단 상태 레일에 포함되어 시드·징조·방패와 함께 충돌 감사를 받는다. 간소 모드에서는 설명 문구만 숨기고 구역명과 진행도는 유지한다.

## 보스 위험 프레임

- 안정: 숨김
- 경고: 화면 안쪽 주황 광원
- 위급: 붉은 테두리 펄스
- 모션 감소: 펄스 애니메이션 비활성화

기존 보스 의도 카드와 동일한 urgency 값을 사용해 정보가 불일치하지 않게 한다.
