# Kingdom Seed v3.7 Premium Visual Identity

## 방향

이번 패치는 특정 게임의 이미지를 그대로 베끼는 방식이 아니라, 최신 모바일 전략/디펜스 게임에서 공통적으로 쓰이는 시각 문법을 Kingdom Seed의 오리지널 왕국 판타지 톤으로 재구성한다.

## 적용 범위

- 타이틀/로그인 화면 배경과 로고 리마스터
- 월드맵 배경과 스테이지 카드 8종 리마스터
- 전투맵 8종 2.5D 배경 리마스터
- 버튼/패널/HUD/보상 패널 톤 통합
- 타워 Lv.1~3 및 최종 진화 타워 스프라이트 리마스터
- UI 텍스트 가독성과 PC 렌더링 선명도 개선

## 디자인 규칙

1. 누를 수 있는 것은 반드시 버튼처럼 보여야 한다.
2. 중요한 정보는 금색 테두리 + 어두운 판 위에 올린다.
3. 보상/유물/영웅은 카드형 계층 구조를 사용한다.
4. 전투 화면은 배경, 길, 타워, 몬스터, HUD가 서로 섞이지 않게 명암을 분리한다.
5. 보스/전설/고급 보상은 보라색, 금색, 붉은색을 제한적으로 사용한다.

## 다음 권장 작업

- 월드맵 하단 메뉴를 아이콘 도크 형태로 개편
- 보상 상자 개봉을 3단계 애니메이션으로 확장
- 타워 최종 진화 선택 UI를 전체 화면 패널로 승격
- 몬스터 도감을 카드 컬렉션형으로 리디자인
- 실제 웹폰트 적용 또는 로컬 폰트 서브셋 생성
