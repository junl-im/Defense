# Kingdom Seed v2.26.0 Atelier Ultra Polish + Performance QA

## 목표

v2.25에서 시작 구조를 분리한 뒤에도 체감이 무거울 수 있는 구간을 다시 점검하고, 고퀄 원화풍 에셋을 추가하되 첫 탭/첫 전환을 막지 않도록 로딩 예산을 제한했습니다.

## 핵심 변경

- 버전: `2.25.0` → `2.26.0`
- 신규 원화풍 아틀리에 UI 에셋 추가
  - PNG 138개
  - WebP 138개
  - 총 276개 이미지 파일
- `PremiumIllustrationArtV226.ts` 추가
  - 로그인/로비/월드맵/전투 전용 원화풍 레이어
  - 저사양 기기에서는 미세 애니메이션 자동 축소
- `ProgressiveAssetLoader.ts` 재정리
  - v2.26 핵심 아트를 v2.25보다 우선 로딩
  - 기본 모드는 씬별 코어 에셋 수를 제한
  - `?fullart`/`?galleryart`에서만 대량 갤러리 에셋 로딩
  - 로더 큐를 추가해 로비/월드/전투 프리워밍이 동시에 몰리는 것을 방지
  - 병렬 다운로드 수를 저사양 1개, 일반 2개로 제한
- 첫 화면 최적화
  - 로그인 고퀄 아트 스트리밍 시작을 `320ms` → `1700ms`로 늦춤
  - Firebase redirect/user 확인을 `1200ms` → `3200ms`로 늦춰 첫 탭 직전의 네트워크/JS 파싱 경쟁 완화
  - 상태 문구를 “탭하면 즉시 입장” 중심으로 변경
- 화면별 미세 다듬기
  - 로그인: 아틀리에 배경, 라커 카드, 프리즘 광원, 마스코트, 로컬 저장/지연 보호 배지
  - 로비: 작전실 배경, 벨벳 네비, 재화 유물, 상점/퀘스트/우편/이벤트 아이콘, NPC 2종
  - 월드맵: 아틀라스 배경, 보석 노드 링, 오로라 루트, 보스 게이트, 미리보기 프레임
  - 전투: 페인터리 오버레이, HUD 라커 프레임, 스킬 카드, 콤보/보스/마나/프레임 예산 배지

## 성능 정책

기본 실행은 빠른 접속을 위해 다음만 수행합니다.

1. BootScene은 필수 구형/핵심 에셋만 로드
2. 첫 탭은 로컬 세션으로 즉시 입장
3. Firebase는 뒤에서 지연 확인
4. v2.26 핵심 아트는 화면 진입 후 점진 로드
5. 대량 갤러리 아트는 `?fullart` 또는 `?galleryart`에서만 로드

## QA

- `npx tsc --noEmit --pretty false` 통과
- `npm run build`는 현재 원본 zip에 포함된 `node_modules/.bin/vite` 실행 권한 및 Rolldown optional native binding 누락으로 실행 불가
  - 코드 문제가 아니라 기존 의존성 폴더 문제
  - 로컬에서는 `npm install` 후 `npm run build` 권장
