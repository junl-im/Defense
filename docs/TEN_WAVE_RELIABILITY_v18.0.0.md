# Ten-Wave Reliability v18.0.0

## 목적

v17에서 추가한 웨이브 복구 장치를 10웨이브 전체 진행, 백그라운드 전환, 적 경로 정지, 보상 큐 정지까지 포괄하는 독립 안정성 계층으로 확장한다.

## 런타임 변경

### Wave Reliability Director

- 매 웨이브 시작·종료·보상·소환 상태 전환 기록
- 3초 주기의 경량 체크포인트 저장
- 적 체력·거리 서명을 이용한 실제 진행 감시
- 16초 동안 적 진행이 없으면 위치·행동 상태 복구
- 비정상 좌표·HP를 가진 적 즉시 복구
- 보상 큐가 열린 화면 없이 정지하면 큐 재개
- 첫 자동 웨이브가 시작되지 않으면 2초 카운트다운 재생성
- 긴 보상 선택 대기 시 추천 선택 경로 재안내

### 백그라운드 안전 복귀

- 탭이 숨겨질 때만 자동 일시정지
- 자동 일시정지와 사용자의 수동 일시정지를 구분
- 탭 복귀 시 자동 일시정지였던 경우에만 자동 재개
- 백그라운드 체류 시간 기록
- `pageshow`, `focus`, `visibilitychange` 경로 통합
- 복귀 직후 Three.js Clock 델타 초기화

### 적 경로 복구

- NaN·Infinity 좌표와 잘못된 HP 수정
- 중앙에 끼이거나 전장 밖으로 벗어난 적을 안전 반경으로 재배치
- 돌진·시전·예고 상태 초기화
- 남아 있는 텔레그래프 제거
- 보상이나 처치 수를 허위로 증가시키지 않고 이동 상태만 복구

### 진단 내보내기

일시정지 메뉴 또는 `F6`으로 다음 정보를 JSON으로 저장한다.

- 웨이브별 소요 시간
- 상태 전환 타임라인
- 복구 발생 원인
- 백그라운드 체류 시간
- 적 경로 복구 횟수
- 보상 큐 복구 횟수
- 런타임 오류
- 성능·에셋·카메라·전투 텔레메트리

## 자동 시뮬레이션

`src/runtime/ten-wave-reliability-simulation.js`는 다음 장애를 포함한 결정론적 10웨이브 진행을 실행한다.

- 첫 웨이브 자동 시작 지연
- 웨이브 3 보상 모달 숨김
- 웨이브 4 소환 정지
- 웨이브 6 백그라운드 전환
- 웨이브 8 비정상 적 상태
- 웨이브 2·4·5·7·9 유물 큐
- 웨이브 3·6·9 축복 큐
- 웨이브 5·8 계약 큐

결과는 `TEN_WAVE_RELIABILITY_SIMULATION_v18.0.0.json`에 기록한다.
