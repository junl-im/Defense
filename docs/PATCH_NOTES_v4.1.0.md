# v4.1.0 Patch Notes

## 전투 방향

- 플레이어 기본 공격과 기술의 목표 방향 선회 및 방향 잠금
- 수호대 공격 예측 선회
- 적의 신목 공격 방향 정렬
- `WeaponSocket` 우선 발사 위치

## 전투 임팩트

- 속성별 베기, 초승달, 폭발, 빙정, 충격파, 문양, 스파크 효과
- 치명타·보스·궁극기 화면 플래시
- 모바일 효과 수 예산과 저사양 히트스톱 제한
- 웨이브 클리어 금빛 파동
- 기존 흔들림·플래시·모션 감소 설정 연동

## 자동 진군

- 보상 처리 후 10초 자동 다음 웨이브
- 즉시 시작 버튼 지원
- 마지막 3초 강조
- 일시정지 및 선택 모달 안전 처리

## 품질 상태

신규 작가 제작 캐릭터 모델이나 최종 승인 아트는 추가하지 않았다. 이번 버전은 기존 19종 모델의 방향, 소켓, 애니메이션과 전투 표현을 강화하는 런타임 프레젠테이션 패치다.

## 프리미엄 디자인 패스

- 자동 진군을 월문 문양, 입체 Moonstone 패널, 진행 게이지, 대형 초 카운터로 재설계
- 320px 세로 화면과 짧은 가로 화면 전용 축소 규격
- 공격 임팩트를 밝은 코어, 속성 후광, 방향성 슬래시, 파편의 4단 레이어로 통일
- 치명타·보스·궁극기만 화면 슬래시와 확산 링을 사용해 시각 위계 강화
- 저사양 모드와 모션 감소 설정에서는 파편 및 반복 애니메이션 자동 축소
- 모든 신규 표현은 CSS와 Three.js geometry 기반이며 SVG를 사용하지 않음
