## 실전 개선

경고 단계의 위험 지형이 카메라 밖에 있으면 화면 가장자리에 최대 네 개의 방향 표시를 배치한다. 남은 시간이 0.72초 이하인 항목은 긴급 상태로 강조한다. 긴급 위험 또는 보스 치명 공격 때만 카메라 거리와 시야각을 제한적으로 넓히며, 사용자의 수동 카메라 설정을 대체하지 않는다.
