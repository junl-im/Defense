# Kingdom Seed v2.28.0 Lag Fix & Mobile UI QA

## 목적

v2.27 이후 일부 모바일 환경에서 게임 시작 직후 전투가 멈추거나 프레임 드랍이 크게 발생하는 문제를 우선 해결하는 긴급 안정화 패치입니다. 이번 버전은 신규 대용량 에셋 추가보다 기본 실행 안정성과 모바일 가독성을 우선합니다.

## 주요 수정

- 모바일/약한 네트워크 기본 품질을 절전 모드로 고정
- 기본 모드에서 전투 중 v2.25~v2.27 고퀄 스트리밍 아트 로딩 차단
- 로비/월드맵/전투 예열 아트 로딩을 기본 차단하고 `?fullart`, `?galleryart`, `?richart`에서만 허용
- ProgressiveAssetLoader 기본 로드 상한 축소
- 전투 중 무거운 프리미엄 원화 레이어와 v2.26 데코 기본 비활성화
- 모바일/절전 모드에서 DOM 클릭 리플/캔버스 펄스 비활성화
- 모바일/절전 모드에서 로그인/로비/월드맵 무한 반복 트윈 축소
- 월드맵 배경 반짝이 수 축소

## UI/UX 확대

- 로그인 버튼, Google 버튼, 이메일/회원가입 버튼 크기 확대
- 로그인 상태 안내 영역 확대
- 로비 하단 주요 버튼 터치 영역 확대
- 로비 좌우 메뉴, 상단 재화, 프로필 터치 영역 확대
- 로비 텍스트 크기 확대
- 전투 상단 HUD 글자 확대
- 전투 시작/속도/일시정지/음향 버튼 터치 영역 확대
- 타워 건설 지점/타워 선택 히트존 확대
- 타워 건설 메뉴와 카드 크기 확대
- 스킬 버튼 크기와 글자 크기 확대

## 품질 모드

기본 모바일 실행은 렉 방지를 위해 초경량 모드입니다.

- 일반 실행: 모바일 안정성 우선
- `?fullart`: 전체 아트 감상/검수용
- `?galleryart`: 갤러리급 아트 감상용
- `?richart`: 고급 아트 강제 확인용
- `?quality=high`: 품질 수동 강제
- `?quality=medium`: 균형 품질 수동 강제
- `?quality=low`: 절전 품질 수동 강제

## 검증

```bash
npx tsc --noEmit --pretty false
```

통과.

`npm run build`는 현재 작업 컨테이너의 기존 `node_modules`에 Rolldown optional native binding이 없어 실패했습니다. 코드 오류가 아니라 의존성 설치 문제입니다. 필요 시 다음 명령으로 재설치하세요.

```bash
npm install
npm run build
```
