# 라니킹덤 v1.1 — 원본 3D 육각 정보뷰·필드 조작 통일·한국어 진행률

## 원칙
기존 Hexkingdom MIT 기반 Three.js 3D 마을, 코어 경제·건축·연구·병력, 저장 v3, 기존 그래픽 에셋과 UI 데이터 키를 보존한다. 별도 DOM/이모지 마을을 생성하지 않는다.

## 실제 변경
1. 이미 설치된 **3D 육각 타일·건축물**을 한 번 터치하면 기존 RadialMenu.js의 3D 타일 위치 중심 **원형 액션 링**이 열린다. 하단 3열 목록을 강제하던 모바일 CSS만 철회한다. 각 동작은 원본 BuildingSystem/ArmySystem을 그대로 사용하며 같은 타일 반복 터치 시 재오픈한다.
2. 모바일 화면에서 원형 메뉴를 화면 밖으로 잘라내지 않도록 투영 좌표에 최소한의 안전 경계만 둔다. 하단 고정 패널로 바꾸지 않는다.
3. 외부 필드는 실제 `grid.cells`를 재사용하여 **영토별 3D 육각 메쉬**를 InstancedMesh로 표시한다. 세력별 대표 성채 및 미니멀 기본 지형을 유지하되, 가짜 독립 영토나 경제 시스템은 만들지 않는다. 지도 육각 또는 건물을 직접 터치하면 실제 세력·영토 정보를 연다.
4. 필드 카메라의 회전축·고도각 및 화면→지면 이동 벡터를 마을의 CameraController와 통일한다. 마우스 휠 줌, 손가락 드래그·핀치, Q/E 60도 회전을 지원하고 마을 카메라와의 입력 이중 처리를 방지한다. 월드에서 RMB 클릭이 손에 든 마을 타일을 회전시키지 않도록 처리한다.
5. 필드의 **내 마을 건물/육각 선택**, 상단 **🏠 마을**, **마을 찾기→내 마을**은 별도 카드가 아닌 **원본 3D 마을 화면**으로 돌아가 해당 육각 타일을 선택하고 원형 정보를 바로 연다. **내 거점**은 현재 필드에서 시점만 이동하는 단축 기능으로 구분한다.
6. 필드에서 적/우호 세력의 실제 육각 타일 선택 시 지형 한국어 이름·좌표·건설된 시설 상태를 정보 패널에 표시한다. 전투는 원본 `ArmySystem.canAttack` 제한을 유지하며 장거리 행군을 허위 구현하지 않는다.
7. 원형 메뉴 건설 진행률에 내부 영어 `icon` ID가 보이던 것을 **건물의 한국어 이름 + 건설 + %**로 수정. 로딩 화면 진행 바 상태(화면 준비 중/마을 자료 불러오는 중/완료)와 연구/건설 fallback도 한국어로 변경.

## 검증
- 기존 Node 전수 검사 + Chromium Playwright PC 1440×900 / 모바일 390×844 / 소형 320×700.
- 원형 메뉴/터치·진행률 한국어, 기존 빈땅 즉시 건설, 실제 3D 영토 개수, 필드 이동 방향, 내 마을에서 원본 RadialMenu 재진입, 저장·연구·군사 회귀 테스트.
- 기존 통과 기준이 충족되기 전에는 main 병합 또는 Pages 공개 완료를 주장하지 않는다.
- 실제 Android/iOS 물리 단말의 FPS·브라우저 핀치 UX는 자동 Chromium 검사와 별개로 후속 점검한다.

## 미구현
Firebase Auth/Firestore 클라우드 세이브, 온라인 연맹·PvP·장거리 행군 및 실제 서버 판정은 미구현. Windows 로컬 작업 폴더는 GitHub 병합 후 자동 동기화되지 않는다.
