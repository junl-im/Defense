# 라니킹덤 v2.1 — 실제 3D 주택 5종·시장·병영·작업장 외형 완성도 강화

## 확정 아트 콘셉트
사용자가 확정한 화면의 **푸른 지붕과 따뜻한 붉은/초가 지붕 혼합, 금장 문장, 골목으로 이어지는 석판길, 시장/상점 진열과 기능별 건축물 실루엣**을 PC·모바일 공통으로 유지한다. UI 스킨 위 이미지로 흉내내지 않고 기존 Three.js 모델 자체를 점진 보강한다.

## 실제 구현 범위
- `src/rendering/RoyalDistrictArt.js`: 3D 실물 vertex-color 병합 모델. 5종 주택의 정면 문턱·돌계단·창틀·처마 금장/왕실 파란 패·화분을 서로 다른 높이와 구조에 맞게 생성. 각 건물의 기존 외관 구조, 높이, 지붕 모양, 랜덤 크기를 보존. 작은 화분·전면 발판이 건물 경계 주변에만 놓여 도로/선택 타일을 가리지 않도록 설계. 각 건물당 추가 렌더 메시 1개.
- 원래 `BuildingFactory.makeHouse`, `makeHouseB`, `makeHouseC`, `makeHouseD`, `makeHouseE` 5변종의 마지막 4단계에 장식 추가. 단독주택은 푸른 지붕 출현 빈도를 높이되 원래 붉은 지붕/초가 변주와 5가지 서로 다른 형태 유지. B 석판 지붕/C 2층/D 가로로 긴 주택의 파란 지붕 색 반영. E 둥근 초가는 왕국 금빛 처마 장식으로 특색 유지.
- 시장은 실제 상품 상자·과일·금빛 차양·파란 깃발·석재 시장 바닥 추가. 병영은 파란 왕실 문장·금색 방패·훈련장 작은 탑과 출입 발판. 대장간은 금장 장인 간판/작업장 발판, 벌목장과 제재소는 푸른 지붕·길드 표식·목재 더미.
- 기존 전문 건물 `CivicFactory.makeBarracks`, `makeForge`, `makeSawmill`의 완공 4단계에만 장식. `BuildingFactory.makeMarket`, `makeLumberMill` 마찬가지. 생산량/구매 비용·연구 잠금·건설 시간·자원/상호작용/픽킹·SaveSystem 스키마 변경 없음.
- 제작된 모든 장식은 원본 4단계 마지막 `p4`에 추가하여 **미완공 건물에 장식이 떠 있는 문제 방지**. 새 메시에는 `raniVisualOnly` 표시. 기존 건축물 종류/저장된 모델 확장 없이 로드시 정상 재생성.

## 자동 품질 검증
- `scripts/check-royal-district-v21.mjs`: 실제 3D 메시·주택 5종/전문 건물 5종·기존 4단계 장식 경로 확인.
- `scripts/qa_royal_district_v21.py`: 원본 게임에서 Three.js 주택 A~E, 시장, 벌목장, 제재소, 대장간, 병영 각각 4단계 구조/최종 단계 실제 3D 장식 1개/vertex count/경계 및 원래 단계별 기존 모델 확인. 게임 ConstructionSystem 실제 instant 빌드 경로까지 검사. PC 1440×900, 모바일 390×844, 소형 320×700 및 새로고침 후 실제 왕국 월드 유지 확인.
- 기존 Game/Playwright 전체 회귀(시작화면/선택 팝업/건축/로드/필드/물류/초기화/우클릭/패널 이동) 전부 유지. GitHub Actions 성공 후 `main` 병합.

## 제한·후속
이번 버전은 **기존 주택·시장·병영·제작소 3D 건물 품질과 실루엣/도시 밀도 표현의 1차 보강**이다. 사용자 이미지 수준의 3D 왕궁/해안/성벽/건물 전체 리모델링 및 상용 일러스트풍 텍스처로 일괄 변경한 것은 아니다. 실제 마을의 생활형 NPC/간판 래스터 세트, 대형 성내 도시 배치, 바다/수목·도로의 분위기 통일은 후속. GitHub Pages CDN 최신 반영 및 Android/iOS 실기기 GPU FPS는 별도 실측 필요.
