# v2.7.0 Tactical Orders + Runtime Performance QA

## 목표
- 전투 다양성을 크게 늘리되 모바일 터치/가독성/성능을 해치지 않는다.
- 전투 중 자동 성능 조절이 화면 재시작으로 이어지지 않도록 안정화한다.
- 고퀄 이미지 UI를 유지하면서 실시간 텍스트와 클릭존은 코드가 관리한다.

## 주요 변경

### 1. 작전 카드 시스템
- 전투 시작 전과 일부 웨이브 클리어 후, 3장의 작전 카드 중 1장을 선택할 수 있다.
- 선택 가능한 효과:
  - 즉시 골드 보급
  - 건설 비용 감소
  - 타워 화력/공속 증가
  - 영웅 피해량 및 생명 보강
  - 스킬 쿨타임 감소
  - 메테오 피해 보정
  - 용병 소환 강화
  - 기존 타워 일시 긴급 강화
- 카드 선택 UI는 이미지 에셋 기반이며, 텍스트와 클릭존은 코드에서 관리한다.

### 2. 전투 HUD 보강
- 상단 우측에 작전 상태 칩을 추가했다.
- 작전 상태 칩을 눌러 현재 전투에서 남은 카드 선택을 다시 열 수 있다.
- 모바일 화면에서 지나치게 큰 텍스트가 되지 않도록 9~12px 기준으로 제한했다.

### 3. 성능 안정화
- 기존 자동 품질 저하 로직이 `setQualityTier()`를 호출하면서 전투 중 reload가 발생할 수 있던 위험을 제거했다.
- v2.7부터 자동 품질 저하는 `setRuntimeQualityTier()`를 사용해 전투 중 즉시 반영하되, 페이지 reload는 하지 않는다.
- 저사양 모드에서는 캔버스 CSS 필터를 제거해 후처리 비용을 줄인다.

### 4. WebP/PNG 유지
- v2.7 신규 UI 에셋은 PNG와 WebP를 모두 제공한다.
- 기존 `?png=1` fallback 확인 옵션 유지.

## QA 확인
- `?hit=1`: 클릭존 확인
- `?perf=1`: 현재 품질/FPS 확인
- `?png=1`: PNG fallback 확인
- `?lite=1`: 저사양 확인

## 기대 효과
- 동일한 스테이지라도 카드 선택에 따라 운영 루트가 달라진다.
- 모바일에서 전투 중 갑자기 새로고침되는 현상을 방지한다.
- 원화급 UI 흐름은 유지하면서, 게임성/반복 플레이 다양성이 증가한다.
