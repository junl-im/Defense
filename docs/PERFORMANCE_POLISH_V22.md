# v2.2 디자인 디테일 / 성능 설계

## 목표

v2.2는 콘텐츠 추가보다 실제 상용 모바일 웹게임처럼 느껴지는 안정성과 디테일을 강화한다.

1. PC에서는 절대 화면을 회전하지 않는다.
2. 모바일에서는 가로모드 몰입감을 유지한다.
3. 저사양/카카오 인앱/오래된 기기에서도 프레임이 급격히 무너지지 않게 한다.
4. 전투 화면에 장식, 분위기, 광원감을 추가하되 성능 예산 안에서만 표현한다.

## 품질 단계

| 단계 | 기준 | 적용 |
| --- | --- | --- |
| 절전 | RAM 2GB 이하, CPU 2코어급, 자동 FPS 저하 | 이펙트 수 대폭 감소, DPR 1 고정 |
| 균형 | 대부분의 모바일 | 중간 파티클, DPR 1~1.35 |
| 고품질 | PC/고성능 기기 | 광선/장식/파티클 최대치, DPR 최대 1.6 |

## 자동 하향

`installScenePerformanceWatch()`가 약 1.8초 단위로 FPS를 샘플링한다. 34FPS 아래가 반복되면 품질을 한 단계 낮추고 페이지를 재기동한다.

## 이펙트 예산

`shouldSpawnFx(scene, cost)`가 씬별 1초 이펙트 비용을 추적한다. 포탑 폭발, 메테오, 다수 사망이 겹쳐도 정해진 예산을 초과하면 일부 시각 이펙트를 건너뛰고 게임 로직만 유지한다.

## URL 디버그

```txt
?perf
```

전투 화면 우측 상단에 현재 품질과 FPS가 표시된다.
