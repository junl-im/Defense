# v1.0.25 Action & Asset Assurance

## 실제 개선
- 주인공 액션 상태가 짧게 튀는 현상을 줄이는 최소 유지 시간 적용
- 피격과 기술 상태는 중요 인터럽트로 허용하고, 공격·대기 전환 떨림은 억제
- 11방향 × 6상태 사용 셀을 런타임에서 계수
- 액션 전환, 잠금 적용, 거부된 짧은 상태 변경을 별도 기록
- 전투 비주얼 레코드와 사망 잔상 해제량, 최대 사용량 기록
- 웨이브별 적·수호대·파티클·투사체·비주얼 레코드 스냅샷 기록
- 10웨이브 도달 여부와 잔여 리소스 건전성 판정
- 결과 화면, 달빛 도감, 3D 미리보기의 시각 언어 통일
- 모바일 세로·가로, PC 컴팩트·와이드 HUD 충돌 프로필 분리

## 승인 경계
- 푸푸도깨비 11방향 원화: 최종 승인 유지
- 6개 액션 행 런타임 매핑: 승인
- 공격·스킬·피격·사망 독립 원화: 아직 파생 임시 승인
- 장난 요괴 폭탄병 11방향 후보: 교체 대기, 런타임 격리
