# v2.23.0 Fast Start Performance QA

이번 패치는 디자인 추가보다 접속/첫 탭 지연 개선을 최우선으로 정리한 성능 패치입니다.

## 핵심 변경

- 기본 실행을 `Fast Start Mode`로 전환했습니다.
- v2.16~v2.22 누적 장식 에셋은 기본 부팅에서 GPU 업로드하지 않습니다.
- 전체 누적 장식 확인이 필요하면 주소 뒤에 `?fullart`를 붙이면 됩니다.
- 빠른 시작은 Firebase 익명 로그인/세이브 로딩을 오래 기다리지 않습니다.
- 네트워크가 느리면 로컬 게스트 세이브로 즉시 입장하고, 기록은 브라우저 localStorage에 보호 저장합니다.
- 첫 화면의 `탭해서 시작` 카드와 TAP 버튼을 조금 키워 작은 모바일 화면에서 누르기 쉽게 조정했습니다.
- 로그인 버튼 터치 영역도 실제 이미지보다 크게 잡아 터치 실패를 줄였습니다.

## QA/안정화

- `completePendingRedirectSignIn`, `waitForUser`, `loadOrCreateSave`에 짧은 대기 제한을 적용했습니다.
- 기존 세이브의 `updatedAt` 갱신은 첫 입장 흐름을 막지 않도록 백그라운드 처리합니다.
- 신규 세이브 생성도 첫 화면 전환을 막지 않도록 지연 저장합니다.
- 스테이지 클리어/업그레이드는 클라우드 저장 실패 시 로컬 저장을 유지합니다.
- 로컬 게스트 상태에서는 리더보드 전송을 생략해 네트워크 지연을 만들지 않습니다.

## 확인 방법

```bash
npx tsc --noEmit --pretty false
npm run build
```

둘 다 통과했습니다. Vite의 큰 번들 경고는 기존 구조상 남아 있지만 실행을 막는 오류는 아닙니다.

## 옵션

- 기본: 빠른 시작/가벼운 장식 모드
- `?fullart`: v2.16~v2.22 누적 장식 전체 로드
- `?fullpreload`: 기존처럼 더 많이 미리 로드하는 확인용 모드
- `?png`: WebP 스왑 비활성화 확인용 모드
