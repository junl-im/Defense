# 패치 노트 — v1.0.12 Cross-Platform Visual Polish

- 공개 버전: `1.0.12`
- 빌드 ID: `b24.12`
- 기준 버전: `1.0.11 IP Knowledge Megaforge v4`
- 아트 스타일 잠금: `DD-ABSOLUTE-ART-BIBLE-2.0`

## 이번 패치의 목표

컨셉 보드의 완성도를 한 번에 전 캐릭터에 적용했다고 과장하지 않고, 실제 게임에서 확인할 수 있는 **P0 그래픽 수직 슬라이스**를 먼저 만들었습니다. PC와 모바일은 같은 화면을 축소하는 방식이 아니라 독립된 전투 HUD 셸로 운용하며, 대표 영웅·수호대·몬스터·보스에는 11방향 런타임 아틀라스를 연결했습니다.

## 그래픽 이미지 다듬기

타이틀 화면의 배경·마스코트·스토어 커버를 새 색보정 파이프라인으로 정리했습니다.

- 데스크톱 배경: `1920×1080`
- 모바일 배경: `900×1600`
- 투명 마스코트: `720×907`
- 저사양용 데스크톱·모바일·마스코트 변형
- 스토어/공유 커버: `1200×630`
- 색 번짐, 투명 경계의 흰 테두리, 중심 UI 안전영역, 야간 대비를 보정

실행 파일:

```text
src/assets/title-v112/
public/cover.webp
scripts/generate-visual-polish-assets-v112.py
```

## P0 실제 11방향 전투 아틀라스

다음 네 개 대표 개체를 11개 독립 방향과 6개 전투 상태로 제작해 런타임에 연결했습니다.

| 분류 | P0 개체 | 상태 | 방향 | 프레임 |
|---|---|---:|---:|---:|
| 영웅 | 도깨비 전사 | 6 | 11 | 66 |
| 수호대 | 불씨 깨비 | 6 | 11 | 66 |
| 몬스터 | 장난 요괴 | 6 | 11 | 66 |
| 보스 | 저승 호랑이 | 6 | 11 | 66 |
| **합계** | **4개체** |  |  | **264** |

상태는 `idle`, `move`, `attack`, `skill`, `hit`, `death`입니다. 각 방향은 좌우 반전으로 대체하지 않으며 `mirroringAllowed: false`를 유지합니다. 기기 품질 단계에 따라 High·Medium·Low 아틀라스를 선택할 수 있습니다.

브라우저 검토 페이지:

```text
/p0-directional-library-v112.html
```

중요: 이 264프레임은 GLB 기반 P0 런타임 제작본입니다. 실게임 적용과 방향 검증에는 사용할 수 있지만, 전 개체의 최종 상업 원화 승인을 의미하지 않습니다.

## 전투 표현 보강

`CombatVisualDirectorV112`가 P0 개체에는 11×6 아틀라스를 사용하고 나머지 개체에는 기존 고품질 스프라이트를 안전하게 유지합니다.

- 카메라 기준 11방향 선택
- 대기·이동·공격·스킬·피격·사망 상태 전환
- P0 개체 좌우 미러링 금지
- 월드 HP 바에 보호막·브레이크·상태 이상 표시 통합
- 보스·수호성의 별도 HP 높이·폭·렌더 순서 유지
- 품질 단계별 아틀라스 선택과 저사양 대응

## PC·태블릿·모바일 독립 셸

`CrossPlatformShellV112`가 화면 폭, 방향, 포인터 종류, 브라우저 가시 영역을 기준으로 셸을 선택합니다.

- PC: 상단 전술 정보 축소, 조이스틱 제거, 중앙 액션 랙
- 태블릿: 중간 밀도와 넓은 전투 시야
- 모바일 세로: 상단 상태 레인, 좌측 조이스틱, 우측 액션 그리드
- 모바일 가로: 중앙 전투 시야 확보, 낮은 높이용 컴팩트 모드
- 보이는 HUD 요소의 실제 사각형 겹침 검사
- 겹침 검출 시 긴급 안전 레이아웃 적용

PC와 모바일은 동일 셸의 단순 스케일 변경이 아니며 진단값에 `shellSeparated: true`, `sharedScaleOnly: false`를 기록합니다.

## 자동 검증

```bash
npm run generate:visual-polish:v112
npm run generate:p0-directional:v112
npm run verify:release:v112
npm run build:static
node scripts/verify-static-dist.mjs
npm run create:patch:v112
npm run verify:patch:v112
```

검증 대상에는 버전 동기화, 이미지 SHA-256, 11방향·6상태 프레임 수, 미러링 금지, 아틀라스 품질 변형, PC·모바일 셸 분리, 서비스 워커 프리캐시, 정적 배포본이 포함됩니다.
