# v4.2.0 Patch Notes — Production Gate & Frame Telemetry

## 아트 제작 잠금

- Absolute Art Bible v2.0 기반 제작 승인 게이트 추가
- 도깨비 전사·일반 요괴·저승 호랑이·환경·HUD·VFX 6종 골든 수직 슬라이스 정의
- 기존 런타임 GLB 19종을 레거시 후보로 명시
- 완전한 승인 증거 없이 `production-approved` 표기 금지
- 골든 수직 슬라이스 승인 전 1,130개 대량 제작 잠금

## 성능 엔진 3.1.0

- 평균 FPS 외에 평균 프레임 시간·P95·장시간 프레임 비율 수집
- 240프레임 고정 버퍼로 계측 메모리 상한 고정
- 25ms 경고, 40ms 위험 프레임 분리
- 렌더 통계 HUD에 프레임 건강도 표시
- 성능 로그 JSON에 프레임 계측과 아트 승인 게이트 상태 포함

## 품질 상태

신규 작가 제작 에셋은 아직 추가하지 않았다. v4.2.0은 다음 디자인 수직 슬라이스를 안전하게 제작하고 전후 성능을 비교하기 위한 기반 패치다.
