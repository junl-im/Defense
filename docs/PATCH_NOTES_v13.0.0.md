# PATCH NOTES v13.0.0 — Transparent Arsenal

- 사용자 제공 시트 10장을 415개 투명 PNG로 분리했다.
- 체크무늬가 구워진 불투명 PNG에서 테두리 연결형 밝은 무채색 배경을 제거했다.
- 시트별 행·열을 자동 보정하고 주요 42개를 직접 검수했다.
- 5직업 선택 카드가 신규 영웅 스프라이트를 사용한다.
- 장비 9종이 신규 무기·부적·재화 스프라이트를 사용한다.
- 달빛 도감의 수호대·요괴·보스·환경·VFX 항목에 신규 초상을 연결했다.
- 415개 전체를 검색·필터링하는 Sprite Forge v13 리뷰 OS를 추가했다.
- 원본 시트는 재생성을 위해 프로젝트에 보존하되 정적 배포본에서는 제외했다.
- 게임 버전을 13.0.0, 세이브 스키마를 11로 갱신했다.
- Scenic 기본 카메라와 런타임 수직 슬라이스 6/6은 유지한다.
- 2D 런타임 사용 승인과 최종 3D 제작 승인을 분리하며 3D production art는 0/6이다.
