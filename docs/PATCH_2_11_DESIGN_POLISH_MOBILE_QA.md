# v2.11.0 Design Polish / Mobile QA

## 목적
v2.10 이후 모바일 기준으로 화면 밀도, 터치 영역, 팝업 크기, 시작 게이트, 전투 HUD의 통일감을 다시 조정한다.
원화형 배경은 유지하되 글씨/수치/클릭존은 코드가 관리하고, 보이는 버튼보다 터치존이 과하게 넓어지지 않게 맞춘다.

## 변경 사항
- 신규 `public/assets/ui/v2_11` UI 에셋 추가
  - 전투 상단 HUD / 하단 독
  - 타워 설치 팝업 / 설치 카드
  - 타워 선택 패널
  - 버튼 6종 / 모바일 칩 / 토스트 플라크
  - 로그인 패널 / 로그인 버튼 / 유틸 버튼
  - 빌드 스팟 / 타워 선택 링
- WebP 우선 로드 패턴에 `v2_11` 추가
- 로그인 첫 화면
  - 로고와 패널 크기 축소
  - 버튼 위치와 이미지 크기 기준 클릭존 재정렬
  - 우측 유틸 버튼 터치 영역 축소
  - 버전 표기 `v2.11.0 DESIGN QA` 갱신
- 메인 메뉴
  - 하단 내비/좌우 버튼/재화 칩 더 컴팩트하게 조정
  - 클릭존을 보이는 에셋 크기에 더 가깝게 축소
  - 라벨 글씨 크기 축소
- 전투 화면
  - 상단 HUD/하단 독 v2.11 클린 프레임 적용
  - 건설 지점 터치존 `34x24`로 축소
  - 설치된 타워 선택 터치존 `30x40`으로 축소
  - 타워 설치 팝업 `248x152`, 카드 `102x36`으로 축소
  - 타워 선택 패널 `292px` 폭 기준으로 축소
  - 전투 하단 스킬 버튼/공세 정보 위치 조정
- 모바일 웹쉘
  - 시작 카드 더 작게 조정
  - 흰색 카드 느낌 제거, 어두운 판타지 카드 톤으로 통일
  - 로딩 문구 v2.11로 갱신
  - 모바일에서는 캔버스 CSS 필터 제거로 비용 감소

## 확인 옵션
- `?hit=1` : 클릭존/터치존 확인
- `?png=1` : PNG fallback 확인
- `?lite=1` : 저사양 모드 확인
- `?battery=1` : 배터리 절약 모드 확인

- 컨테이너에서는 기존과 동일하게 `vite: Permission denied`로 `npm run build`의 Vite 단계는 실행되지 않음
