# v2.2.0 Mobile Fill + Combat Visual Sync QA

## 목표
- 모바일 세로 브라우저에서 게임이 작은 16:9 스트립처럼 보이는 현상을 줄인다.
- 원화급 전투 배경, 타워, 몬스터, HUD가 서로 분리되어 보이도록 전투 시각 레이어를 정리한다.
- 클릭존/터치존이 UI 프레임과 어긋나거나 HUD/하단 독에 가려지는 문제를 다시 점검한다.

## 변경 내용
- 모바일 portrait 기본 표시 방식을 `contain`에서 `fill`로 변경했다.
  - 전체화면/가로잠금이 막히는 모바일 브라우저에서도 화면을 꽉 채우도록 보정한다.
  - 비교가 필요하면 개발 주소에 `?fit=contain`을 붙이면 기존 16:9 안전 표시로 확인 가능하다.
- `BattleVisualDirector`를 추가했다.
  - 전장 안전 영역 상수화
  - 전투 배경 위 클린 포커스 오버레이
  - 경로 방향 비콘
  - ENEMY/CASTLE 진입·도착 게이트 글로우
  - 테마별 저채도 전장 안개
- 전투 안전 영역을 코드에서 공유한다.
  - 스킬 조준 프리뷰
  - 빈 전장 터치
  - 빌드 스팟 보정
  - HUD/하단 독 입력 가드
- 타워 선택 링을 v2.2 클린 이미지 에셋으로 교체했다.
- 웨이브 시작 배너를 v2.2 클린 프레임 에셋 우선 사용으로 변경했다.
- 빌드 스팟 hover/out 텍스트가 프리미엄 패드 사용 시 `건설`로 안정적으로 되돌아오도록 보정했다.

## QA 방법
- 기본 모바일 세로 테스트: `npm run dev` 후 휴대폰에서 접속한다.
- 클릭존 표시: `?hit=1`
- 기존 contain 표시 비교: `?fit=contain&hit=1`
- 확인 포인트
  - 로그인 버튼/우측 상단 버튼 클릭 영역
  - 월드맵 스테이지 노드/전투 시작 버튼
  - 전투 상단 HUD와 하단 독 터치가 영웅 이동/스킬 시전을 막는지
  - 스킬 조준 프리뷰가 전장 밖에서 자동 보정되는지
  - 타워 건설 메뉴와 타워 선택 패널이 화면 밖으로 밀리지 않는지
