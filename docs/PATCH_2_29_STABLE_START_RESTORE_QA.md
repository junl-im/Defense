# PATCH 2.29.0 - Stable Start Restore QA

## 목표

첫 접속/시작 화면의 정체성이 v2.24~v2.27 원화풍 레이어로 바뀌어 보이던 문제를 되돌리고, v2.28의 성능 안정화는 유지한다.

## 수정

- MenuScene 기본 로그인 화면을 v2.15 계열 `v1-login-clean-bg`, `v1-title-logo-clean`, `v1-login-panel-v18` 중심으로 복구.
- v2.16~v2.27 로그인 장식/프리미엄 로그인 아트 자동 주입 제거.
- 첫 화면에서 progressive login art 스트리밍을 시작하지 않도록 차단.
- 첫 화면 하단 glow 트윈을 정적 처리해 약한 모바일에서 시작 프레임 부담 감소.
- Firebase 지연 부트스트랩/로컬 즉시 입장 구조는 유지.
- 버전 표기를 `v2.29.0 STABLE START`로 갱신.

## 유지

- 빠른 시작은 네트워크를 기다리지 않고 로컬 게스트 세션으로 즉시 입장.
- Google/이메일 로그인은 기존처럼 필요할 때만 Firebase 동적 import.
- v2.28의 전투 중 고퀄 아트 기본 차단 정책 유지.

## 적용

프로젝트 루트에 덮어쓰기.
