# 공개 버전 정책 v1.0

## 공개 버전

- 일반 기능·기술·성능·버그 수정: `1.0.1 → 1.0.2 → ... → 1.0.99`
- 초대규모 시스템 개편: `1.0.x → 1.1.0`, 이후 `1.2.0`
- 호환성이 끊기는 정식 세대 전환에서만 `2.0.0`

## 내부 계보와 빌드 ID

공개 버전을 낮춰 재정렬해도 과거 기능 계보와 캐시 순서가 역행하지 않도록 세 값을 분리한다.

- 공개 버전: `1.0.2`
- 내부 개발 계보: `23.1.0`
- 단조 증가 빌드 ID: `b24.2`

과거 회귀 검증은 내부 계보를 사용하고, 플레이어 화면·패키지·패치 ZIP은 공개 버전을 사용한다. 서비스 워커와 캐시는 빌드 ID를 사용한다.
