# Clear Horizon v16.0.0

## 목표

v15 이후 사용자 체감과 코드 상태 사이의 차이를 제거한다.

- 카메라가 중앙 수호성과 겹칠 때 과도하게 가까워지지 않을 것
- 새 아틀라스 에셋이 실제 플레이 화면에서 명확하게 보일 것
- 첫 접속 화면은 플레이 시작에 필요한 정보만 제공할 것
- 캐시·로딩·렌더 경로 문제를 런타임에서 감지할 것

## 1. Camera Guard

### 발견된 문제

중앙 수호성은 내비게이션 충돌과 카메라 충돌에 동시에 등록되어 있었다. 카메라의 목표점과 실제 카메라 위치 사이에 성이 들어오면 레이 충돌 결과가 5~8 거리까지 짧아질 수 있었다.

### 변경

- 중앙 수호성의 `cameraObstacles` 등록 제거
- `resolveCameraCollisionDistance`에서 `core` 유형을 명시적으로 무시
- Scenic 최소 거리 14.8, Balanced 12.8, Close 10.4
- 중앙 접근 시 줌인 대신 `coreKeepout`으로 소폭 후퇴·FOV 확대
- 플레이어를 가리는 성과 신목 재질을 부드럽게 반투명 처리

## 2. Visible Atlas

### 발견된 문제

아틀라스 파일과 코드 연결은 존재했지만 주요 스프라이트가 화면 외곽에 작게 배치되었다. 직업 선택 카드와 도감 외에는 사용자가 즉시 확인할 수 있는 지점이 부족했다. 동일 파일명의 정적 WebP는 브라우저 캐시에 남을 가능성도 있었다.

### 변경

- 모든 아틀라스 페이지 URL에 `v=16.0.0` 적용
- WebP 실패 시 동일 페이지 PNG 자동 대체
- 장터 문·제단·등불·수정·환경 장식을 중앙 전장권에 재배치
- 주요 스프라이트의 월드 스케일 확대
- 선택 영웅 초상을 전투 HUD와 첫 화면 로드아웃 요약에 표시
- 로딩 성공·대체 사용·오류 메시지를 제작 콘솔에 기록

- 설정

## 4. Runtime Visual Audit

검사 항목:

1. 아틀라스 로딩 성공
2. 전장 스프라이트 7개 이상 활성화
3. 살아있는 전장 프롭 3개 이상 활성화
4. 영웅 선택 카드 5개가 아틀라스 프레임 사용
5. 첫 화면에 플레이 액션만 노출
