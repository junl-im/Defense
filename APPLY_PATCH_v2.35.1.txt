KingdomSeed v2.35.1 Mobile Combat Juice Patch

기준 파일:
- KingdomSeed_v2.35.0_Clean_Full_Source.zip

적용 방법:
1. 이 zip의 내용을 기존 KingdomSeed 프로젝트 루트에 그대로 덮어씁니다.
2. node_modules, dist, .git은 포함되어 있지 않습니다.
3. 적용 후 권장 확인:
   npm ci
   npm run build

검증 결과:
- npm run build 실행 완료
- TypeScript tsc 통과
- Vite production build 통과
- Vite 500 kB chunk warning은 기존 구조상 남아 있으며 빌드 실패가 아닙니다.
