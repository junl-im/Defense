KingdomSeed v2.36.27 MOBILE BACK NAVIGATION GUARD

적용 방법:
1. 기존 프로젝트 루트에 이 패치 zip의 내용을 덮어씁니다.
2. npm ci
3. npm run build

핵심 변경:
- 모바일 브라우저 뒤로가기 버튼을 게임 네비게이션으로 가로챕니다.
- 게임 중 뒤로가기 1회는 MainMenuScene 첫 화면으로 돌아갑니다.
- 첫 화면에서 뒤로가기 1회는 종료 확인 팝업을 띄웁니다.
- 종료 팝업이 떠 있을 때 뒤로가기 1회 추가 또는 종료 버튼 탭은 보호 저장 후 브라우저 이탈을 시도합니다.
- 모바일 기본 UI 밀도를 focus로 낮춰 전장과 핵심 액션이 더 잘 보이게 정리했습니다.
