도깨비 운빨 수호대 3D v1.1.0 -> v1.2.0 패치 적용

패치 ZIP의 안내 파일 3개는 프로젝트에 복사하지 않습니다.
프로젝트에는 PATCH_FILES 폴더의 내용만 복사합니다.

1. GitHub Desktop에서 현재 변경 사항을 커밋하거나 프로젝트 폴더를 백업합니다.
2. 실행 중인 npm dev/preview 서버를 종료합니다.
3. DELETE_FILES.txt에 적힌 파일을 기존 v1.1.0 프로젝트에서 삭제합니다.
4. PATCH_FILES 폴더 안의 모든 파일과 폴더를 기존 프로젝트 루트에 덮어씁니다.
5. 프로젝트 루트에서 아래 명령을 실행합니다.

   npm install
   npm run verify
   npm run build

6. GitHub Desktop에서 변경 내용을 확인하고 main 브랜치에 커밋/push합니다.
7. Firebase 규칙은 기존 Defense 경로를 보존한 병합본이므로 firestore.rules 전체를 유지합니다.

적용 후 프로젝트 루트 Markdown 파일은 README.md와 PROJECT_HANDOFF.md 두 개만 있어야 합니다.
패치 상세 기록과 다음 작업은 PROJECT_HANDOFF.md에 통합되어 있습니다.
