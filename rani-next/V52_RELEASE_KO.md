# 라니킹덤 v5.2 — 실제 2.5D 월드 그래픽 개선

## 변경 사항 (실제 게임 엔진에 적용)
- `rani-next/v52-scene.mjs`: 원본 Fiefdom `src/main.ts` 월드 장식 생성에 직접 패치.
  - 신규 `rani_coast` 지도에서 과도한 야자수 일부를 참나무·올리브나무로 대체. **원본 `coast`와 과거 저장 지형, 타일 점유·목재 채취·길찾기는 그대로 유지**.
  - 나무·관목 각각 `x,z,종류` 기반 안정적인 5종 색조를 SpriteBatch의 `iTint` GPU 경로에 전달. 저장·로드·카메라 회전 시 임의 재추첨 없음.
- `rani-next/v52-building-polish.py`: 성·성문·망루·민가·시장·병영·종교 시설 19종×4방향 **76장 진짜 PNG** 명암·색채 보정, 원래 픽셀 투명도·그림자·앵커 유지.
- `rani-next/v52-forest-polish.py`: 실제 나무·관목·바위 **6종×4방향 24장** 디테일 보정, 원본 그림자 투명도 확인.
- `rani-next/v52-shore.mjs`: Three.js `src/engine/terrain.ts`의 실제 WebGL 월드에 바다와 육지 접촉 방향을 기록하고, **물 타일 안쪽에만** 작은 얕은 물/해안 윤광 렌더. 기존 지형 타입 ID·물 충돌·이동/건축 로직은 건드리지 않음.
- 기존 v5.1의 6종 무손실 WebP 지형색 보정은 그대로 적용. **SVG 생성/이미지 금지, 한국어 게임 UI 유지**.

## 기능·라이선스 보호
- 사용자 승인 16종 원본 이미지 sha 잠금 유지, 사용자 인터페이스 래스터 우선.
- 신규 자산은 원본 게임의 라이선스 고지를 따름: Fiefdom AGPL-3.0-only, 0 A.D. 파생 일부 CC BY-SA 3.0.
- 새 버전은 여전히 해당 라이선스의 소스 공개 의무가 있는 **Fiefdom 기반 게임**이며 원본 작성자 귀속을 계속 명시.
- 구버전 v4는 `/Defense/legacy/` 경로에 보존, 새 게임의 저장 포맷 변경·자동 마이그레이션 없음.
- 기존 건설·생산·전투·조작 기능 그대로; 텍스처 색감 및 월드 그리기만 조정.

## 검증
- `npm test` 원본, 한글 및 SVG=0 체크, `npm run build` TypeScript/GLSL 패키징.
- 실제 Chromium 게임 시작·4건축·600초 시뮬레이션, 소스/빌드 이미지·SVG 검사.
- `/Defense/`와 `/Defense/legacy/` 루트 경로 실브라우저 QA 후 main 병합 및 GitHub Pages 배포.
- 단, **새 4방향 왕궁 모델을 생성한 게 아니며 새 항구·정박 무역선·배 항해 및 실제 폭포는 미구현**. 필요한 원본 아트 및 물리 기능은 후속 개발 진행.

## 이후 그래픽 목표
- 각각 4방향 원본 PNG/WebP를 갖춘 왕궁·시장·병영·공사 현장 아트, 계절형 숲 디테일.
- 실제 부두·배·선박·물가 소품을 통과/클릭/저장에 연결한 새 항구 기능(먼저 자산/엔진 통합 설계 검증).
- 모바일 실기기 FPS, 표면 경계의 실제 비교스크린샷, 100% 남은 동적 한글 이벤트 점검.
