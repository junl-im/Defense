KingdomSeed v2.36.21 REFERENCE VARIANT MATRIX

Apply by copying this patch over the existing project root.

This patch adds a no-text reference variant matrix:
- framed reference art slots for hero hall, codex, build menu and spell buttons
- selected, locked, elite, boss, upgrade and spell states without baked text
- tiny no-text pips instead of writing labels inside images
- reference actor pedestals for tower/enemy/hero battle objects
- essential reference-art mode for weak devices and emergency fallback

No .git, node_modules, dist, or temporary files are included in the patch zip.
