KingdomSeed v2.36.19 REFERENCE ASSET INTAKE

적용 방법:
1. 기존 프로젝트 루트에 이 패치 zip을 그대로 덮어씁니다.
2. node_modules, dist, .git은 포함되어 있지 않습니다.
3. npm ci
4. npm run build

검수 추천:
- 기본 주소: 정상 실행 및 첫 탭 영향 확인
- ?referenceart: 사용자 제공 레퍼런스 no-text 자산 강제 확인
- ?norefart: 이전 fallback과 비교
- ?textsheet: 레퍼런스 자산 사용 금지 비교
- ?pngart: WebP 대신 PNG 경로 확인

주의:
- 원본 콜라주 전체를 런타임에 쓰지 않습니다.
- 글씨/라벨이 있는 영역은 crop 대상에서 제외했습니다.
- 전투 중 waveRunning 상태에서는 새 actor art 로드를 시작하지 않습니다.
