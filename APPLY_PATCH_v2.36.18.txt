KingdomSeed v2.36.18 Supreme Design Fallback System

Apply this patch by copying the zip contents over the existing project root.
This patch is intended to be applied after v2.36.17.

Included changes:
- Adds SupremeDesignSystem scene-wide premium design layer.
- Adds design grades: supreme, accessible, essential, balanced.
- Adds WebShell/root CSS support for the same design language before Phaser loads.
- Adds a Design button to the fallback panel.
- Updates version metadata and documentation.

After applying:
1. npm ci
2. npm run build
3. npm run preview

Useful QA URLs:
- /?supremedesign
- /?accessibledesign
- /?essentialdesign
- /?designpanel
- /?nodesignsystem
