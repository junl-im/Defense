KingdomSeed v2.35.7 Run Recovery Patch

1) 이 zip을 프로젝트 루트에 덮어씌웁니다.
2) 기존 dist 캐시가 있다면 삭제하거나 새로 빌드합니다.
3) npm run build
4) npm run preview 또는 배포 환경에서 확인합니다.

중요:
- 이번 패치는 실행 복구가 목적입니다.
- Vite base 기본값을 './'로 바꿔 하위 경로 배포에서 JS/CSS 청크 404를 줄였습니다.
- 절대 루트 배포가 필요한 환경은 VITE_BASE_PATH=/ npm run build 를 사용하면 됩니다.
- 시작 게이트에 '엔진 스크립트를 아직 못 불러왔습니다'가 뜨면, 이전 dist 캐시 또는 배포 경로 문제일 가능성이 높습니다.
