# Kingdom Seed v3.9 Premium Polish Pass

이번 패치는 기능 추가보다 “상용 게임처럼 보이는 마감”에 집중한 대규모 디자인 다듬기 패치입니다.

## 핵심
- 타이틀/월드맵/전투 배경의 조명, 명암, 깊이감 재정리
- HUD/버튼/패널/도크/툴팁/모달 프레임 재생성
- 스테이지 카드 8종 리마스터
- 모바일 회전 보조는 유지하되 PC에서는 CSS 차원에서도 회전 방지 보강
- PremiumDesignKit에 화면 전환 wipe, 버튼 광택, 패널 글로우 보강
- 새 UI FX: 버튼 글린트, 보상 버스트, 화면 전환 베일

## 적용
기존 프로젝트 루트에 이 폴더 내용을 덮어쓴 뒤:

```bash
npm run build
```

성공하면 GitHub Desktop에서 커밋/푸시하세요.
