# Kingdom Seed v3.8 Premium UI/UX Art Direction Patch

상용 모바일 전략/디펜스 게임의 공통 디자인 문법을 Kingdom Seed 스타일로 재해석한 대규모 디자인 패스입니다.

## 핵심
- 타이틀/로그인 화면, 월드맵, 스테이지 카드, 전투 배경 리마스터
- HUD, 버튼, 패널, 보상창, 제작소 패널 톤 통일
- 타워 Lv.1~3 및 최종 진화 타워 스프라이트 개선
- 보상 상자, 유물 아이콘, 영웅 초상화 리워크
- PremiumDesignKit 확장: 패널/버튼/토스트/레터박스/부유 먼지 유틸

## 적용
압축을 풀고 `kingdom-seed-v3.8-patch` 안의 내용을 프로젝트 루트에 덮어쓴 뒤 `npm run build`를 실행하세요.
