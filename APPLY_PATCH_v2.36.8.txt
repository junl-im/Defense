KingdomSeed v2.36.8 LOCAL RESULT FIRST 적용 안내

1. 이 zip의 내용을 기존 KingdomSeed 프로젝트 루트에 덮어씌웁니다.
2. 포함된 파일은 소스/문서/설정 변경분만이며, .git, node_modules, dist는 제외되어 있습니다.
3. 적용 후 아래 명령으로 확인합니다.

   npm ci
   npm run build

4. 권장 검수 순서
   - 기본 주소에서 빠른 시작
   - ?quality=low
   - ?safe=1
   - 빠른 시작 local guest로 스테이지 클리어 후 결과 화면 즉시 표시 확인
   - 연구소 local guest 업그레이드 확인
   - 로그인 계정의 클라우드 저장/리더보드 확인

핵심 변경: 전투 클리어/연구소 local guest 경로는 Firebase 청크와 네트워크를 기다리지 않고 로컬 저장으로 즉시 진행합니다.
