KingdomSeed v2.36.16 Adaptive Fallback Suite

적용 방법:
1. 기존 KingdomSeed 프로젝트 루트에 이 패치 zip의 내용을 그대로 덮어씁니다.
2. node_modules, dist는 포함되어 있지 않습니다.
3. 필요 시 아래 명령으로 확인합니다.
   npm ci
   npm run build

주요 변경:
- AdaptiveFallbackDirector.ts 추가
- 모바일/저사양/작은 화면/느린 네트워크/오프라인/런타임 watch 상태에서 적응형 fallback class 적용
- 씬 내부 `보기` 패널 추가: 큰 UI, 고대비, 저사양, 비상, 기본
- WebShell 시작 게이트에서도 저장된 fallback 설정 반영
- PrestigeGraphicFallback이 ksSafeGfx/ksEmergencyFallback/ksContrastUi 저장값을 반영
- CSS adaptive fallback class 추가
