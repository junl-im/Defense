# BLOCK SURVIVAL TPS v0.8 — 자체 절차적 전투 애니메이션

2026-10-30 · 곰같은여우 · 기존 GitHub Pages 웹게임 유지

## 실제 변화
- Kenney 현대 생존자·언데드의 Idle/Run/Jump 원본 클립 3종은 그대로 유지. 전용 사격/장전/피격/사망 클립은 이 CC0 원본에 없음.
- combat-pose.mjs 순수 함수: 사격 반동 강도·재장전 중간 총기 하강·조준 시 견착각·피격 순간 기울임·언데드 근접 공격 기울임·0.58초 이내 사망 넘어짐 계산
- game.mjs: 양팔 상완 리깅 본 보정에 반동/견착 계산 반영, 오른손 총기 회전·이동 연동, 적의 Hit/Death 전용 클립 없는 상황에서도 부드러운 몸통 회전으로 체감 타격감 강화
- 현대 캐릭터가 없는 환경에서 기존 KayKit 애니메이션 및 블록형 메쉬 폴백 경로 유지
- 새 로직 단위 테스트와 기존 전투·군중·보급품·LOD/모바일 회귀 검사 전부 통과한 경우에만 main 승격

## 범위와 제약
- 새로운 외부 라이선스/자산 추가 없음. 전체 12종 런타임 GLB CC0, Three.js MIT, SVG 0개 원칙.
- 실제 '애니메이션 전용 모션 캡처'나 '블렌더에서 수작업으로 만든 시퀀스'로 오인하지 않게 명시. 절차적 트랜스폼 방식.
- Chrome 소프트웨어 WebGL QA와 실제 기기 GPU 성능을 구분.
