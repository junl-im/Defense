## 새 기능
- 모델: 기존 KayKit Knight / Skeleton 대신 정식 CC0 Kenney Modern Survivors FBX를 직접 변환한 현대 생존자·일반 좀비·러너로 우선 표시. 이전 GLB 캐릭터는 다운로딩 실패 폴백.
- 현대 생존자 남성형 스킨 survivorMaleB, 좀비 zombieA, 러너 zombieC. 58개 뼈대, 826폴리곤 기본 메쉬, PNG 피부·옷 텍스처를 통합한 GLB.
- 정확한 원본 ZIP SHA256 9cc53e82c941781f26aa8fb39d40887cf14b1d74cca2d10ccc6e7c140a68f820, Kenney 작성 OpenGameArt 원저자 미러. Kenney 공식 랜딩페이지는 자동 다운로드 요청에 HTML이 반환되어 미러를 사용.
- Blender 4.0.2 변환으로 보존된 3개 리깅 애니메이션은 Idle / Run / Jump. 총기 사격, 히트, 사망 전용 원본 애니메이션은 없음. 간단한 자체 포즈/반동/사망 기울임으로 대체.
- 현대 캐릭터 과대 확대·팔 '만세' 포즈 오류를 실제 PC/모바일 스크린샷 역검수 후 수정. 58개 본의 올바른 월드/부모 로컬 Quaternion 회전 보정, 실제 RightHand 본에 Kenney 블라스터 연결.
- 모델 오류 시 기본 리깅 GLB와 블록형 폴백 유지. 전체 정적 게임 에셋 12개 CC0 GLB(기존 9+현대 3), 외부 CDN 불필요.
