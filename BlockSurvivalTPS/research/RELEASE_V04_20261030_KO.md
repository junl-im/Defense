# 블록 서바이벌 TPS v0.4 — 애니메이션 캐릭터·경량화

2026-10-30 · 곰같은여우 · 설치 없는 무료 웹게임

## 새 기능
- KayKit Adventurers Knight 리깅된 주인공. Idle, Walking_A, Running_A, 1H_Ranged_Shoot, 1H_Ranged_Reload, Hit_A 총 6개 애니메이션
- KayKit Skeleton_Minion 언데드. Idle_Combat, Walking_D_Skeletons, Running_A, Unarmed_Melee_Attack_Punch_A, Death_A, Hit_A 총 6개 애니메이션
- Kenney CC0 blaster를 손뼈 handslot.r에 장착. 애니메이션된 모델 원본의 별도 검·방패는 화면 비노출
- 실제 PC와 모바일 스크린샷을 직접 검토하여 생존자와 언데드 모델의 정면 방향을 교정
- 총구 섬광 3D 효과와 실제 명중 시에만 조준점 색이 바뀌는 피격 표시
- src/tools가 아닌 tools/compact-glb.mjs: 원본 GLB에서 사용하지 않는 애니메이션·accessor·binary bufferView를 제거하는 자체 경량화 도구

- Knight 원본 3,659,532바이트 → 630,020바이트(약 83% 감소), 스킨 1개, 6개 애니메이션 보존
