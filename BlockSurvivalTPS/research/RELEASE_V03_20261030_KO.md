# Block Survival TPS v0.3 — 검증 가능한 개발 기록 (2026-10-30)

## 적용
- `src/navigation.mjs`: 8방향 A*, 그리드 반경/모서리 통과 방지, 선분 스무딩, 800 노드 제한, 경로 캐시.
- `src/sim.mjs`: 장애물에 막힐 때 경로탐색·재탐색, 플레이어 이동 시 목표 갱신, 적 정체 복구, 엄폐물 뒤 대상 조준 보정 차단.
- `src/game.mjs`: 카메라 중앙 방향을 쏘는 TPS 조준 계산. 기존 블록형 대체 모델 유지.
- `style.css`: 350~390px 화면에서 HUD·사격 버튼 잘림 방지.
- `tests/browser_qa.py`: 실제 Chromium headless SwiftShader WebGL 확인, 데스크톱/모바일 게임 시작·사격·UI 실측.

## 검증
- [Playwright QA Actions 40963580690](https://github.com/junl-im/Defense/actions/runs/40963580690): success. 실제 desktop canvas 1280x720, mobile viewport 390x844, 각 탄약 12→11. 모바일 scrollWidth=390, scrollHeight=844; health+ammo 중첩 검사 통과.
- QA는 GPU 하드웨어가 아닌 Chromium SwiftShader 소프트웨어 렌더러. 인쇄된 순간 FPS는 실제 폰·PC GPU FPS 수치가 아님.
- [브라우저 시각 검증 스크린샷 아티팩트 12936883254](https://github.com/junl-im/Defense/actions/runs/40963580690/artifacts/12936883254): 데스크톱·모바일 이미지 포함. 이미지 검수 결과 조작 HUD 겹침 없이 보임; 그래픽은 아직 임시 블록 모델 기반으로 미려한 최종 작품과 거리 있음.
- 기존 KayKit/Gobkit/Kenney CC0 원본 8개 출처·60파일, 실행 내장 7개 GLB, 라니킹덤 아카이브 보존.
