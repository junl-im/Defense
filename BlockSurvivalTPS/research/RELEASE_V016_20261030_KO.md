# 《라니블록 생존》 v0.16 — 사격·재장전·피격 모션 강화

2026-10-30 | 구현 타깃: GitHub Pages 웹 TPS

## 변경 사항

1. 사격 시 상체 리코일(후방 반응), 좌우 어깨 높이와 소총의 후퇴·반동 각도를 한 프레임에 함께 적용한다. Kenney Animated Characters Survivors 모델의 실제 스켈레톤을 활용하며 가짜 팔/별도 캐릭터 모델은 추가하지 않는다.
2. 재장전 동안 소총 회전·하강·미끄러짐과 보조 팔 위치, 상체 자세를 한 사이클 안에서 변경한다. 입력/탄약 상태 시뮬레이션과 분리된 계산(src/combat-pose.mjs)을 사용한다.
3. 현대 좀비/러너 모델의 피격 시 머리 방향 반응과 짧은 주황색 emissive 피드백을 추가한다. 스킨 메시 재질을 적 개체별로 복제해 서로의 색이 공유되는 오류를 방지한다. 적 제거 또는 레거시 모델 교체 시 복제 재질을 해제한다.
4. 기존 전투 판정, 좀비 이동/공격 클립 및 모바일 조작, 카메라 방향, 폰트와 HUD는 유지한다.
5. SVG 사용 없음. 신규 타사 자산 없음. 사용 중인 CC0 모델/텍스처의 라이선스 정책은 기존과 동일하다.

## 검증

- 새로운 Node 단위 테스트 tests/v016-action-motions.test.mjs: 발사 자세, 재장전 모션, 좀비 피격/사망 경계, 비정상 입력 유한 값 검사.
- tests/browser_qa.py: 실제 데스크톱 WebGL 렌더링에서 발사 자세가 활성화됐는지와 R키 재장전 자세가 나타났는지 확인. PC·모바일 세로·가로 HUD/공격/회피 회귀 검사 유지.
- GitHub Actions는 PR 및 main 자동 검증 기준. 테스트 결과는 실제 워크플로 실행 완료 후 별도 기록한다.
