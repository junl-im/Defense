# Block Survival TPS v0.14 — 시점 조작 정상화·실제 보행 모션

날짜: 2026-10-30 · 책임자 표시: 곰같은여우 · 자산 라이선스: 기존 source-lock 및 PROVENANCE_MODERN.json 유지

## 사용자 증상 및 원인
- PC 마우스를 오른쪽으로 움직여도 yaw 값을 감소시키던 역방향 입력을 바로잡음. 모바일 lookZone 역시 수평 방향 반대 적용을 수정.
- 마우스·터치 각각 감도(PC 0.0021 / 0.0017, 모바일 0.005 / 0.0036) 분리. 수직 pitch 범위 유지.
- Run/Idle 클립이 연결되어도 실제 관절 움직임 검증이 없어 캐릭터가 미끄러져 보일 수 있었음.
- 기존 이동 명령만으로 걷기 상태를 판단하던 코드를 실제 x/z 위치 변화 기반으로 교체.

## 구현
- src/control-math.mjs: 마우스·터치 동일 수평 규칙, 비정상 좌표 필터링, 입력 스파이크 제한.
- src/combat-pose.mjs: 보폭 반대위상, 무릎 굽힘, 무게중심 바운스, 달리기 상체 전방 기울기 및 좌우 무게이동 레이어.
- src/game.mjs: 실제 SkinnedMesh 골격의 양쪽 대퇴골 추적 및 애니메이션 위 가벼운 보행 오버레이. 기존 CC0 아바타/무기/자산 보존, SVG 미사용.
- tests/v014-controls-locomotion.test.mjs: 좌우 시점 극성·터치 조작·보행 진폭·정지 복원 테스트.
- tests/browser_qa.py: PC 실제 W키 이동 중 대퇴골 관절 변화 감지(`data-hero-leg-motion=detected`) + Run 애니메이션 활성화 검증. 모바일·가로모드 검증 유지.

## 주의/향후 검토
