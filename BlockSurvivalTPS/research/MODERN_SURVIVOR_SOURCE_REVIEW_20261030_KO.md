# 차기 모델 조사: 현대 생존자·좀비 후보 (v0.6)

공식 제공: https://kenney.nl/assets/animated-characters-survivors
원 저작권/라이선스: Kenney Creative Commons CC0 (공식 배포 페이지에서 2026-10-30 확인)
확인된 형식: FBX 애니메이션 모델 + PNG 캐릭터 스킨, SVG 포함 가능. 공식 ZIP 8개 파일.
후보: Survivor Female A / Survivor Male B / Zombie A / Zombie C (실제 GDevelop 패키지 인덱스 포함)

판정: 아직 게임 실행 자산으로 채택·배포하지 않음.
이유: Three.js 런타임은 현재 GLB 전용 파이프라인. FBX를 GLB로 변환한 뒤 애니메이션 트랙, 뼈대, PNG 텍스처, 법적 출처, 스케일, 방향, 프레임·압축률을 자동 검증해야 함.
SVG 소스는 어떤 경우에도 사이트/자산 폴더에 동봉하지 않음. GLB/PNG 바이너리만 검증 후 채택.
미리보기·게임 테스트를 통과한 자산이 기존 KayKit 중세풍 캐릭터보다 더 현대적인 외형과 성능을 보장할 때 교체.

원본 Kenney CC0와 곰같은여우의 자체 게임 소스 권리는 명확히 구분하여 기록.
