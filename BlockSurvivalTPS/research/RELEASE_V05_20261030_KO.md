## 실제 소스 변경
- src/world-detail.mjs 신규 추가: 모든 잔해·도로 파손·잡초는 InstancedMesh 기반 저비용, 결정적 PRNG 배치. 플레이어 주요 이동로와 기존 COVER 구조 보호
- src/sim.mjs: 3킬마다 탄약 +18, 5킬마다 응급 키트 +24, 1.35m 자동 수거, 18초 소멸, 필드 보급품 12개 최대
- src/game.mjs: 아이템 부유 애니메이션·보급품 3D 아이콘, 엄폐물과 일치하는 사격 궤적·명중 섬광, 인코드 합성 WebAudio 사격음(외부 파일 0개)
- src/game.mjs: 주인공 리깅 모델의 색상톤을 저채도 녹색·회색으로 보정, 3초 HUD 안내 자동 사라짐
- test/loot.test.mjs: 적 처치 보상, 탄약 충전, 응급치료, 체력 만충 보존, 보급품 만료/개수 제한, 정지상태 검사
- 기존 v0.4 경량 리깅 모델 2종·3인칭 카메라·엄폐 우회 AI·PC/모바일 가로세로 대응 및 8개 CC0 출처·60개 선별 자산을 변경 없이 유지

- 저사양 모바일과 Chromium SwiftShader CPU 소프트웨어 렌더러의 성능은 다름. 실제 휴대전화 GPU FPS, 발열, 배터리 별도 실측 필요
