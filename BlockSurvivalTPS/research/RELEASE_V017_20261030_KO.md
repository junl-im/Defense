# 《라니블록 생존》 v0.17 — 방향별 움직임과 회피 착지, 좀비 공격 모션

2026-10-30 | 이전 안정판 v0.16을 기반으로 한 보행/액션 디테일 패치.

## 변경

1. 이동 애니메이션: 실측 움직임 여부 기반 보행을 유지하며 왼쪽/오른쪽 이동 때 스킨 모델의 골반 회전과 옆 기울기를 추가. 뒤로 걸을 때 발걸음 위상을 반전하고 상체 무게 중심을 뒤로 배치.
2. 회피 애니메이션: 기존 0.25초 무적 회피 동안 Kenney Survivors의 원본 Jump 클립을 실제 활성화. 가벼운 도약 높이·몸 기울기·두 대퇴골 접힘을 본 모델 위에 합성하되 게임 판정은 지면의 기존 이동/회피 상태를 그대로 유지.
3. 착지: 회피 종료 순간 양 발 접지 파티클(기존 풀 4개)과 0.2초 몸 중심 압축·복귀를 연동. CPU 및 GPU 자원 증가 제한.
4. 현대 좀비·러너 공격: 근접 공격 경고부터 충돌 프레임까지 실제 좌우 상완골 방향을 조절해 양팔을 뻗는 모션을 추가. 머리 끄덕임·기존 돌진 거리/공격 판정과 동기화.
5. 사격·장전·피격 반응, 사용자 선호 카메라 방향, PC/모바일 단일 화면 HUD, 91개 기존 테스트 유지.

## 품질 게이트

- 신규 Node pose 검증 6개: 후진 발 움직임, 좌우 이동 회전, 회피 도약, 착지 압축, 좀비 양팔 공격, 비정상 숫자 방어.
- PC 실제 WebGL QA: Space 회피 시 Jump 애니메이션 활성화와 모델 도약 감지, 0.25초 뒤 착지 감지, D키 좌우 몸 회전 감지.
- 이전 PC·모바일 세로 390×844, 가로 844×390 화면 및 사격/재장전 테스트 포함.
- GitHub Actions의 전체 소스/라이선스 검사, 독립 실행 빌드, PC·모바일 WebGL, Pages 배포 완료 후 확정.
