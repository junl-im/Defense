# Kingdom Seed v4.0 Premium Polish Patch

이번 패치는 새 스테이지 추가보다 문제점 점검과 프리미엄 마감에 집중한 패치입니다.

## 핵심

- PC 전체화면/회전 개입 방지 CSS 보강
- 모바일 safe-area 대응 강화
- 버튼/패널/HUD/툴팁/도크/카드 에셋 재정리
- 전투 배경 8종 프리미엄 리마스터
- 월드맵 배경/스테이지 카드 리마스터
- PremiumDesignKit 확장
- PolishAuditV40 추가

## 적용

`kingdom-seed-v4.0-premium-polish-patch` 폴더 내용을 기존 프로젝트 루트에 덮어쓴 뒤:

```bash
npm run build
```

성공하면 GitHub Desktop에서 commit/push 하세요.
