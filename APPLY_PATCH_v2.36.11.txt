KingdomSeed v2.36.11 Scene Prestige Cohesion Patch

How to apply:
1. Start from the v2.36.10 integrated project root.
2. Unzip this patch over the project root and allow overwrite.
3. Do not copy node_modules or dist from another build.
4. Run:
   npm ci
   npm run build

This patch intentionally excludes:
- .git
- node_modules
- dist
- temporary files

Main focus:
- Login/lobby/world-map prestige cohesion
- Less emoji-forward/toy-like UI presentation
- Static low-cost frame and information panel polish
- No new heavy art in the initial boot path

Escape hatches:
- ?plainui
- ?legacyui
- ?toydebug
- ?plainbattle
- ?flatbattle
