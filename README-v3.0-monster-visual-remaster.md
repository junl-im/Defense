# Kingdom Seed v3.0 Monster Visual Remaster Patch

## 목적

v2.9 이후에도 몬스터 실루엣이 아직 프로토타입처럼 보이는 문제를 해결하기 위한 대규모 에셋 리마스터입니다.
이번 패치는 TypeScript 로직을 건드리지 않는 **파일명 호환형 에셋 교체 패치**입니다.

## 핵심 변경

- 31종 몬스터 스프라이트 전체 재생성
- 32x32 x 36프레임 기존 규격 유지
- walk / attack / death / up / side / down 모션 유지
- 소형 / 중형 / 비행 / 장갑 / 마법 / 보스 실루엣 분리
- 몬스터별 그림자, 하이라이트, 림라이트, 무기/날개/오라 디테일 추가
- 보스 이름표, 몬스터 특성 뱃지, 타격 FX, 엘리트 오라 에셋 추가

## 적용

프로젝트 루트에 덮어쓰기 후:

```bash
npm run build
```

성공하면 GitHub Desktop에서 Commit & Push 합니다.

## 안전성

기존 코드가 로드하는 파일명과 프레임 규격을 유지합니다.
따라서 빌드 에러 가능성을 낮추기 위해 src 파일은 변경하지 않았습니다.
