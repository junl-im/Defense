# Kingdom Seed v1.0 Patch

## 핵심 변경

- 4개 스테이지 전투맵 배경 아트 추가
- 상단/하단 HUD 패널 스킨 추가
- 건설 먼지 이펙트 추가
- 업그레이드 버스트 이펙트 추가
- 적 사망 poof 애니메이션 추가
- 포탑/메테오 폭발 spritesheet 이펙트 추가
- GameScene이 배경 이미지를 우선 사용하도록 변경
- ART_PIPELINE.md를 v1.0 기준으로 갱신

## 적용 방법

압축을 풀고 `kingdom-seed-v1.0-patch` 안의 파일을 기존 프로젝트 루트에 덮어쓰기 합니다.

```bash
npm run build
```

성공하면 GitHub Desktop에서 commit/push 합니다.

```txt
Summary: Add combat map art and battle animations
```

배포 확인 URL:

```txt
https://junl-im.github.io/Defense/?v=100
```
