# Kingdom Seed v3.4 - Combat Depth & Retention Polish Patch

이번 패치는 전투의 반복 재미와 상용 게임식 전투 피드백을 강화합니다.

## 핵심

- 전투별 3성 보조 목표 UI 추가
- 연속 처치 콤보 보너스 추가
- 전투 지휘 힌트 시스템 추가
- 웨이브 시작 시 몬스터 구성에 따른 대응 추천 표시
- 결과 화면에 목표 달성 항목 표시
- 생명력 보존/무누수/연속 처치/빠른 클리어 평가 추가

## 적용 파일

- `src/scenes/GameScene.ts`
- `public/assets/ui/*_v34.png`
- `docs/COMBAT_DEPTH_V34.md`

npm run build
