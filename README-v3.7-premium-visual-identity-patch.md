# Kingdom Seed v3.7 Premium Visual Identity Patch

## 적용 방법

`kingdom-seed-v3.7-patch` 폴더 안의 내용을 기존 프로젝트 루트에 덮어쓰기.

```bash
npm run build
```

성공 후 GitHub Desktop에서 commit/push.

## 핵심 변경

- 타이틀/로그인 화면 아트 리마스터
- 월드맵과 스테이지 카드 8종 리마스터
- 전투 배경 8종 리마스터
- HUD/버튼/패널/보상창 프리미엄 톤 통합
- 타워 기본/업그레이드/최종진화 스프라이트 재생성
- CSS 렌더링 디테일 개선
- PremiumDesignKit 유틸 추가

## 주의

이번 패치는 상용 게임들의 UI 문법을 참고하되, 특정 게임의 화면 구성/아이콘/로고/캐릭터를 직접 복제하지 않는다.
