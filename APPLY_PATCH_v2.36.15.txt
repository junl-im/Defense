KingdomSeed v2.36.15 MASSIVE GRAPHIC FALLBACK 적용 안내

1. 기존 프로젝트 루트에 이 zip의 내용을 그대로 덮어씌웁니다.
2. 포함된 파일은 소스/문서/버전 파일 중심입니다.
3. `.git`, `node_modules`, `dist`, 임시 파일은 포함하지 않았습니다.
4. 적용 후 권장 확인:
   - npm ci
   - npm run build
   - npm run preview
5. 그래픽 검수 추천 URL:
   - 기본: /
   - 강제 폴백: /?graphicfallback
   - 안전 그래픽: /?safegfx
   - 고대비 그래픽: /?contrastgfx
   - 이전 비교: /?nographicfallback 또는 /?legacygfx
