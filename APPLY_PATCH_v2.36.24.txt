KingdomSeed v2.36.24 REFERENCE REWARD CONTINUITY

적용 방법:
1. 기존 KingdomSeed 프로젝트 루트에 이 zip의 내용을 덮어씌운다.
2. node_modules, dist, .git은 포함되어 있지 않다.
3. npm ci
4. npm run build
5. 기본 주소와 ?rewardpipeline, ?norewardart, ?essentialreward를 비교한다.

주의:
- 새 reward badge는 no-text 파생 자산이다.
- BootScene 프리로드에 넣지 않았다.
- 약한 기기에서는 자동으로 reward pipeline이 생략되거나 essential 표현으로 내려간다.
