v1.0.49 v145 CI 측정 핫픽스 적용 안내

1. 원본 프로젝트를 별도 백업합니다.
2. 이 ZIP의 overlay 폴더를 엽니다.
3. overlay 폴더 안의 내용 전체를 프로젝트 루트에 붙여넣고 같은 이름 파일은 덮어씁니다.
4. overlay 폴더 자체, APPLY_KO.txt, PATCH_MANIFEST.json은 프로젝트 루트에 복사하지 않습니다.
5. 기존 dist 폴더가 있다면 삭제한 뒤 의존성을 설치하고 새로 빌드합니다.
6. 권장 검증: npm run verify

핵심: 실제 하드웨어 기준은 유지하고, 명시적 SwiftShader/llvmpipe CI만 기준선 대비 악화율로 판정합니다. 표본 미달과 timeout은 계속 실패합니다.
