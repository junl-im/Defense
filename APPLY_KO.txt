Defense v1.0.46 CI Residency Autosync Hotfix

1. 이 ZIP을 임시 폴더에 풉니다.
2. overlay/ 폴더 안의 내용만 프로젝트 루트에 덮어씁니다.
3. APPLY_KO.txt와 PATCH_MANIFEST.json은 저장소 루트에 복사하지 않습니다.
4. 아래 명령을 실행합니다.

   npm ci
   npm run verify:ci
   VITE_BASE_PATH=/Defense/ npm run build
   npm run verify:dist:all

이 패치는 CI에서 residency 산출물을 결정적으로 재생성한 뒤 전체 검증을 실행합니다.
로컬 npm run verify는 기존처럼 strict check를 유지합니다.
