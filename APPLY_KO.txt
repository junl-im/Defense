1. 기존 프로젝트를 백업합니다.
2. 이 폴더의 파일과 폴더를 프로젝트 루트에 그대로 복사해 덮어씁니다.

4. 아래 명령을 실행합니다.

   rm -rf dist
   npm ci
   npm run verify:release:v144
   VITE_BASE_PATH=/Defense/ npm run build
   REQUIRE_BROWSER_V144=1 npm run verify:dist:all
