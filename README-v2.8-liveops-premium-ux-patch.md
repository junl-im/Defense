# Kingdom Seed v2.8 — LiveOps & Premium UX Mega Patch

## 핵심

- 영웅 전당 추가: 레온 / 아리아 / 녹스 선택
- 선택 영웅에 따라 전투 보너스 적용
- 왕국 임무 게시판 추가
- 일일/주간 미션과 보급 상자 보상 추가
- 전투 시작 시 지휘관 HUD 연출 추가
- 월드맵 하단에 영웅/임무 진입 버튼 추가
- 월드맵 v28 프리미엄 배경 추가
- 영웅 전당 / 임무 게시판 전용 배경, 카드, 초상화, 아이콘 추가
- PC 렌더링 대비/선명도 보정 CSS 추가

## 적용

기존 프로젝트 루트에 `kingdom-seed-v2.8-patch` 내부 파일을 덮어쓰기 후:

```bash
npm run build
```

성공하면 GitHub Desktop에서 Commit & Push.

배포 확인:

```txt
https://junl-im.github.io/Defense/?v=280
```

## 새 플레이 루프

월드맵 → 영웅 전당에서 영웅 선택 → 임무 게시판 확인 → 스테이지 클리어 → 보급 상자 획득 → 다음 전투 강화.
