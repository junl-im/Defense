KingdomSeed v2.35.3 Combat Runtime Cleanup Patch

기준 파일:
- KingdomSeed_v2.35.0_Clean_Full_Source.zip + v2.35.1 + v2.35.2 적용본

적용 방법:
1. 이 zip 파일의 내용을 KingdomSeed 프로젝트 루트에 그대로 덮어씁니다.
2. .git, node_modules, dist, 임시 파일은 포함하지 않았습니다.
3. 적용 후 권장 확인:

   npm install
   npm run build

검증 결과:
- npm run build 실행 완료
- TypeScript tsc 통과
- Vite production build 통과
- Vite 500 kB chunk warning은 기존 번들 구조상 남아 있으며 빌드 실패가 아닙니다.

변경 파일:
- src/game/CombatFxBudget.ts
- src/game/Enemy.ts
- src/game/Tower.ts
- src/scenes/GameScene.ts
- docs/PATCH_2_35_3_COMBAT_RUNTIME_CLEANUP.md
- APPLY_PATCH_v2.35.3.txt

핵심 내용:
- 사망 애니메이션 중인 적이 enemies 배열에 남아 웨이브 종료 판정을 막을 수 있는 문제 수정
- 킬/보상 판정은 즉시 처리하고, 사망 시각 연출은 씬 오브젝트로 독립 재생되도록 정리
- 전투 FX 예산 카운터에 자동 해제 watchdog 추가
- 씬 shutdown/destroy 시 Combat FX 예산을 리셋해 재시작 후 FX가 막히는 문제 방지
- Enemy destroy 시 독 타이머와 잔여 트윈 정리
- 포격/체인 타겟 판정에서 inactive enemy 제외
