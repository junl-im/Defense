KingdomSeed v2.35.4 Fast Start Boot Patch

적용 방법:
1. 이 zip을 기존 프로젝트 루트에 그대로 덮어씁니다.
2. node_modules, dist, .git은 포함되어 있지 않습니다.
3. 적용 후 권장 검증:
   npm install
   npm run build
4. 첫 시작 속도 테스트는 일반 주소 또는 ?quality=low / ?fast 로 진행하세요.
5. 기존 전체 프리로드와 비교하려면 ?legacyboot 또는 ?fullpreload 를 사용하세요.

핵심 변경:
- index.html 정적 시작 게이트 추가
- WebShell 정적 시작 게이트 재사용
- BootScene 기본 프리로드를 로그인 화면 최소 에셋으로 제한
- 기본 부팅 오디오 생략 및 lazy audio 유지
