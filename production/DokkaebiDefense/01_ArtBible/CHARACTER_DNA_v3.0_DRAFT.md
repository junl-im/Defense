# CHARACTER DNA SYSTEM v3.0 — DRAFT

> 상태: 확장 초안. `DD-ABSOLUTE-ART-BIBLE-2.0`을 절대 상속하며 어떤 항목도 v2.0을 변경하지 않는다.

## 1. Face DNA

- 눈 폭: 얼굴 폭 28% 고정
- 눈 높이: 얼굴 중앙보다 약간 아래 고정
- 눈 간격·광택 위치·코 점·입 위치를 공용 얼굴 템플릿으로 관리
- 표정 변형은 눈썹과 입만 허용, 눈 크기는 고정

## 2. Hair DNA

- 앞머리 / 뒷머리 / 장식 3영역
- 큰 덩어리 우선, 잔머리 노이즈 금지
- 직업 실루엣을 가리지 않도록 모자·뿔·귀와 충돌 검사

## 3. Class DNA

- 전사: 큰 곤봉 또는 검, 넓은 어깨, 낮은 중심
- 궁수: 큰 활, 화살통, 옆으로 열린 실루엣
- 법사: 큰 지팡이, 둥근 마력 코어, 긴 소매
- 도사: 긴 모자, 부적, 긴 소매
- 무당: 방울·부채·의식 장식, 좌우 비대칭 포인트
- 수호수: 큰 얼굴·꼬리·발, 둥근 귀

각 직업은 대표 실루엣 요소 3개를 반드시 등록한다.

## 4. Rarity DNA

- 모든 등급은 최대 4색과 무지개 금지를 유지
- 등급 차이는 색 개수 증가가 아니라 Gold Edge 면적, 장식 크기, FX 밀도, 무기 실루엣으로 표현
- 얼굴과 기본 체형은 등급에 따라 바꾸지 않는다.

## 5. Animation DNA

- 공용 Humanoid Rig
- 11개 필수 클립 이름과 루트 방향 통일
- 공격의 타격 프레임, 이동 루프, 소환 진입 프레임을 공용 메타데이터로 관리
- 직업 개성은 실루엣·타이밍·무기 궤적으로 표현하되 골격 계약은 유지
