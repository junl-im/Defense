# Dokkaebi Defense 게임 기획서 v3.8.0

## 1. 제품 정의

한국 전통 판타지 영웅을 직접 조작해 엽전을 모으고, 운에 따라 수호대를 소환·합성하며, 짧은 원정 안에서 폭발적으로 성장하는 캐주얼 3D 디펜스다. 모바일 MMORPG의 무거운 조작과 복잡한 메뉴가 아니라, 한눈에 읽히는 전투와 강한 수집 욕구를 목표로 한다.

## 2. 핵심 감정

- 귀여운 2.3등신 영웅을 모으는 즐거움
- 랜덤 소환과 합성에서 터지는 기대감
- 큰 무기·강한 이펙트·등급 색으로 즉시 느껴지는 성장
- 8~10분 안에 완성되는 한 판의 서사
- 도깨비, 무당, 신선, 구미호, 호랑이, 용으로 확장되는 한국형 IP

## 3. 코어 루프

`직접 이동 → 자동 공격 → 엽전 회수 → 무작위 소환 → 동일 수호대 합성 → 유물 선택 → 보스 패턴 대응 → 전리품 획득 → 영구 성장`

## 4. 시작 직업 11종

도깨비 전사, 도깨비 궁수, 도깨비 법사, 도사, 무당, 호랑이, 해태, 구미호, 산신령, 저승사자, 용. 각 직업은 기본 공격, Skill1, Skill2, 고유 패시브, 궁극 성장 축을 가진다. 첫 출시에서는 11종을 모두 선택 가능하게 만들기보다 도깨비 전사를 골든 샘플로 승인한 뒤 3종씩 확장한다.

## 5. 성장 구조

### 한 판 성장
- 소환 등급 상승
- 수호대 3개 자동 합성
- 유물 3택 1
- 직업 전용 스킬 강화
- 보스 처치 전리품 장착

### 계정 성장
- 직업 해금과 숙련
- 도감 연구
- 무기·장신구 수집
- 시즌 패스와 업적
- 길드 공동 목표

### 등급
Common, Rare, Epic, Legend, Mythic, Immortal, God. Common의 회색은 작은 테두리·라벨에만 사용하고 화면 전체를 회색으로 만들지 않는다.

## 6. 적과 보스

일반 적은 Ghost, Skeleton, Crow, Wolf, Pig, Spider, Bat, Goblin 계열로 구성한다. 엘리트는 큰 귀신, 화염 도깨비, 얼음 도깨비를 시작점으로 한다. 런칭 보스 축은 도깨비왕, 구미호, 구천현녀, 이무기, 용, 저승대왕이며 총 20종까지 확장한다.

## 7. 스테이지

도깨비마을 → 대나무숲 → 폐사찰 → 설산 → 용궁 → 저승 → 천계. 각 지역은 Ground, Road, Grass, Rock, Tree, Shrine, Bridge, Fence, Water, Flower, Lantern, Torch의 공통 문법을 공유하되 색·실루엣·조명으로 구분한다.

## 8. 화면과 메타 시스템

메인, 소환, 영웅, 가방, 상점, 업적, 패스, 랭킹, 길드, 설정의 10개 주요 화면을 운영한다. 전투 진입 전에는 선택을 3단계 이내로 제한하고, 전투 중에는 화면 중앙을 비우며 핵심 HUD만 유지한다.

## 9. 밸런스 원칙

- 전투 실패가 결제 부족처럼 느껴지지 않게 한다.
- 보스 패턴은 이펙트 색, 바닥 텔레그래프, HUD 의도 문구가 동시에 알려준다.
- 치명타·잭팟은 강하지만 일반 공격의 가독성을 압도하지 않는다.
- 1회 원정에서 최소 한 번은 명확한 파워 스파이크가 발생한다.
- 자동 전투는 반복 피로를 낮추고, 직접 이동은 위험 회피와 보상 회수에 의미를 둔다.

## 10. 출시 단계

1. P0 골든 샘플: 도깨비 전사, 일반 적 3종, 도깨비마을, 전투 HUD
2. P0 런칭 코어: 시작 직업 3종, 보스 2종, 소환·영웅·가방
3. P1 수집 루프: 11직업, 6보스, 4스테이지, 패스·업적
4. P2 시즌 확장: 7스테이지, 길드, 랭킹, 라이브 이벤트
5. P3 IP 확장: 캐릭터 50종과 1,130개 시각 에셋 완성
