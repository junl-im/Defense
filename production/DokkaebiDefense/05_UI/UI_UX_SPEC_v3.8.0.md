# Dokkaebi Defense UI/UX 설계서 v3.8.0

## 기준 해상도

- 1920×1080 가로
- 1440×2560 세로

실제 배치는 CSS 픽셀 고정이 아니라 안전영역, visual viewport, 글자 배율, 조작 손 방향을 입력으로 계산한다.

## 디자인 언어

Gold, Dark, Blue, Red, Green 버튼 세트를 사용한다. 모든 버튼은 둥글고, 눌리는 깊이와 상단 하이라이트가 있으며, 활성 상태에는 제한된 Glow를 준다. MMORPG식 얇은 유리 패널보다 두껍고 명확한 캐주얼 패널을 사용한다.

## 주요 화면 흐름

### 메인
플레이 시작, 오늘의 보상, 직업 대표, 핵심 재화만 노출한다. 소환·영웅·가방·상점·업적·패스·랭킹·길드는 하단 또는 측면 탭으로 접근한다.

### 소환
소환 종류 → 확률·보장 확인 → 1회/10회 소환 → 결과 정렬 → 신규 표시. 확률과 천장 진행도를 같은 화면에 표시한다.

### 영웅
직업 필터 → 캐릭터 선택 → 3D 미리보기 → 능력·스킬 → 장비 → 승급. 얼굴과 무기가 가장 크게 보이게 한다.

### 가방
장비·유물·재료를 분리하고, 비교 수치는 증가·감소를 색과 화살표로 동시에 표시한다.

### 상점·패스
가격, 획득량, 구매 제한, 갱신 시간을 한 카드 안에 표시한다. 과도한 팝업 연쇄를 금지한다.

### 랭킹·길드
친구·지역·전체 필터를 유지하며, 길드 화면은 출석·공동 보스·기부를 첫 화면에서 보여준다.

## 전투 HUD 우선순위

1. 플레이어 HP와 보스 HP
2. 보스 공격 의도
3. 조이스틱·스킬·소환·웨이브 버튼
4. 웨이브·재화·수호대 상태
5. 시드·유물·도전과제

충돌 시 5번부터 축약하며 1~3번은 숨기지 않는다.

## 모바일 겹침 방지

- 320px 폭에서도 조이스틱과 액션 도크 사이 최소 16px
- 보스 HUD는 상단 독립 레일
- 모달은 visual viewport 높이를 넘지 않고 내부 스크롤
- 마지막 주요 행동 버튼은 모달 하단에 고정
- 한국어 2줄 초과 시 글자 축소가 아니라 정보 재배치
- 44×44px 미만 터치 영역 금지

## UI 자산 규칙

UI 250종은 screen, button, panel, frame, slot, badge, navigation, hud로 분류한다. 패널·버튼·프레임은 9-slice를 전제로 제작하고, 아이콘과 텍스트는 분리한다. 래스터 포맷만 사용한다.
