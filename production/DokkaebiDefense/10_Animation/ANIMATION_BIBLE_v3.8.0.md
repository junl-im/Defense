# Dokkaebi Defense Animation Bible — Absolute v2.0 Contract

모든 캐릭터는 공용 Humanoid Rig와 아래 11개 필수 클립을 사용한다.

1. Idle
2. Walk
3. Run
4. Attack1
5. Attack2
6. Skill1
7. Skill2
8. Hit
9. Death
10. Victory
11. Spawn

11개 시작 직업 기준 핵심 제작 행은 **121개**다. 보스 Phase는 선택 추가 클립이며 11개 공통 클립을 대체하지 않는다.

제작 방향은 Front, 45°, Side, 135°, Back이며 좌우 반전을 사용한다. 눈 크기와 얼굴 비율은 모든 애니메이션에서 고정한다. 동작의 개성은 실루엣, 타이밍, 무기 궤적으로 표현한다.
