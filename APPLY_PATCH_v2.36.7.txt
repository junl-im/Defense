KingdomSeed v2.36.7 - Battle Stream Guard Patch

적용 방법:
1. 기존 KingdomSeed 프로젝트 루트에서 이 zip의 내용을 그대로 덮어씌웁니다.
2. 기존 node_modules 또는 dist는 zip에 포함되어 있지 않습니다.
3. 적용 후 아래 명령으로 확인합니다.

   npm ci
   npm run build
