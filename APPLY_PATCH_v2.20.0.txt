KingdomSeed v2.20.0 Toy Garden Massive Art QA Patch

적용 방법
1. 이 zip의 내용물을 기존 프로젝트 루트에 그대로 덮어씁니다.
2. GitHub Desktop에서 변경 파일을 확인합니다.
3. 로컬 node_modules 문제가 있으면 터미널에서 npm install을 실행합니다.
4. 확인 명령:
   npx tsc --noEmit --pretty false
   npm run build

구성
- v2.16~v2.20 귀여운 UI/아트 패치 누적 포함
- .git, node_modules, dist 제외
- 새 에셋은 public/assets/ui/v2_20에 PNG/WebP 세트로 추가
- scene-ready 버전은 2.20.0
